厦马小筑（XMUMDorm）面向厦门大学马来西亚分校学生，提供校园资讯、同学交流与日常生活服务。

## 主要功能

### 广场

- 学校、学院与专业组织通知
- 校园热搜、社团广场、新生指南与一站式校园信息
- 校园活动与合作推广轮播

### 树洞

- 图文发帖、评论、点赞、收藏
- 按话题浏览同学讨论
- 举报不当内容，共同维护社区环境

### 食堂

- 食堂分区、商铺和菜品浏览
- 热门菜品、商铺排行与最新点评
- 补充商铺和菜品信息，发表点评、上传图片

### 社团与校园互助

- 发现社团、查看动态、发布活动和报名
- 二手物品发布与浏览
- 跑腿任务发布、接取与进展查看

### 个人空间

- 编辑个人资料和公开范围
- 课程表、待办、日记
- 信箱中的公告、互动与事务通知

## 使用

访问 [厦马小筑 Web 版](https://xmumdorm-200-lyzz-production.up.railway.app)，或使用面向 XMUM 学生逐步提供的 Android 应用。
