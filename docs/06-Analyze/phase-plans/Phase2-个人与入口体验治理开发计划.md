# Phase 2 - 个人与入口体验治理开发计划

## 目标

本 Phase 聚焦上线前高频入口和个人操作区域的收束与优化，覆盖备忘录第 5、6、7、8、9 项：广场功能入口排布、轮播图管理员界面、Todo 页面、关于我们内容收束、设置入口收束。

目标是让用户更快找到核心功能，让管理员操作更清楚，让个人区域从“功能堆叠”变成稳定的信息架构。改造同时覆盖 Capacitor App 和 Web 端；废弃的 `mobile/` RN 前端不在范围内。

## 用户问题

- 广场入口较多，社团广场、马校一站通等功能的排布缺少主次，首屏扫描成本高。
- 轮播图管理入口和编辑操作偏后台堆叠，预览、状态、排序和操作反馈不够清楚。
- Todo 页面体验粗糙，创建 Todo 需要额外页面，完成状态反馈不够直接。
- 免责声明、联系我们等低频信息占据独立顶层入口，关于我们信息架构分散。
- 编辑资料、退出登录、注销账号缺少统一设置容器，危险操作与普通操作层级不清。

## Phase 范围与实施顺序

### 1. 广场功能入口排布

保留社团广场、马校一站通等既有功能入口和业务路径，重新组织首屏顺序、分组和视觉权重。入口应支持快速扫描，避免新增解释性大卡片、重复标题或不必要的装饰容器。

交付结果：用户能从广场首屏明确区分核心功能入口、校园内容入口和次级入口；App 与 Web 的入口语义和顺序一致，允许因平台布局差异采用不同排列方式。

### 2. 轮播图管理员界面

围绕管理员的真实工作流整理页面：查看当前轮播、识别启用状态、预览图片、调整排序、编辑内容、启停、删除和新建。编辑表单与列表之间应有稳定的返回和取消行为，保存、删除和失败状态必须有明确反馈。

权限边界保持现有后端鉴权：普通用户不能进入或执行管理员轮播图管理操作；前端隐藏入口不替代后端权限校验。

交付结果：管理员可在一个清晰的工作区完成轮播图维护，不需要依靠隐含状态或重复跳转。

### 3. Todo 页面与创建流程

优化 Todo 列表的密度、完成/未完成层级、加载/空/错误状态和触控反馈。创建 Todo 收束到“创建”按钮触发的页内表单、抽屉或弹层，不再要求用户进入一个内容单一的独立创建页面。

继续使用现有乐观更新语义：勾选完成后先更新界面，后端失败时恢复状态并提示。创建成功后关闭创建界面并将新 Todo 放入正确列表位置。

交付结果：用户可以在 Todo 页面内完成浏览、创建、勾选和失败恢复，且键盘、返回键和小屏布局不被遮挡。

### 4. 关于我们内容收束

将免责声明、联系我们作为关于我们下的子入口或同页分区，移除不必要的顶层导航重复入口。原有页面内容、外部链接、联系方式和法律文本保留，改变的是信息架构与导航路径，不是法律含义。

交付结果：用户从关于我们可以稳定找到团队、特别鸣谢、免责声明和联系我们；旧路径如需兼容，应通过重定向或等价入口保留可达性。

### 5. 设置入口收束

新增或完善设置容器，将编辑资料、语言设置（如已有）、退出登录和注销账号统一放入设置。普通设置与危险操作必须分组，注销账号需要二次确认及明确后果，退出登录需要清晰反馈并清理本地会话状态。

权限和安全边界保持不变：设置只操作当前用户；注销和退出不得误触发其他用户数据操作；未登录用户不应看到需要身份的设置内容。

交付结果：用户从个人空间进入设置即可完成个人资料、语言、登录状态和账号生命周期操作。

## 跨端与交互原则

- App 优先保证单手触控、返回键、底部 Tab 和安全区域；Web 保持键盘导航、焦点可见和桌面宽度下的合理容器。
- 不引入新的渐变背景、堆叠式圆角卡片或解释性功能文案作为主要布局手段。
- 保持现有中英文模式；所有新增可见文案必须同时提供中英文，内容型文本不被错误翻译。
- 交互反馈优先使用现有 Toast、空态、错误态和确认模式，避免新增重复基础组件。
- 不改变后端业务契约，除非现有入口无法满足权限或数据一致性要求；如需接口调整，必须同时补充鉴权和回归测试。

## 依赖与阶段顺序

1. 先盘点并确定个人空间、关于我们和设置的导航信息架构。
2. 完成关于我们和设置的入口收束，稳定全局导航后再改 Todo 的页内创建体验。
3. 完成 Todo 页面，再处理广场入口排布，避免两个高频入口同时改变导致验收混乱。
4. 最后优化轮播图管理员工作区，并执行管理员权限与普通用户可见性回归。
5. Phase 末尾统一进行 App/Web 双端构建、路由可达性、语言模式和真机/浏览器验收。

## 验收标准

- [ ] 广场核心入口保留且首屏层级清楚，App/Web 均可到达社团广场和马校一站通。
- [ ] 管理员可完成轮播图查看、预览、新建、编辑、排序、启停和删除；普通用户不能执行管理操作。
- [ ] Todo 创建在 Todo 页面内部完成；完成勾选保持乐观更新，失败会恢复并提示。
- [ ] 免责声明和联系我们从关于我们可达，原内容和必要旧路径不丢失。
- [ ] 编辑资料、退出登录、注销账号从设置可达；注销有明确二次确认，退出后会话被清理。
- [ ] 中英文模式、键盘导航、Android 返回键和移动端安全区域回归通过。
- [ ] App 生产构建、Web 生产构建和必要的后端/权限测试通过。

## 不在本 Phase 范围内

- 个人空间整体视觉重构（备忘录第 4 项）。
- 通知系统全链路测试和通知 UI 治理（第 11、12、13 项）。
- 树洞推荐话术清理、底部 Tab 动效和其他未选中的备忘录事项。
- 任何废弃 `mobile/` RN 前端改造。
