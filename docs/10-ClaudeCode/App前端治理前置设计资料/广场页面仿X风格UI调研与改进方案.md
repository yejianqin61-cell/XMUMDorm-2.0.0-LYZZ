# Capacitor App 广场页面：仿 X 风格 UI 调研与改进方案

## 结论

广场应从“多个说明卡片组成的首页”收敛为“一个连续的校园信息流 + 一行功能入口”：顶部只保留页面标题和必要的 Tab，帖子/热搜/公告用同一套行级内容节奏呈现；社团广场、马校一站通、帮帮我、出物四个功能入口保留，但收敛为单行轻量入口栏，只展示图标和名称。大圆角、渐变、箭头和解释性副文案不再承担默认视觉层级。这里的“仿 X”指交互和信息密度借鉴，不复制 X 商标、图标资产或具体品牌视觉。

## 当前广场的主要问题

当前入口在 `frontend-app/src/pages/SquareHome.jsx`，同时渲染 `TodayCampusHero`、`TodayCampusTrendingBoard`、`TodayCampusQuickActions` 等多个视觉模块；相关样式在 `frontend-app/src/pages/SquareHome.css`。这会带来：

- 首屏模块堆叠，用户先读标题、说明和入口，再读内容。四个功能入口不应删除，但应降级为一行轻量入口。
- 大圆角、渐变背景、玻璃效果和箭头把“导航提示”做成了主内容。
- 英文 eyebrow、功能解释句、`→` 引导文案和装饰 emoji 增加阅读噪音。
- 热搜是运营排序列表，但视觉上被表现成营销型榜单，和校园讨论流割裂。

## 目标信息架构

```text
广场                         [刷新/发布]
校园        热搜             <- 仅保留真实筛选 Tab
----------------------------------------
作者名  时间                         ···
正文文本（可含图片）
评论数       点赞数       更多
----------------------------------------
作者名  时间                         ···
正文文本
...
```

### 首页规则

1. 顶部使用普通页面标题“广场”，保留现有轮播图作为唯一首屏媒体位；不使用 hero 大标题、eyebrow 或解释段落。
2. `校园` 与 `热搜` 是两个可切换的真实内容源；用 1px 底部指示线表达选中态，不做胶囊按钮。
3. 内容行全宽排列，行间用 `1px` 分割线；不使用浮层卡片、阴影、毛玻璃或渐变。
4. 作者行：头像（可选）+ 名称 + 时间；低优先级元信息使用中性色。不要重复“校园帖子”“社区内容”等标签。
5. 正文是主要点击区域，点击进入对应详情；图片紧跟正文，最多保持一张主图预览，更多图片进入详情。
6. 操作行只保留已有能力：评论、点赞、更多；使用熟悉图标和可访问 label，隐藏“点击查看”“参与讨论”等解释性文字。
7. 热搜行展示标题和真实讨论数；排名使用普通数字，不为前三名增加红/橙/黄渐变徽章。只有趋势数据真实存在时才显示趋势标记。
8. 社团广场、马校一站通、帮帮我、出物四个入口保留，但降级为 Tab 下方的一行轻量入口栏：每项只有图标和短标题，无描述、无渐变、无阴影，超出屏幕宽度时支持水平滚动。它们不和信息流并列堆成大型四宫格。

### 视觉基线（Dorm 建议 token）

| 项目 | 建议 |
| --- | --- |
| 背景 | `#FFFFFF`；页面分区需要时用 `#F7F9F9`，不使用渐变 |
| 正文 | `#0F1419`，移动端 `15-16px`，行高 `1.45-1.6` |
| 次要信息 | `#536471`，`13px` 左右 |
| 分割线 | `#EFF3F4`，`1px` |
| 强调色 | 使用现有品牌蓝作为链接、Tab 指示线和焦点态；每屏只保留一个强调色 |
| 圆角 | 信息流行不设外层圆角；图片最多 `8px`；按钮不超过 `8px`。 |
| 间距 | 内容行左右 `16px`；作者行与正文 `4-8px`；操作行与正文 `8-12px`。 |
| 动效 | 只保留加载、点赞反馈和 Tab 切换；禁止漂浮装饰和自动位移背景。 |

## 文案收敛

删除或移入无障碍属性/开发注释的可见文案：`Today on Campus`、`校园信息聚合中心`、`快速入口`、`查看热搜榜`、`探索校园`、`了解更多`、`→` 等。保留用户需要完成动作或理解状态的短文本：`广场`、`校园`、`热搜`、`发布`、`暂无内容`、`加载失败，重试`。

无障碍 label 仍应保留，但放在 `aria-label`、tooltip 或菜单项中，不把它们渲染成解释性段落。

## 实施顺序与验收

1. 先收敛 `SquareHome.jsx` 的 DOM：保留一个标题栏、Tab、信息流；移除 Hero/QuickActions 的首屏说明和装饰。
2. 复用现有 `SquareCampusFeed`、`SquareTrendingList` 的查询和详情路由，避免新增 API 或数据模型。
3. 在 `SquareHome.css` 中替换卡片/渐变/阴影 token，统一分割线、正文和操作行节奏。
4. 检查 375px、390px、430px 宽度：首屏第一条内容完整可读，Tab 不横向溢出，操作图标可触达（至少 44px 命中区）。
5. 验收：首屏不出现功能解释段落；信息流中不出现嵌套卡片；无渐变背景；详情、点赞、评论、刷新和错误重试行为不变；中英文切换不溢出。

## 不在本轮范围

- 不改变热搜后端排序、帖子权限或 API。
- 不移植 X 的商标、logo、专有图标或品牌资源。
- 不改弃用的 `mobile` RN 前端，也不同时重做 Web 端。
