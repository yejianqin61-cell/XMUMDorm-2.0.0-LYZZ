# 移动端宪法（v0.2 草案 · 待批准）

> **状态**：草案。批准后**取代** [`移动端约束.md`](移动端约束.md)。
> **冲突裁决**：本文与技术约束冲突时以本文为准；[`技术约束.md`](技术约束.md) 的「样式体系」行已同步修改。
> **覆盖范围**：`mobile/` 全部代码、设计、依赖、发布流程。
> **背景**：旧移动端的实测结论是「功能已齐、展示层从未建立」——69/69 屏不使用自有 UI 组件、1144 处硬编码色值、645 处 `fontSize` 字面量、Reanimated 与 gesture-handler 装了但**全项目 0 处引用**、Android 上玻璃效果从未生效。故本次为**全盘重写**，不是修补。

**v0.1 → v0.2 变更**：SDK 由 56 更正为 **57**。原因：Expo 官方 changelog 显示 **SDK 58 于 2026-09-15 仍是 Beta**（其官方 pin 里 `react-native` 为 `0.88.0-rc.2`），当前**最新稳定版是 2026-06-30 发布的 SDK 57**，且 SDK 57 修了 SDK 56 的 Hermes V1 内存回归。原「直上 58」的选项已撤回。

## 第 1 条 设计方向（不可协商）

三条来源，各有明确边界与量化上限：

| 来源 | 取什么 | 明确不取什么 |
|---|---|---|
| **苹果式舒适** | 留白与呼吸感、层级分明的字阶、连续圆角、物理化动效、内容优先、克制的色彩 | 不做纯 iOS 克隆；Android 必须拥有同一品牌气质，不是两个 App |
| **Discord 式社区感** | 暗色**分层表面**、社区信息密度、成员/在线/未读语义、单一强调色、分组列表与分隔线 | 不搬侧栏/频道隐喻（移动端用 Tab + 分段控件承载）；不做无层次的密集堆叠 |
| **Neo-Brutalism（只一点点）** | **仅限 CTA / Badge / 分区标题**：2px 描边 + 硬偏移阴影 + 高对比色块 + 较重字重 | 不用于内容表面、不用于正文段落、不全站铺开；超过三类元素即越界 |

**禁止项（红线）**

1. ❌ 玻璃拟态 / `backdrop-filter` / 模糊作为视觉身份 —— 本设计语言已废弃。
2. ❌ 「移动端 1:1 复刻 Web 端 UI」—— 这正是旧版「网页感、不像成品 App」的根源。
3. ❌ 在组件内书写十六进制色值与 `fontSize` 字面量（改由令牌提供）。

**深度的表达方式**：分层表面 + 硬阴影 + 描边，**不是模糊**。

## 第 2 条 设计令牌是唯一事实源

- 位置：`mobile/src/design/`（`tokens.ts` 为唯一来源）。
- 六组令牌：**色彩 / 字阶 / 间距 / 圆角 / 描边 / 阴影**。
- **暗色优先**，亮色为派生；两套都必须完整可用（含真机验收）。
- 新代码禁止出现色值与字号字面量，由 lint 规则强制（细则见《编码规范》）。
- 平台差异只允许发生在**语义令牌**层（如 `surface.content` 在两端取不同值），不允许散落到组件的 `ios:`/`android:` 分支里。
- 页面结构收敛到 12 种**布局原型**（见《移动端页面清单与结构盘点》§2）；新需求先扩原型库，不许单页自造样式。

## 第 3 条 技术栈（硬约束）

| 层面 | 选定 | 说明 |
|---|---|---|
| 框架 | **Expo SDK 57** + RN **0.86.3** + React **19.2.3** | 最新稳定版；见 v0.1→v0.2 变更说明 |
| 路由 | **expo-router ~57.0.24** | **禁止 `import '@react-navigation/*'`**（SDK 56+ 已在应用代码层阻断） |
| Tab 栏 | `expo-router/unstable-native-tabs` | SDK 57 上稳定入口仍带 `unstable-` 前缀（58 才去掉）；能力不受影响 |
| 样式引擎 | **Uniwind 1.12.0**（Tailwind v4） | MIT、无原生模块、OTA 安全；与旧 `StyleSheet` 可共存 |
| 原生分区 | **`@expo/ui` ~57.0.21**（Jetpack Compose / SwiftUI） | 用于 sheet / picker / datetime / segmented / 导航壳 |
| 内容分区 | RN 组件 + 令牌 | 卡片、列表、媒体、表单 |
| 列表 / 图片 / 触感 | `@shopify/flash-list` 2.0.2 / `expo-image` ~57.0.5 / `expo-haptics` ~57.0.3 | 瀑布流用 `numColumns={2} masonry` prop |
| 动效 | **Reanimated 4.5.1** + `react-native-worklets` 0.10.1 | 能力边界见下 |

**禁止的依赖**

- ❌ `react-native-unistyles`、`react-native-m3`、任何 nitro-modules 系 —— 引入原生依赖，破坏 OTA 纪律。
- ❌ `react-native-paper` —— 仅 MD3（2021）且官方声明不支持动态取色，RN 0.86 兼容性未验证。
- ❌ 任何无 LICENSE 的仓库代码。

**`@react-navigation/*` → expo-router 映射表**

| 旧写法 | SDK 57 写法 |
|---|---|
| `@react-navigation/native` | `expo-router/react-navigation` |
| `@react-navigation/stack` | `expo-router/js-stack` |
| `@react-navigation/bottom-tabs` | `expo-router/js-tabs` |
| `@react-navigation/material-top-tabs` | `expo-router/js-top-tabs` |
| native-stack / drawer | `Stack` / `Drawer` |

**原生 ↔ RN 边界规则**

- 所有 Compose 组件必须包在 `Host` 内；RN 视图进入原生树用 `RNHostView`。
- `@expo/ui` 的 Compose API **没有光栅/网络图片组件** → 一切图片走 `expo-image`，置于 `RNHostView`。
- ⛔ **禁止给 `matchContents` 传同轴可滚动子节点**（会崩溃）。
- `matchContents` / `ignoreSafeAreaKeyboardInsets` 只在挂载时生效一次，不可动态改。

**Reanimated 4.5.1 能力边界（写代码前必读）**

- ✅ 可用：`withTiming/withSpring/withDecay/withSequence/withRepeat/withDelay/withClamp`、`useSharedValue/useAnimatedStyle/useAnimatedProps/useDerivedValue`、滚动驱动、布局动画（Fade/Keyframes/transitions，含 `.withInitialValues()`/`.withTargetValues()`）、CSS 过渡与 CSS 动画、`useReducedMotion`。
- ⚠️ **Shared Element Transitions**：4.5.0 起 API 存在（`SharedTransitionBoundary`），但官方仍标注为**实验特性、需开启 feature flag、不建议生产使用** → v1 **不纳入计划**。
- 英雄转场由**导航层**提供（`Stack.Screen` 的 `animation` / `presentation`）。

## 第 4 条 导航与交互铁律（直治旧版病症）

1. **一屏一路由。禁止屏内状态机式导航。** 旧版把 6–12 个"视图"塞进一个屏，是返回栈错乱、深链失效的根本原因。
2. 返回栈只允许走 `router.dismiss(count)` / `dismissTo(href)` / `dismissAll()` / `canDismiss()`。
3. **每个模块必须能被深链直达**（URL → 具体页面，不只是 Tab 首页）。
4. 根布局必须包裹 **expo-router 的 `ThemeProvider`/`DarkTheme`/`DefaultTheme`**，否则出现白闪与 header 闪烁。
5. `Stack.Title` / `Stack.Header` / `Stack.Toolbar` 组合式 API 仍是 **ALPHA** → v1 一律用 **options API**。
6. `android.predictiveBackGestureEnabled`（当前为 `false`）**必须先实测再打开**——存在未决 issue，开启后手势返回可能失效。
7. Android 限制：Tab ≤ 5、原生 sheet detents ≤ 3、Tab 不支持嵌套、Tab 内容为**急切渲染**（重内容用 `useIsFocused`/`useFocusEffect` 延后）。

## 第 5 条 唯一一次原生重建窗口

以下原生依赖**必须一次装齐**，装完才进入 OTA-only 阶段（版本按 **SDK 57** 官方 pin）：

| 包 | 版本 | 用途 |
|---|---|---|
| `react-native-worklets` | **0.10.1** | **Reanimated 4.5.1 的非可选 peer，旧工程缺失** |
| `react-native-reanimated` | 4.5.1 | 动效层 |
| `@expo/ui` | ~57.0.21 | 原生分区 |
| `expo-image` | ~57.0.5 | 图片（含 config plugin） |
| `@shopify/flash-list` | 2.0.2 | 列表/瀑布流 |
| `expo-haptics` | ~57.0.3 | M3 / HIG 触感反馈 |
| `@expo/material-symbols` | 0.1.1 | `@expo/ui` 的 `Icon` 图标源 |

**顺序铁律**：**先装齐原生包，再做首次商店提交**；否则白白消耗一轮审核周期。
`runtimeVersion.policy` 必须在本窗口内一次性定下（建议 `fingerprint`，杜绝原生漂移）。

## 第 6 条 复用边界（什么移植、什么重写）

| 处理 | 对象 | 理由 |
|---|---|---|
| **移植（不重写）** | `mobile/src/api/`（19 模块，覆盖 ~158 个端点契约）、`src/utils`、Auth / Language context、现有测试所表达的业务断言 | 这是后端契约的唯一准确映射；重猜一遍只会换来一批线上才发现的问题 |
| **重写** | 全部 UI、导航、屏内状态、样式、组件 | 旧展示层未建立且架构方向已否定 |
| **禁止** | 把旧屏"搬过来再改" | 会把状态机导航一起带回来，等于重写失败 |

旧代码保留在标签 `mobile-v1-pre-rewrite`（待创建，见《移动端重写》总纲），需要时从 git 取回。

## 第 7 条 商店合规红线（不可推迟到 v2）

1. **屏蔽用户**（UGC 政策 + Apple 1.2 强制；后端目前只有管理员侧 ban/mute）—— **需改后端**。
2. **应用内真注销**（Apple 5.1.1(v)：设置内可找到，且**必须删除该用户的 UGC**；后端目前仅 `status='deactivated'` 软注销）—— **需改后端**。
3. **使用条款接受**（Play UGC 政策要求；移动端当前缺失）。
4. **隐私政策应用内可达**（Web 已有 `/privacy`）。
5. `android.package` / `ios.bundleIdentifier`（当前均缺失）。
6. `eas.json` 与发布链路（当前不存在）。
7. 权限清理：移除与功能无关的 `RECORD_AUDIO`。
8. **审核者可用的测试账号**（登录墙应用，缺失将无法审核）。

1. ~~SDK 版本~~ **→ 已裁决方向：SDK 57**（58 为 Beta，已排除）。**待所有者最终确认**。
