# 技术约束

## 技术栈（硬约束）

| 层面 | 技术 | 版本 | 约束 |
|------|------|------|------|
| 后端运行时 | Node.js + Express | — | 不可切换框架 |
| 数据库 | MySQL | — | `jack_campus` 库，使用 `database.js` 的 `query` 方法 |
| 鉴权 | JWT | — | 中间件 `middleware/auth.js` |
| Web 前端 | React | 18+ | 不可引入 Next.js / Remix 等 SSR 框架（已有独立 SSR 方案） |
| 移动端 | React Native (Expo) | SDK 52+ | `mobile/` 目录，Expo Router 文件系统路由 |
| 状态管理 | TanStack Query | — | Web + RN 统一使用 |
| 样式体系 | 液态玻璃设计 | — | CSS 模式 → `expo-blur`（RN） |
| 图片存储 | **对象存储（S3 兼容，Cloudflare R2）** | — | 经 `services/objectStorage.js` 写入；`sharp` 统一转 webp（≤2048px 宽）；类型 jpg/png/webp/gif，≤ 8MB |
| 通知推送 | Web Push + RN Push | — | 双通道推送 |

## 存储形态（权威口径）

> ⚠️ 本节为存储相关的**唯一权威说明**。历史文档中「图片本地存储 / 非云存储」的表述已作废。

| 资产 | 存储位置 | 写入者 | 公网访问方式 |
|------|----------|--------|--------------|
| 用户上传图片（帖子 / 头像 / 商品 / 评论 / 封面 / 横幅） | **Cloudflare R2**（S3 兼容） | 后端 `services/objectStorage.js` `uploadBuffer()` | `PUBLIC_ASSET_BASE_URL` + object key，见 `utils/assets.js` `assetUrl()` |
| —— 未配置对象存储时的回退 | `uploads/` 本地目录 | 同上（分支回退） | `/uploads/<key>` 静态服务 |
| 默认图 / 随代码部署的静态资源 | `public/` | 提交进仓库 | 根路径静态服务 |
| **学习资料（M10，已实施）** | **独立 public GitHub 仓库 + CDN** | 后端代理 GitHub API（PAT 仅服务端） | `cdn.jsdelivr.net/gh/...`，见 [Module10 设计](../../04-Module/M10-学习资料/Module10-学习资料设计.md) |

**约束**：
1. 图片等二进制资产**一律走对象存储**，不得新增本地磁盘写入（回退分支仅为兼容历史环境保留）。
2. 新增存储形态必须在本节登记，并说明写入者与公网访问方式。
3. 任何存储凭据（R2 Key / GitHub PAT）**只允许存在于服务端环境变量**，不得下发前端。

## 不可变约束

1. **API 层 100% 复用** — 后端 API 不因 Web/App 而分叉
2. **单库多端** — 同一仓库 `XMUMDorm-2.0.0-LYZZ`，Web 在 `frontend/`，RN 在 `mobile/`
3. **路由文件命名** — 后端 `routes/<模块名>.js`，前端 `pages/<PageName>.jsx`
4. **迁移系统** — 使用 `migrations/` + `scripts/run-incremental-migrations.js`，不可手动改库
5. **用户角色** — `student | merchant | admin`（admin 即官方号）
