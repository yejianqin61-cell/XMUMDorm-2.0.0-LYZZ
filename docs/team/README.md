# 团队协作

本目录只存放**团队共同遵守的协作规则、入职指引和变更流程**，不放业务需求或个人笔记。

## 四份手册（按角色选读）

| 文档 | 回答什么 | 谁必读 |
|---|---|---|
| [团队协作契约](团队协作契约.md) | **规则**：分支模型、提交规范、PR 要求、文档规则、数据库规则、密钥纪律、上线与回滚 | **所有人**（先读这份） |
| [本地开发环境手册](本地开发环境手册.md) | **怎么跑起来**：依赖、`.env`、两条迁移命令、启动自检、以及"注册收不到验证码"的三条绕过路径 | 新成员、协助者 Agent |
| [协助者 Agent 守则](协助者Agent守则.md) | **AI 协助者的底线**：写作用域、Git 禁令、验证门槛、五段式汇报、必须停下来的四类情形 | **每个 AI Agent** |
| [Git 协作手册](Git协作手册.md) | **具体怎么敲**：初始化、每日循环、提交、PR、冲突处理、事故对照表 | 提交代码的人与 Agent |

**新人顺序**：契约 → 本地开发环境手册 →（跑通后）→ Git 协作手册。
**Agent 顺序**：协助者 Agent 守则 → 契约 → 本任务所属层的 README。

> Git 的原理与命令教程不在这里，见 [`docs/09-Deploy/git/`](../09-Deploy/git/)。
