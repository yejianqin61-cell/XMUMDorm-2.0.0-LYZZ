# 二手市场私信体验与信箱联动：需求

**版本**：V1.0（Web）　**日期**：2026-11-16　**提出人**：wx　**任务表**：任务管理表 #8「web:二手市场的UI优化，对话用户体验。和信箱的联动对接」

## 一、要解决的问题

1. **Web 找不到自己的对话**。后端早有"我的全部会话"接口（`GET /api/marketplace/chat/threads`，App 的会话页在用），Web 没有入口。买家想找旧对话只能重新打开商品，卖家只能进每个商品详情页去翻。
2. **读了私信，信箱还显示未读**。每条私信都会给对方发一条 `marketplace_chat` 通知。但从商品页或链接直接进聊天页时，这些通知不会消掉，信箱「交易」一栏的红点一直挂着。
3. **聊天页信息太少**。看不到对方是谁、在聊哪件商品、现在什么价、卖没卖；只显示最近 100 条，更早的看不到；发送失败消息就没了；也不知道对方读没读。

## 二、范围

**本期（Web + 后端）**：
- 信箱新增「私信」Tab：列出我作为买家、卖家的全部对话（对方头像和名字、我在卖还是我想买、商品名、最后一条消息、时间、未读数），点开进入对话。Tab 上显示私信未读总数。`/mailbox?tab=chats` 可以直接打开这个 Tab。
- 打开对话、或者在对话里收到对方新消息时，标记已读。后端顺带把**自己**这条对话的私信通知全部标已读，信箱红点同步消失。
- 聊天页改版：
  - 顶部显示对方头像、名字和身份（买家或卖家），右上角「全部私信」回到信箱
  - 商品卡片显示封面、标题、价格、状态（在售、已预订、已售出、已删除），点击进入商品详情
  - 按天插入分隔条（今天、昨天、具体日期）
  - 「查看更早的消息」按页往前翻，加载后保持当前滚动位置
  - 我的最后一条消息标「已读」或「已送达」
  - 发送时先显示「发送中」；失败后保留原文，可以「重发」或「删除」
  - Enter 发送，Shift+Enter 换行（输入法选词时的 Enter 不算）；剩余不到 200 字时显示倒计数

**不在本期**：App 端（App 已有会话列表，后端字段已兼容，App 想要已读提示、商品卡片可另开任务接）；图片消息；WebSocket 实时推送（仍是 4 秒轮询）。

## 三、后端约束

- 通知只按「当前用户 + `marketplace_chat` 类型 + 这条对话的 ID」更新，碰不到别人的通知，也碰不到其它类型的通知。
- 通知更新是尽力而为：失败只记日志，不影响已读边界和接口结果。
- 会话详情新增的字段（`role`、`peer`、`peer_last_read_at`、`item`）只是追加，原有字段不动，App 不受影响。
- 不新增表或字段，不需要迁移。

## 四、验收

| # | 标准 |
| --- | --- |
| 1 | 信箱有「私信」Tab，买家和卖家两侧的对话都列出来，未读数和对话里一致 |
| 2 | 从任何入口打开对话后，回到信箱，这条对话的私信通知已读，「交易」未读数减少 |
| 3 | 聊天页显示对方和商品卡片；商品删除后显示「商品已删除」，卡片不可点 |
| 4 | 超过 100 条消息可以往前翻页，翻页时画面不跳 |
| 5 | 断网发送：消息显示「发送失败」，点「重发」成功后与正常消息一致 |
| 6 | 无关用户读不了别人的对话（403），也改不了别人的通知 |
