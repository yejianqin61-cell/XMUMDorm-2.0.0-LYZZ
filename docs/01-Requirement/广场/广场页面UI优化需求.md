# 广场页面 UI 优化：需求

**版本**：V1.0（Web）　**日期**：2026-11-16　**提出人**：wx　**任务表**：任务管理表「web:广场页面的UI优化」（重要紧急）

## 背景

任务在 2026-10-15 创建，之后广场在 10-23 到 10-30 之间改成了「轮播 + 校园快讯」（见 `frontend/src/features/campus-news/README.md`）。这次**不重做设计**，只修当前页面上能指出来的具体问题。

## 要修的问题

| # | 问题 | 改法 |
| --- | --- | --- |
| 1 | 筛选有两行一模一样样式的按钮：「全部 / 竞赛 / 讲座 / 校园生活」和「全部通知 / 与我相关」，两个「全部」容易混 | 合成一行：分类在左，右侧单独一个「只看与我相关」开关 |
| 2 | 英文界面下，筛选、翻页、加载中、错误提示、点赞和评论按钮的读屏文字仍是中文 | 补齐英文 |
| 3 | 切换分类或翻页时，整块列表先变成「正在加载校园快讯…」，再跳回来 | 保留上一屏、半透明显示，新数据到了直接替换 |
| 4 | 翻到下一页后，视线还停在页面最底部 | 翻页后滚回快讯列表顶部 |
| 5 | 没有快讯时同时显示「暂时没有校园快讯」「暂时没有更多快讯」和「第 1 页 · 共 0 条」的翻页 | 列表为空时只显示一句；只有一页时不显示翻页 |
| 6 | 翻页文字只有「第 N 页」，不知道总共几页 | 改成「第 N / M 页 · 共 X 条」 |
| 7 | 点赞失败的提示和重试按钮没有样式 | 补上样式 |

## 不在本期

- 轮播、卡片版式、配色等整体视觉：维持 10 月改版的设计。
- 「web:广场页面的校园公告，学院通知，UI排版的优化」那条任务（另有负责人记录）。

## 验收

| # | 标准 |
| --- | --- |
| 1 | 只有一行筛选；「只看与我相关」可开可关，开启时有明显的选中样式 |
| 2 | 英文界面下，快讯区域没有中文控件文字（快讯内容本身除外） |
| 3 | 切换分类和翻页时列表不闪成「加载中」 |
| 4 | 翻页后回到列表顶部 |
| 5 | 空列表只有一句「暂时没有校园快讯」，没有翻页 |
