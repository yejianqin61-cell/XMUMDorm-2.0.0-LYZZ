# 角色丁阶段三 Debug 记录

日期：2026-10-29　分支：`dev-zjr-phase3`

## 发现与修复

会话列表游标原先要求 `last_message_at` 必须是字符串。数据库允许该字段为空，导致末尾空时间会话无法翻页；非空游标也会漏掉这些行。

修复后：

- 空时间游标可正常解码。
- 空时间游标只继续 `NULL` 时间且按线程 ID 向前翻页。
- 非空时间游标会把 `NULL` 时间行纳入后续页。
- 非法游标仍在访问数据库前返回 400。
