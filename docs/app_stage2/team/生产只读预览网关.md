# 生产只读预览网关

状态：已实现。用途：协作者在本地 Web 中读取课程资料预览数据，不获得数据库 URL 或迁移权限。

## 如何启用

部署环境必须设置下面三个变量。`PREVIEW_DATABASE_URL` 必须属于只读数据库账号或只读副本；网关不会使用 `DATABASE_URL`、`MYSQL_URL` 或 `RAILWAY_MYSQL_URL` 作为后备。

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `PREVIEW_DATABASE_URL` | 只读 MySQL 连接串 | 只授予所需 schema 的 `SELECT`。 |
| `PREVIEW_GATEWAY_TOKENS` | `alice:<sha256>,bob:<sha256>` | 每位协作者一个令牌哈希。 |
| `PREVIEW_ALLOWED_ORIGINS` | `http://localhost:5173` | 允许的本地开发来源，可用逗号分隔多个值。 |
| `PREVIEW_MATERIALS_BASE_URL` | `https://cdn.jsdelivr.net/gh/<owner>/<repo>@<ref>` | 课程资料文件的**公开**只读 CDN 基址；用于本地预览下载和在线阅读。 |

生成令牌和哈希。只把原始令牌交给对应协作者；部署环境只保存哈希。

```powershell
$token = [guid]::NewGuid().ToString('N')
$token
[Convert]::ToHexString([Security.Cryptography.SHA256]::HashData([Text.Encoding]::UTF8.GetBytes($token))).ToLower()
```

数据库账号必须没有 `INSERT`、`UPDATE`、`DELETE`、`CREATE`、`ALTER`、`DROP`、`INDEX` 或 `GRANT OPTION` 权限。优先连接只读副本。

仓库提供了创建当前最小权限账号的脚本。它默认读取 `MYSQL_URL`，也可用一次性的 `PREVIEW_ADMIN_DATABASE_URL` 覆盖；成功时只输出一次要填到部署平台的 `PREVIEW_DATABASE_URL`。账号已存在或任一授权失败时不会覆盖既有账号；若本次刚创建后续步骤失败，会尝试删除该账号。

```powershell
node scripts/materials/create-preview-reader.js --dry-run
node scripts/materials/create-preview-reader.js
```

## 协作者如何使用

协作者在 `frontend/.env.local` 写入个人配置。该文件受 Git 忽略；变量没有 `VITE_` 前缀，因此浏览器 bundle 不会得到令牌。

```dotenv
PREVIEW_GATEWAY_URL=https://your-production-api.example
PREVIEW_GATEWAY_TOKEN=<their-raw-token>
PREVIEW_GATEWAY_ORIGIN=http://localhost:5173
VITE_MATERIALS_PREVIEW_GATEWAY=1
```

启动 `npm run dev` 后，本地 Vite 会把 `/api/preview/*` 转发到网关，并在服务器侧加入令牌。`VITE_MATERIALS_PREVIEW_GATEWAY=1` 只公开一个本地功能开关，**不包含令牌**；它会让课程资料页面改用网关，并屏蔽上传、我的上传、管理、收藏与下载计数等写路径。预览请求会固定经当前 Vite 地址转发，即使协作者另设了 `VITE_API_BASE_URL` 也不会绕过本地代理。可先访问 `http://localhost:5173/api/preview/health` 验证，再读取：

- `GET /api/preview/materials/courses?q=数据&limit=50`
- `GET /api/preview/materials?courseId=7&type=notes&page=1&pageSize=30`

网关只提供固定的只读课程资料接口。它不接受 SQL、表名、列名或任意排序语句。

`PREVIEW_MATERIALS_BASE_URL` 留空时，资料元数据仍可浏览，但文件没有可用的下载或在线预览地址；因此协作者要预览文件本体时必须配置它。该地址指向原本就公开的资料 CDN，不是数据库连接信息。

## 如何撤销或回滚

删除 `PREVIEW_GATEWAY_TOKENS` 中该协作者的条目后重启服务，即可撤销其访问。删除三个预览变量并重启服务后，`/api/preview/*` 返回 404。回滚代码时也应先删除预览变量，避免旧路由留下意外访问面。

## 不在范围内

本版本不提供其它模块、写操作、生产迁移、用户隐私数据或通用数据库查询。新增模块必须增加固定 DTO 和固定参数化查询，并补访问控制测试。
