# 团队协作

本目录存放 Stage 2 协作规则副本。通用协作规则以 [`../../team/`](../../team/) 为主版本；本目录若与主版本不一致，先同步再分发任务。

## Stage 2 的 Agent 统一工作流

甲乙丙丁戊的 Agent 均使用 [`yejianqin61-cell/easy-workflow`](https://github.com/yejianqin61-cell/easy-workflow) 的技能集合。仓库当前 `main` 提交为 `2d501095d919d2e1960ae7caf860b8cafd6c7686`（2026-10-28 核对）；派发任务时记录实际安装提交，五人使用同一提交。成员自行安装并在开工汇报中写明版本。

- 需求拆阶段用 `easy-plan`；任务书与逐项执行用 `easy-task-act`。
- 未决事项用 `easy-registry`；阶段总结用 `easy-summary`；复核用 `easy-audit`。
- `easy-diagram` 和 `easy-report` 只在图或 HTML 报告能帮助审阅时调用。
- Agent 在任务汇报中写出所调用的 skill 名称、对应产物和验证结果。skill 约束不能替代 Stage 2 已裁决的产品与接口契约。

成员自行运行 `npx skills add yejianqin61-cell/easy-workflow -g -y`，并在首次任务汇报中列出已安装的 skill 与仓库提交。该仓库 `README.zh-CN.md` 目前仍使用旧仓库名 `easy-output`，派发时以本节的 `easy-workflow` 仓库地址和实际提交为准。若仓库 `main` 已更新，团队先统一新提交再开始下一批任务。
