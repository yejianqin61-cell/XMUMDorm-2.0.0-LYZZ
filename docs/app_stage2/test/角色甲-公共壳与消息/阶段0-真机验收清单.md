# 阶段0 真机验收清单（给非实现者执行）

**构建**：`app-release.apk`（**尚未产出**，见[出包记录](阶段0-出包记录.md)；拿到后在此填：文件名 / SHA-256 / 构建时间）
**包名 / 版本**：`com.xmumdorm.app` · 1.0.0（versionCode 1）
**烘焙后端**：`https://xmumdorm-200-lyzz-production.up.railway.app`（**生产服务**，见 §1 红线）
**设备要求**（[验收矩阵](../Stage2验收矩阵.md)）：Android 13 / 14 / 15 各一台 + iOS 一台；Android **手势与三键各一台**。
**证据**：每条至少一张截图或一段录像；放 `docs/app_stage2/test/evidence/A2-xx/`（打码：真实账号、学号、聊天内容）。
**判定**：只填「通过 / 失败 / 未验证」，⛔ 不填「基本通过」；失败要写复现步骤与预期/实测差异。

## 1. 开测前（10 分钟）

| # | 动作 | 判定 |
|---|---|---|
| P-1 | 安装 APK（`adb install -r …` 或直接点开，需允许未知来源） | 安装成功、桌面图标可辨 |
| P-2 | 记录设备型号 / 系统版本 / 导航方式（手势 or 三键）/ 语言 / 深色浅色 / 字体缩放 | 填入每条证据抬头 |
| P-3 | 准备两个测试账号：买家号、卖家号（同一台设备可先登一个再切） | 两号都能登录 |
| P-4 | 打开系统「减少动态效果」（另开一轮正常动效） | 两轮都要测 |
| P-5 | **写数据红线**：标 `⚠️ 写数据` 的步骤会往**生产库**写（发布、私聊、点赞、报名、保存图片）。**未获团队领导书面同意前，只做标 `读` 的步骤** | 未授权就不做写操作，记「未验证」 |

## 2. A2-11 发布安全区（六张表单）

六张表单：万能墙 `/publish/wall`、树洞 `/publish/confession`、社团活动 `/publish/club-activity`、社团帖子 `/publish/club-post`、二手 `/publish/marketplace`、跑腿 `/publish/errand`。

| # | 步骤 | 预期 | 写数据 |
|---|---|---|---|
| A11-1 | 逐张打开六张表单（手势导航设备） | 标题不被状态栏压住；返回按钮可点；页面无横向溢出 | ⚠️ 打开不写数据 |
| A11-2 | 每张表单滚到最后一项输入，点它弹键盘 | 最后一项与底部提交按钮**同时可见可点**；底部没有双倍留白 | 读 |
| A11-3 | 键盘打开时点提交（空内容提交） | 有字段级错误提示，键盘不遮挡；错误文案说明原因与改法 | 读（提交失败不写） |
| A11-4 | 万能墙填正文 | 下方出现模板预览；清空后预览消失；其它五张表单**不出现**该预览 | ⚠️ 填字不提交 |
| A11-5 | 打开图片选择与图片预览（每张带图表单各一次） | 弹层顶部/底部不被状态栏与手势条压住；多图可横滑；关闭手势与返回不冲突 | 读 |
| A11-6 | 同一组步骤在三键导航设备重做 | 底部按钮不被系统导航栏压住 | 读 |
| A11-7 | 返回（有草稿时） | 有返回确认；确认后草稿按既有规则保留/清除，不静默丢 | 读 |

## 3. A2-12 消息与交易

| # | 步骤 | 预期 | 写数据 |
|---|---|---|---|
| A12-1 | 顶栏信箱 → 「互动」 | 每行能看出：发生了什么 / 来自谁或哪个内容 / 何时 / 点了去哪 | 读 |
| A12-2 | 点一条帖子互动通知 | 进入对应内容；返回后列表仍在原分类、原位置 | 读（会自动标已读） |
| A12-3 | 点一条评论回复通知 | 进入那条评论所在内容并**定位到该评论**；没有评论定位的旧通知退化为进入内容 | 读 |
| A12-4 | 找一条「内容不可查看」的失效通知 | 行内给说明、不跳转；点了只标已读，不 404 | 读 |
| A12-5 | 切到「交易」分类 | **只出现会话**（商品名 / 对方 / 最新消息 / 未读），**不出现通知行**；页面上**没有**「全部已读 / 清空」按钮 | 读 |
| A12-6 | 点一条会话 | 进入私信；发出/收到消息正常；返回交易分类，**会话行未读数**按会话维度变化 | ⚠️ 发消息 |
| A12-7 | 双账号：卖家号看卖出的会话、买家号看买到的会话 | 两侧都能看到同一线程且商品对应；对方名字正确 | ⚠️ 发消息 |
| A12-8 | 角标核对（**两条来源，不要互相对等**） | ① 交易分类**角标数字** = 未读私信**通知条数**（来自 `unread-summary`）；② 会话行未读 = 会话维度（来自 threads）。两者不等是契约设计，**不是缺陷** | 读 |
| A12-9 | 读一条私信会话后回顶栏看角标 | 按 D-4/R-14：服务端未回标通知，角标**可能仍亮** → 记为已知缺口（归丁），不算本轮失败项 | 读 |
| A12-10 | 找一条活动报名/提醒通知 | 出现在「系统」分类；「交易」分类里没有它 | 读 |
| A12-11 | 顶栏信箱按钮在四个一级 Tab 都可见 | 未读数一致；非登录态不显示假 0 | 读 |
