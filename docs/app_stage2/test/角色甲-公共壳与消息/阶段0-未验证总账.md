## 5. 建议顺序

1. **先出一条可侧载包**（M-1）：容器构建（不 push）或团队领导授权 push 后用现成工作流。没有包，下面全部动不了。
2. 拿到包后按 A2-01 / A2-02（启动与手势最贵、最容易暴露阻塞）→ A2-11（六表单逐页）→ A2-12 / A2-13 → 阶段 A/B/C 接线项（M-8…M-12）的顺序验。
3. **不卡真机的三条**（C-1…C-3）随时可补，建议在等包期间做掉。
4. 他人项里只有 **O-1（丁回标）** 卡 A2-12 的通过线；其余是缺口登记，不阻塞本轮。
5. 写数据的验收步骤（发布、私聊、保存图片）需团队领导书面同意，或改在隔离后端做（见清单 §1 P-5）。
