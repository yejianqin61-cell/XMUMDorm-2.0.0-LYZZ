## 4. 仍未验证（如实）

1. **真机三种滚动**（慢滚 / 甩动 / 横滑）与录像：无设备，按指示统一验收。
2. **每帧改外层高度是否抖动**：本机只有测试渲染器；已在阶段4-01 结论 §6 登记。
3. **安卓到顶的 `onScrollEndDrag` 实际值**：方案按 RN 语义推导，未经真机确认。
4. **横滑切 Tab 与系统边缘返回手势是否冲突**：`directionalLockEnabled` 之外的参数未调。
5. **减少动态效果系统开关**：实现本身无动画（跟随手指/瞬时到位），但"无抖动"仍需真机看。
6. **挖孔/灵动岛机型上 Tab 条位置**：结构上由 `Screen` header inset 保证，未真机截图。
7. **今日 / 树洞 / 万能墙 / 食堂 的上报**：各需一行，属【搁置·待团队领导统一】；**当前只有跑腿 Tab 会收起**，其余四个 Tab 上部常驻（＝改造前行为）。
