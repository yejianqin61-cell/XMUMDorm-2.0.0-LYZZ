## 2. 配置真实进入原生工程（不是"写了就以为生效"）

**插件解析（`expo config --type introspect`）**

- `android.colors.resources.color`：`splashscreen_background = #f7f8fa`。
- `android.colorsNight.resources.color`：`splashscreen_background = #12141a`。
- `android.styles`：`Theme.App.SplashScreen` 的 `windowSplashScreenBackground = @color/splashscreen_background`、`windowSplashScreenAnimatedIcon = @drawable/splashscreen_logo`、`android:windowSplashScreenBehavior = icon_preferred`。
- `ios.infoPlist.UILaunchStoryboardName = SplashScreen`；iOS 启动底色由插件的 colorset（亮/暗两套）提供。

**生成物核对（`expo prebuild --platform android --no-install` 之后）**

```
res/drawable-{m,h,xh,xxh,xxxh}dpi/splashscreen_logo.png   ← 五个密度齐全，styles 里的 @drawable 引用可解析
res/values/colors.xml        <color name="splashscreen_background">#f7f8fa</color>
res/values-night/colors.xml  <color name="splashscreen_background">#12141a</color>
res/values/styles.xml        Theme.App.SplashScreen -> windowSplashScreenBackground / windowSplashScreenAnimatedIcon
```

**一处实现发现（写进提交正文）**：任务书原计划"只配底色、不配图"，但插件在**没有 `image` 时不会写出 `splashscreen_logo`**，而 `styles.xml` 固定引用它 —— 缺 `image` 会导致资源缺失。故改用 `assets/android-icon-foreground.png`（透明前景层，领导已确认自适应图标为正式素材的一部分），`imageWidth: 256`（该图形在 512 画布中约占 46%，256dp 下图形约 117dp）。⛔ 没有用 `splash-icon.png`（模板网格占位图）。

真机（必须 build 包，Expo Go / 开发构建不算）：
1. 冷启动：图标→启动底色的过渡里不出现白屏/闪屏；收起后有内容（或应用内 `SessionSplash`）。
2. 热启动：从后台回前台不出现空白帧。
3. 深链：`xmumdorm://` 打开后直接落到目标页，不闪登录页。
4. 系统设置里打开「减少动态效果」，再冷启动：启动画面不淡出、直接进首屏。
5. 暗色系统下重复第 1 条，确认启动底色为 `#12141a`。
