## 4. 数据契约

### 课程测评（已存在，甲直接复用）

客户端封装在 `shared/api/handbook.js:132-172`：

- `listCourseReviews({ q, tags, page, pageSize })` → `GET /api/handbook/course-reviews`
- `getCourseReviewDetail(id)` → `GET /api/handbook/course-reviews/:id`
- `createCourseReview(body)`、`updateCourseReview(id, body)`、`deleteCourseReview(id)`
- `rateCourseReview(id, rating)`
- `listCourseReviewComments(id)`、`createCourseReviewComment(id, body)`、`deleteCourseReviewComment(reviewId, commentId)`
- `getMyCourseReviews({ tags, page, pageSize })`

列表返回（`routes/handbook.js:1114-1132`）：

```text
id, courseName, teacher, tags[], rating, difficulty, comment,
created_at, term, term_year, term_month, author: null,
stats: { comments, avgRating, ratingCount }
```

要点：

- 课程测评**匿名**，公开接口不返回作者；详情只额外给 `viewer.isOwner` 用于显示编辑按钮。
- 标签白名单固定：`MPU`、`GE`、`ME`、`required`、`final`、`no final`。
- 列表用 `hasMore` 判断翻页，`pageSize` 上限 30。

### 社团动态流（本次改动）

`GET /api/clubs/feed?page=&pageSize=&clubId=`，客户端 `getClubFeed`（`shared/api/clubs.js:17`）：

```text
data: { list, page, pageSize, hasMore }
list[i]: { type: 'activity' | 'post', id, cover, title, summary,
           clubId, clubName, clubCategory, createdAt,
           stats: { likes, views }, viewer: { liked } }
```

变更点（`routes/clubs.js:1109-1210`）：

- 两类各取 `offset + pageSize` 前缀再合并切页，翻页连续。
- 新增 `clubId`，非正整数返回 400。
- 新增 `hasMore`。

### 攻略

沿用 `shared/api/handbook.js` 的文章接口；`handbook_article` 通知的目标 ID 即文章 ID。

## 5. 管理入口与权限

课程测评管理走既有管理端点，戊已修复字段与软删恢复（提交 `23645177`）：

| 端点 | 用途 | 说明 |
| --- | --- | --- |
| `GET /api/admin/contents/course-review?includeDeleted=1` | 审核列表 | 默认只看未删除；带参数可找回已删记录 |
| `GET /api/admin/contents/course-review/:id` | 详情（含评论） | 可打开已软删记录 |
| `PATCH /api/admin/contents/course-review/:id/toggle-visibility` | 隐藏 / 恢复 | `{ hidden: true/false }` |
| `DELETE /api/admin/contents/course-review/:id` | 删除 | 软删，可从列表恢复 |

返回字段：`id`、`title`（=课程名）、`teacher`、`rating`、`difficulty`、`username`、`created_at`、`deleted_at`、`content`（=测评正文）。

权限：这些端点需要管理员 token；App 端不能用「隐藏按钮」代替服务端鉴权。

## 6. 失败状态约定

| 状态 | 展示 |
| --- | --- |
| 401 | 登录恢复入口 |
| 403 | 无权限 |
| 404 | 内容不存在或已失效 |
| 409 | 具体冲突（如已评分） |
| 断网 | 保留当前内容 + 重试 |
