日期：2026-10-29　阶段：阶段一 买家能联系卖家并返回商品

## 交付内容

阶段一已提供服务端线程授权和商品摘要契约。`ChatScreen.tsx` 仍有一段旧的首批会话列表预检，不能用列表缺页判断线程不存在。

## 接线约定

- 深链进入线程时直接调用 `getMarketplaceThreadMessages(threadId)`。
- 以消息端点的 `200` 作为进入依据。
- `403` 显示无权限状态，`404` 显示线程不存在状态。
- 网络失败保留线程参数并提供重试，不清空草稿或伪造成功。
- 删除“线程必须存在于 `listMyChatThreads()` 首批结果”的前置拒绝。

## 服务端事实

- 消息端点会校验卖家、买家或管理员身份。
- 返回 `thread` 含 `item_id`、`item_title`、双方用户 ID 和已读时间。
- 商品已删除时，历史线程仍由服务端参与者校验决定是否可读。
