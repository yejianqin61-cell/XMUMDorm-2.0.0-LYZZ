# 阶段五任务 02：完整自动验证

日期：2026-10-29　阶段：阶段五 收齐自动验证和设备证据

## 1. 任务位置

- 阶段目标：服务端、App、lint 和差异检查有可复现结果。
- 本任务：运行阶段一至四针对性自动验证。
- 边界：不因 warning 伪造错误，也不忽略真实失败。
- 前置：阶段代码提交完整。后置：状态记录。

## 2. 开发信息

**先读**

- `app/package.json` — App 验证脚本。
- `package.json` — 根测试和路由脚本。
- `docs/app_stage2/summary/角色丁-阶段四-debug记录.md` — 上次验证基线。

**已定**

- lint 以 errors 为阻断，warnings 记录基线。
- 根脚本和 App 脚本在各自目录运行。
- 失败命令和退出码必须保留。

**边界与接口**

- 触及验证记录，不改业务代码。
- 不运行生产迁移。

**运行**

- `npm run verify:serial`（在 `app/`）
- `npm run lint`（在 `app/`）

**未知**

- 全量验证可能暴露与本阶段无关的既有 warning，按基线区分。

## 3. 工作步骤

1. 阅读本任务并重述：验证结果能区分错误和既有 warning。
2. 运行根服务端针对性测试。
3. 运行 App verify、lint 和 typecheck。
4. 运行路由与 diff 检查。
5. 记录退出码和未验证项。
6. 提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 证据 |
| --- | --- | --- | --- |
| 1 | 服务端测试 | 退出 0 | 命令日志 |
| 2 | App verify | 退出 0 或记录失败 | 命令日志 |
| 3 | lint | 0 errors | 命令日志 |
| 4 | 路由检查 | 退出 0 | 命令日志 |
| 5 | diff 检查 | 无空白错误 | 命令日志 |
