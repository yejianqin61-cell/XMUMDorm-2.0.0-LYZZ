# 阶段二任务 02：字段回填与提交锁

日期：2026-10-29　阶段：阶段二 卖家能发布并管理自己的商品

## 1. 任务位置

- 阶段目标：编辑和发布失败时，用户不会丢失已填内容。
- 本任务：校验字段回填、分类失效、重复提交和错误保留。
- 边界：只改表单描述或纯规则测试；页面接线交甲。
- 前置：任务 01。后置：任务 03 状态动作。

## 2. 开发信息

**先读**

- `app/src/features/marketplace/publishFields.ts` — 字段描述、限制和提交函数。
- `app/src/features/publish/resolveDescriptor.tsx` — 远程分类和表单装配。
- `app/src/i18n/zh.ts` — 中文错误词条来源。

**已定**

- 标题 120 字，描述 3000 字，图片最多 4 张。
- 分类必须来自服务端有效选项。
- 提交中必须锁住动作，失败后解除并保留输入。

**边界与接口**

- 触及发布字段和表单纯规则测试。
- 不新增图片编辑接口。

**运行**

- `npm test -- --runInBand app/src/__tests__/*publish*`
- `npm run typecheck`（在 `app/`）

**未知**

- 若现有公共表单无法区分编辑和发布语义，交甲确认后再改。

## 3. 工作步骤

1. 阅读本任务并重述：错误不会清空输入，重复提交被锁住。
2. 对照字段描述和服务端限制列出边界。
3. 先写失败测试覆盖分类失效和提交锁。
4. 修复纯规则或请求状态。
5. 回归成功发布和失败恢复。
6. 运行命令并提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接口 |
| --- | --- | --- | --- |
| 1 | 分类不在远程列表 | 阻止提交 | 表单 |
| 2 | 标题超过 120 字 | 明确错误 | 表单 |
| 3 | 发送中再次点击 | 只发一次 | 表单 |
| 4 | 服务端失败 | 输入仍在 | 表单 |
| 5 | 分类加载失败 | 可重试 | 表单 |
