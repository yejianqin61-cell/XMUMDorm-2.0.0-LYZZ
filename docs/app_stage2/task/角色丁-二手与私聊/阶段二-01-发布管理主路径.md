# 阶段二任务 01：发布管理主路径

日期：2026-10-29　阶段：阶段二 卖家能发布并管理自己的商品

## 1. 任务位置

- 阶段目标：本人发布商品，编辑文本，返回列表看到真实结果。
- 本任务：固定发布、详情、本人列表、编辑保存的服务端主路径。
- 边界：只覆盖已有接口和测试夹具；页面入口交甲。
- 前置：发布字段契约可用。后置：字段回填和状态动作。

## 2. 开发信息

**先读**

- `routes/marketplace.js` — 发布、详情、编辑和本人列表响应。
- `shared/api/marketplace.js` — 客户端调用参数。
- `app/src/features/marketplace/publishFields.ts` — 表单字段和提交门禁。

**已定**

- 发布必须通过条款和账号门禁。
- 编辑只修改现有文本字段和商品元数据。
- 图片编辑不在本任务。

**边界与接口**

- 触及 marketplace 路由、API 契约测试和领域适配。
- 不修改甲负责的个人页和编辑路由 UI。

**运行**

- `npm test -- --runInBand __tests__/routes/marketplace*`
- `npx tsc --noEmit`（在 `app/`）

**未知**

- 若测试库无法提供上传对象，停止在文本主路径并记录图片阻塞。

## 3. 工作步骤

1. 阅读本任务并重述：发布后编辑结果能回到列表。
2. 找到现有发布和编辑测试夹具。
3. 写主路径失败测试。
4. 修复最小接口或适配缺口。
5. 回归详情和本人列表响应。
6. 运行命令并提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接口 |
| --- | --- | --- | --- |
| 1 | 合法发布 | 返回商品 ID | 发布 |
| 2 | 查看刚发布商品 | 字段一致 | 详情 |
| 3 | 编辑标题描述 | 返回更新值 | 编辑 |
| 4 | 本人列表 | 商品出现一次 | 我的商品 |
| 5 | 他人编辑 | 返回无权限 | 编辑 |
