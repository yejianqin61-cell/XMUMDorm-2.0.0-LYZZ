# 任务 02：详情模型承接状态

日期：2026-10-29　阶段：阶段一 买家能联系卖家并返回商品

## 1. 任务位置

- 阶段目标：买家从商品详情进入咨询，并看见真实商品上下文。
- 本任务：扩展详情模型承接权限、配送和咨询状态。
- 边界：只改 marketplace 领域模型及其测试；等待 UI 接线。
- 前置：任务 01 样例通过。后置：任务 03 首发竞态处理。

## 2. 开发信息

**先读**

- `app/src/features/marketplace/model.ts` — 详情字段当前如何被丢弃。
- `app/src/features/marketplace/MarketScreens.tsx` — 详情操作区的消费方式。
- `routes/marketplace.js` — 详情响应字段和权限计算。
- `app/src/features/marketplace/publishFields.ts` — 配送与宿舍字段词汇。

**已定**

- 服务端权限字段优先。定义见 PRD D-R2。
- 不在本任务新增路由或改变图片编辑语义。
- 想要请求保留现有不确定状态处理。

**边界与接口**

- 触及 `model.ts` 和 marketplace 模型测试。
- 不修改 mailbox 页面或公共导航。

**运行**

- `npm test -- --runInBand app/src/features/marketplace`
- `npx tsc --noEmit`

**未知**

- 若服务端字段没有稳定类型，先以可选字段承接并记录来源。

## 3. 工作步骤

1. 阅读本任务并重述：详情模型不丢失咨询所需状态。
2. 对照真实详情响应列出保留字段。
3. 先写缺字段的模型解析测试。
4. 增加最小类型和归一化逻辑。
5. 回归想要和异常响应测试。
6. 运行命令并提交本任务。
