# 任务 05：会话授权预检

日期：2026-10-29　阶段：阶段一 买家能联系卖家并返回商品

## 1. 任务位置

- 阶段目标：旧线程可直接打开，不被不完整列表预检误拒。
- 本任务：替换首批会话列表授权预检，交甲接入服务端结果。
- 边界：只提交授权契约和适配补丁；页面归甲。
- 前置：任务 04 完成。后置：任务 06 权限和恢复验证。

## 2. 开发信息

**先读**

- `app/src/features/mailbox/ChatScreen.tsx` — 当前列表预检和拒绝分支。
- `app/src/shared/api/marketplace.js` — 线程查询、消息和读取接口。
- `routes/marketplace.js` — 服务端参与者权限判断。

**已定**

- 服务端授权结果是真源。定义见 PRD D-R7。
- 列表不完整不能证明线程不存在。
- 不扩大管理员权限，不修改公共通知来源。

**边界与接口**

- 丁提供 API/契约补丁；甲负责聊天页面合入。
- 不直接重构 `ChatScreen.tsx`。

**运行**

- `npm test -- --runInBand app/src/features/mailbox/p2b-06-chat*`
- `npx tsc --noEmit`

**未知**

- 若单线程查询无法区分不存在和无权限，先停在契约层。

## 3. 工作步骤

1. 阅读本任务并重述：列表缺页不再误判无权。
2. 记录现有拒绝分支和服务端错误码。
3. 写旧线程不在首批列表的失败测试。
4. 增加按线程查询的契约断言。
5. 形成交甲补丁说明和迁移注意事项。
