# 阶段二任务 05：列表筛选返回与缓存

日期：2026-10-29　阶段：阶段二 卖家能发布并管理自己的商品

## 1. 任务位置

- 阶段目标：发布和编辑后，列表筛选、分页和返回位置保持正确。
- 本任务：回归搜索、组合筛选、分页、详情返回和缓存失效。
- 边界：不重新设计列表布局或筛选词汇。
- 前置：任务 01、04。后置：任务 06 边界验证。

## 2. 开发信息

**先读**

- `app/src/features/marketplace/MarketScreens.tsx` — 列表筛选和详情返回逻辑。
- `app/src/shared/queryClient.ts` — 缓存失效约定。
- `shared/api/marketplace.js` — 列表参数。

**已定**

- 当前布局和已裁决筛选保持不变。
- 旧请求不能覆盖新筛选结果。
- 发布、编辑、状态变化后必须失效相关列表缓存。

**边界与接口**

- 触及 marketplace 页面纯规则测试和缓存契约。
- 不改导航骨架或公共返回组件。

**运行**

- `npm test -- --runInBand app/src/__tests__/*market*test.tsx`
- `npx tsc --noEmit`（在 `app/`）

**未知**

- 若返回位置依赖甲的导航状态，输出契约而不改导航实现。

## 3. 工作步骤

1. 阅读本任务并重述：筛选与返回不会被旧请求破坏。
2. 画出现有查询键和失效键。
3. 写竞争请求和组合筛选测试。
4. 修复最小缓存或页面状态缺口。
5. 回归详情返回和分页。
6. 运行命令并提交。
