# 任务 04：会话商品摘要

日期：2026-10-29　阶段：阶段一 买家能联系卖家并返回商品

## 1. 任务位置

- 阶段目标：会话列表和聊天页保留商品上下文。
- 本任务：接入卖家咨询列表及会话商品摘要字段。
- 边界：只提供领域数据和契约；页面改动交甲。
- 前置：任务 01、03 完成。后置：任务 05 授权预检。

## 2. 开发信息

**先读**

- `app/src/features/mailbox/conversations.ts` — 当前会话 DTO。
- `app/src/shared/api/marketplace.js` — 卖家线程和会话列表响应。
- `app/src/features/mailbox/chat.ts` — 消息与商品摘要归一化。

**已定**

- 会话行只代表聊天线程。定义见 PRD D-R6。
- 商品标题和可用状态来自服务端。
- 本任务不改变全局未读角标来源。

**边界与接口**

- 触及会话 DTO 和领域适配层。
- 不改 `ConversationsScreen.tsx` 的导航和布局。

**运行**

**未知**

## 3. 工作步骤

1. 阅读本任务并重述：会话 DTO 显示真实商品摘要。
2. 对照买家和卖家响应列出字段矩阵。
3. 写 DTO 归一化测试。
4. 增加可选字段和稳定默认值。
5. 回归未读和消息历史合并。
6. 写交甲契约并提交本任务。
