# 阶段二任务 03：状态动作与权限

日期：2026-10-29　阶段：阶段二 卖家能发布并管理自己的商品

## 1. 任务位置

- 阶段目标：状态动作有明确语义，并由服务端校验身份。
- 本任务：接入已确认的已售或下架动作，覆盖权限和刷新。
- 边界：不自行决定“下架”新状态；只实现现有契约。
- 前置：任务 01、产品确认状态语义。后置：任务 04 个人入口。

## 2. 开发信息

**先读**

- `routes/marketplace.js` — 状态端点允许的状态转换。
- `shared/api/marketplace.js` — 状态和删除调用。
- `migrations/026_marketplace.sql` — 数据库状态枚举。

**已定**

- 服务端身份校验是真源。
- 当前状态包括 `on_sale`、`sold`，删除是软删除。
- 未确认的独立下架状态不进入实现。

**边界与接口**

- 触及状态路由测试和客户端 API。
- 不修改公共个人区域的操作菜单。

**运行**

- `npm test -- --runInBand __tests__/routes/marketplace*`
- `npm run check:routes-cjs`

**未知**

- 若产品确认与数据库枚举冲突，停止代码改动并记录冲突。

## 3. 工作步骤

1. 阅读本任务并重述：状态动作只允许已确认转换。
2. 建立状态、身份和删除矩阵。
3. 写非法转换和他人操作测试。
4. 修复服务端或 API 适配缺口。
5. 验证详情和列表缓存刷新契约。
6. 运行命令并提交。
