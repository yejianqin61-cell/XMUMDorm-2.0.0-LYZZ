# 阶段二任务 06：边界、图片、长文与门禁

日期：2026-10-29　阶段：阶段二 卖家能发布并管理自己的商品

## 1. 任务位置

- 阶段目标：发布管理边界可验证，失败不丢数据。
- 本任务：回归图片数量、长文本、空态、权限和发布门禁。
- 边界：不实现未经批准的图片编辑。
- 前置：任务 01 至 05。后置：阶段二交甲和总结。

## 2. 开发信息

**先读**

- `app/src/features/marketplace/publishFields.ts` — 图片和文本边界。
- `routes/marketplace.js` — 上传过滤、条款和账号门禁。
- `docs/app_stage2/test/角色丁-二手与私聊/验收清单.md` — 验收记录格式。

**已定**

- 图片最多 4 张，每张 8MB，格式由服务端过滤。
- 未登录、未接受条款和受限账号不能发布。
- 设备未取得的证据保持未验证。

**边界与接口**

- 触及阶段二测试、证据记录和交甲文档。
- 不改生产数据、不迁移 schema、不改公共个人页。

**运行**

- `npm test -- --runInBand __tests__/routes/marketplace*`
- `npm run check:routes-cjs` 与 `git diff --check`

**未知**

- 若图片编辑需求再次出现，停止并新开决策，不借本任务扩范围。
