**已定**

- 进度 `p ∈ [0,1]`：**只在下滑时**按 `p = clamp(offsetY / H, 0, 1)` 更新；反向轻滚**冻结**（⛔ 不得减少）。
- 展开只有一条路：内容已在顶部 + 继续下拉（iOS 负偏移 `offsetY < 0` 直接展开；Android 用"到顶后整段手势 `offsetY` 保持 ≤0"的 `endDrag`）。
- 切 Tab：按目标 Tab 自己记录的 offset 重算 p，⛔ 不带动画、⛔ 不沿用上一个 Tab。
- 布局：外层 `height = H·(1-p)`＋`overflow:'hidden'`；内层固定 `H`、`translateY = -p·H`；未测量（`H=0`）时高度用自然值，避免首帧闪缩。
- pane 用 `React.memo`，⛔ 不许每帧重渲染 5 个 pane。
- 无上报的 Tab：p 恒 0（上部常驻＝现状），⛔ 不假装已收起。

**边界与接缝**

- 改 `SquareHome.tsx`；新增 `app/src/features/square/squareCollapse.ts`（纯函数：进度映射、布局换算、展开判定）。
- 不改 `Screen.tsx` / `TopTabStrip.tsx`（吸顶由 header 槽布局获得）。
