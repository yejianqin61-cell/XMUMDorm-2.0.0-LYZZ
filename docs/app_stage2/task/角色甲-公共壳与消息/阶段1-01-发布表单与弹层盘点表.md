## 6. 盘点结论（进入阶段1-02/03/04 的输入）

1. **A2-11 的真实缺口是两件**：① 顶部无标题（`Screen` 头没挂）；② 提交位在滚动内容里，键盘打开时最后一项与提交不能同时保证可触达。
2. **媒体弹层不是缺口**：发布链路用的是系统图片选择器，没有自绘弹层；日期字段是行内 picker。A2-11 的"预览/媒体选择弹层"盘点结果为**无自绘覆盖层**，不需要改 insets，但要在证据清单里写明这一点（避免下一个 Agent 再查一遍）。
3. **可改范围最小**：`Form`（可选提交位）+ `PublishFormHost`（启用 + 顶部标题）；覆盖层零改动。
4. **要防的回归**：`Form` 有 7 个生产消费文件（发布宿主、注册、找回密码、资料编辑、待办、食堂点评、菜品点评），默认行为必须不变。

## 8. 阶段1-04 复核结论（2026-10-29）

- **发布链路确实没有自绘弹层**：`PublishMedia` 只注入 `onPick`（系统 `ImagePicker`），预览是行内 `<Image>`；日期字段是行内 native picker。→ 原任务书用例 2（"媒体弹层拿 48 底部 inset"）**不成立**，等价证据改为覆盖层源码守卫。
- 已落成守卫用例 `app/src/__tests__/s2-03-publish-overlays.test.ts`（11 条）：
  1. 发布链路组件不自读 insets、不自绘 `Modal`；
  2. 7 个组件层覆盖层均不 import `react-native-safe-area-context` / 不用 `SafeAreaView`；
  3. 覆盖层无写死数值 padding（S1）；
  4. 只有 `Screen` 允许调用 `useSafeAreaInsets`。
