# 阶段B-05 · 我的想要（R-12）

## 1. 本任务的位置

- **阶段 B 二手页面接线**。本任务让用户在「我的」里看到自己"想要"的商品。
- **前置**：无。**后置**：无。

## 2. 开发者需要知道的

**先读**

- `app/src/features/me/ContentPanes.tsx:191-244` — 「我的」内容区的分页与四类数据源。
- `app/src/features/navigation/secondaryTabs.ts:66-71` — 「我的」四个内容 Tab 是**所有者 2026-10-18 的裁决**。
- `shared/api/marketplace.js:28-34` — `listMarketplaceMyWants({page,pageSize})`（**目前无调用方**）。
- `app/src/__tests__/p2a-03-secondary-tabs-config.test.tsx:43-51` — 钉死"四个 Tab"的用例。

**已定**

- **⛔ 不新增第五个内容 Tab**（会重开所有者的四模块裁决）。想要作为**二手面板内的分段**（我的商品 / 我的想要）接入。
- 分页沿用 `list`/`hasMore` 与既有 `useListPagination`；空态/失败/重试沿用既有四态组件。
- 想要的面板只读列表，点条目跳商品详情；取消想要在详情里做（不在列表里加动作）。

**边界与接缝**

- 只改「我的」内容区与词条；不改导航集合、不改二手列表页。
- 接缝：二手面板的段切换（渲染后切换，断言数据源换成了想要接口）。

**运行**

- `cd app && npx jest src/__tests__/s2-26-me-wants src/__tests__/p2c-07-me-content-panes src/__tests__/p2a-03-secondary-tabs-config --ci`
- `cd app && npm run typecheck`

**未知**

- 想要接口的行字段若与商品列表不同（缺价格/封面）：记降级为"标题+状态"，不猜价格。

## 3. 工作流

1. 读四个入口并一句话复述。
2. 写用例 1（二手面板出现两段；切到"想要"调用想要接口），红。
3. 接段切换与数据源，绿。
4. 补用例 2（空态）、用例 3（失败可重试）、用例 4（翻页去重）。
5. 跑三个用例文件 + typecheck，提交。
