**已定（本卡给定，不重新讨论）**

- 收起实现：**状态驱动的「外层裁剪高度 + 内层位移」**——外层 `height = H·(1-p)`、`overflow:'hidden'`，内层固定 `H`、`translateY = -p·H`。⛔ 不做动画高度（每帧重排不可控），⛔ 不加 `react-native-gesture-handler`。
- 手势 API：**只用滚动事件**（`onScroll` / `onScrollBeginDrag` / `onScrollEndDrag`）；⛔ 不加 `PanResponder`（会抢滚动），⛔ 不加新依赖。
- 吸顶：Tab 条移入 `Screen header` 槽、紧跟可收起块下方；不改 `Screen`/`TopTabStrip`。
- reduced-motion：实现不带动画（跟随手指、瞬时到位），天然满足"减少动态效果时瞬时到位"。

**边界与接缝**

- 只写文档（本卡），接缝名固定为 `SquarePaneScroll`。
- ⛔ 不写乙丙的屏幕文件。

**运行**

- 现状基线：`cd app && npx jest src/__tests__/p3a5-square-integration src/__tests__/p3a6-square-brand-header --ci`

**未知**

- Android 到顶不产生负偏移 → 本卡必须给出"下拉判定"的可行信号。若结论是"Android 上滚动事件无法区分"，如实写并把展开降级为"到顶后整段手势不移动、松手触发"，⛔ 不假装完成。
- 无设备：录像/截图与真机手感一律记【未验证】。
