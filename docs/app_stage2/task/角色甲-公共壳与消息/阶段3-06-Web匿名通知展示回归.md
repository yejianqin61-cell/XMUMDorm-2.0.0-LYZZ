1. 读四个入口，一句话复述：匿名通知到 Web 后只剩「没有作者」，展示必须给中性称呼。
2. 建 `mailboxDisplay.js`，把四个函数原样搬过去（不改逻辑）。

4. 写用例 1（中文匿名点赞 → 中性句），红 → 绿。
5. 写用例 2/3/4（英文、无标题、有名作者），红 → 绿。
6. 跑 `npm test` 目标用例 + `cd frontend && npm run build`，提交。
