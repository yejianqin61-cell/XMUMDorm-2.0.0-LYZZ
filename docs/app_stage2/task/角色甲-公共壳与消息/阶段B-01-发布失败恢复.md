# 阶段B-01 · 二手发布失败恢复（R-15）

## 1. 本任务的位置

- **阶段 B 二手页面接线**，目标是「双账号走通商品→私聊→回复→返回，卖家能改能标已售能翻页」。
- 本任务先证 **R-15 发布失败恢复**：提交中不重复提交、失败保留全部输入（含图片）。
- **前置**：无。**后置**：无（其余 B 卡并行）。

## 2. 开发者需要知道的

**先读**

- `app/src/features/publish/PublishFormHost.tsx` — 发布宿主如何装配表单与提交。
- `app/src/features/marketplace/publishFields.ts` — 二手字段、限制与提交函数（丁已交）。
- `app/src/components/ui/Form.tsx` — 提交状态机（submitting 防重入）与错误提示。
- `docs/app_stage2/task/角色丁-二手与私聊/阶段二-02-字段回填与提交锁.md` — 丁的验收口径（120/3000/4 张、失败保留）。

**已定**

- 不新增图片编辑接口；不重写表单状态机（提交锁只在既有 `Form` 一处）。
- 既有非发布表单（登录/注册/资料…）行为不变。
- 失败后**不清空**任何字段；成功后清空并回明确落点。

**边界与接缝**

- 若核心状态机已覆盖，本卡可能**只补用例**；要改也只改二手发布宿主/描述符。
- 接缝：既有发布表单组件渲染（填一版必填 → 提交失败 → 断言输入仍在）。

**运行**

- `cd app && npx jest src/__tests__/s2-22-market-publish-recovery --ci`
- `cd app && npm run typecheck`

**未知**

- `usePublishForm` 是否把图片字段单独存（若失败后图片被吞，要停并报告，不猜）。

## 3. 工作流

1. 读四个入口并一句话复述。
2. 用真实表单渲染二手发布，填标题/正文/价格/分类，提交一次失败。
3. 断言：服务端只被调用一次、输入全在、错误可见。
4. 提交中再点一次，断言不重复发送。
5. 成功路径断言清空并回落点。
6. 跑用例 + typecheck，提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接缝 |
|---|---|---|---|
| 1 | 提交中再点提交 | 只发一次 | 发布表单 |
| 2 | 服务端失败 | 标题/正文/价格/分类仍在 | 同上 |
| 3 | 失败后重试 | 同一份内容再次发出 | 同上 |
| 4 | 成功 | 清空并落回明确页面 | 同上 |
| 5 | 非二手发布类型 | 行为不变 | 同上 |
