# 阶段0-04 · 未验证总账与阶段收口

## 1. 本任务的位置

- **阶段 0 联测与出包**的收口卡：把阶段 A/B/C/D 四份证据清单里的「未验证 / 未达成 / 缺口」合并成**一张总账**，并给下一步一个明确顺序。
- **前置**：阶段0-01…0-03 全部提交。**后置**：批小结（easy-summary）→ 团队领导排真机。
- ⛔ 本任务不修任何缺陷、不下验收结论；只登记与排序。

## 3. 工作流

1. 读四个入口并一句话复述：只合并登记与排序。
2. 抄 A/B/C/D 四份材料里的全部未验证 / 未达成 / 缺口，去重。
3. 每条标出处、原因、负责人、是否卡真机。
4. 分三区：**真机才能验** / **他人未交付** / **领导已裁决不做**。
5. 给出建议顺序（哪几项在真机之前就能关）。
6. 写文档并提交。
