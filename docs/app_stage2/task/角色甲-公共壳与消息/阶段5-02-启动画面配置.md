# 阶段5-02 · 启动画面配置（SDK 57 官方方式）

## 1. 本任务的位置

- **Phase 5 启动一条线**第二卡：用 SDK 57 官方的 `expo-splash-screen` 配置插件，给冷启动一个**与首屏同底色**的原生启动画面 —— 消掉白屏/闪屏。
- 前置：5-01（现状清单）。后置：5-03（首屏衔接）、5-04（收口）。
- 回退：删 `plugins` 里的一项 + 卸载依赖，即回到现状（无启动画面配置）。

## 2. 开发者需要知道的

**先读**

- `app/app.json:14-32`（`plugins` 数组位置）、`:8`（`icon`）、`:40-45`（自适应图标）、`:9`（`userInterfaceStyle: automatic`，暗色变体才生效）。
- `https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/` — 配置字段只有这些：`backgroundColor`、`image`、`imageWidth`、`resizeMode`、`dark`、`android`、`ios`。
- `docs/app_stage2/task/角色甲-公共壳与消息/阶段5-01-启动现状取证.md` — 资源实测与原生工程形态（含「素材是占位图」的事实）。
- `tokens/design-tokens.css` — `--color-bg-canvas`：暗 `#12141a`、亮 `#f7f8fa`。

**已定**

- 依赖用 `npx expo install expo-splash-screen` 装（SDK 兼容版本由 Expo 解析，⛔ 不手写版本号）。
- **本轮只配底色，不配 `image`**：四张图标资源实测为 Expo 模板占位图（含构建网格），把占位图烤进构建会得到"网格启动图"；素材到位后再补 `image`（【搁置·等素材】）。Android 12+ 会在此底色上显示应用图标，与桌面图标同源，不额外造图。
- 亮色底 `#f7f8fa`、暗色底 `#12141a`，取自 `bg-canvas` 令牌；⛔ 不写与首屏不同的底色（那会在收起时闪一下）。
- 不改图标、不改自适应图标、不改 `userInterfaceStyle`。

**边界与接缝**

- 改 `app/app.json` + `app/package.json` / `app/package-lock.json`（依赖）。
- 不碰 `app/android/`、`app/ios/`（CNG 生成物，`app/.gitignore:41` 已忽略）。
- 接缝：`expo config` 的插件解析结果（配置是否真的进原生工程）。

**运行**

- `cd app && npx expo config --type introspect --json`（看插件解析后的原生资源改动）
- 失败则退回：`cd app && npm run prebuild:android` 后检查 `android/app/src/main/res/values/colors.xml`
- `cd app && npm run typecheck`

**未知**

- `expo config --type introspect` 若因缺原生依赖跑不起来：改走 prebuild（生成物被忽略，可接受），两条都失败就如实记【未验证】。
- 本机无 Android 12+ 真机 → 实际视觉一律【未验证】，⛔ 不写"已消除白屏"。

## 3. 工作流

1. 读四个入口，一句话复述：用官方插件把原生启动画面底色改成与首屏一致。
2. `npx expo install expo-splash-screen`，确认 `package.json` 出现该依赖且版本由 Expo 解析。
3. 在 `app.json` 的 `plugins` 里加 `["expo-splash-screen", { backgroundColor, dark: { backgroundColor } }]`。
4. 跑 `npx expo config --type introspect --json`（或 prebuild）确认底色进了原生资源。
5. 跑 `npm run typecheck` 与 `npm test -- src/__tests__/p0-01-scaffold`（`app.json` 被既有脚手架用例读过）。
6. 提交（配置 + 依赖一个意图）。
