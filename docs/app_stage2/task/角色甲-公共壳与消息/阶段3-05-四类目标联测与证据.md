## 3. 工作流

1. 读五个入口，用一句话复述本任务。
2. 写四类联调用例（帖子互动 / 评论回复 / 失效 / 二手私聊样例），红 → 绿。
3. 跑服务端通知用例与 App 信箱回归。
4. 写 `docs/app_stage2/test/角色甲-公共壳与消息/阶段3-05-证据清单.md`：四类情形、未验证项、复测步骤。
5. 写 `docs/app_stage2/summary/角色甲-阶段3-批小结.md`（用 easy-summary）。
6. 跑 `verify:serial` 记录退出码，提交。
