# 阶段3-04 · 消息行摘要、失效说明与聚焦刷新

## 1. 本任务的位置

- **Phase 3 消息一条线**，目标是「行内有来源与被回复内容或占位；失效内容不留原文；重新聚焦刷新」。
- **本任务把 J2-3/J2-5 的成果接到界面上**：摘要行、失效说明、聚焦重取。
- **前置**：阶段3-01/02（服务端字段）、阶段3-03（映射函数）。**后置**：阶段3-05（联测与证据）。

## 2. 开发者需要知道的

**先读**

- `app/src/features/mailbox/notifications.ts` — 行模型归一化处（新增三个字段要在这里读出来）
- `app/src/features/mailbox/MailboxScreen.tsx:222-260` — `ListItem` 的 title/subtitle/meta 用法
- `app/src/features/mailbox/targets.ts` — 阶段3-03 的三档结果
- `app/src/components/ui/ListItem.tsx` — 行组件支持的槽位与 `variant` 语义
- `app/src/i18n/zh.ts` / `en.ts` — 新增词条要双字典同步

**已定**

- 摘要缺失时用「类型 + 标题」兜底，⛔ 不显示空白行。
- 失效目标行仍可标已读，但**不跳转**，行内说明"内容不可查看"。
- 重新聚焦时刷新第一页；⛔ 不做本地扣减，也不伪造成功。
- 匿名域不显示作者名（服务端已裁）。

**边界与接缝**

- 改 `features/mailbox/**` 与 `i18n/**`；不碰其他域的屏幕。
- 接缝：阶段3-01 的响应字段 + 阶段3-03 的映射函数；**不新增接缝**。

**运行**

- `cd app && npx jest src/__tests__/s2-10-mailbox-excerpts src/__tests__/p2b-04-mailbox --ci`
- `cd app && npx tsc --noEmit`

**未知**

- `MailboxScreen` 现在是"挂载即取"；改成聚焦取数后，既有用例可能需要补路由 mock（`useFocusEffect`）。若改不动，允许保留挂载取数 + 只在聚焦时补一次重取，并写进提交说明。

## 3. 工作流

1. 读五个入口，用一句话复述本任务。
2. 在行归一化里读出 `sourceExcerpt`/`replyExcerpt`/`targetCommentId`。
3. 写用例 1（有摘要 → 行里显示摘要而不是作者名），红 → 绿。
4. 写用例 2（两段摘要都缺 → 回退到类型/标题，不留空白），红 → 绿。
5. 写用例 3（失效目标 → 行内说明、点击不跳转但仍标已读），红 → 绿。
6. 加聚焦刷新（或按 brief 的未知项降级），写用例 4（聚焦后重取一次）。
7. 跑用例 + 既有信箱回归 + `tsc --noEmit`，提交。
