**已定**

- 参数名统一为 `comment`（甲侧契约；与甲已发出的 `?comment=` 一致）。
- 甲只做：路由读参 → 详情 props → 公共组件定向展开 + 目标标识；**滚动定位与加载失败状态归丙**（02 文档 :33）。
- 目标不存在或不在已加载节点里时：不展开、不报错，页面照常可读。

**边界与接缝**

- 改两条详情路由、`components/ui/CommentThread.tsx`（甲），并对丙的详情屏只加一个可选透传 prop（已获准的最小改动）。

**运行**

**未知**

## 3. 工作流

1. 读四个入口并一句话复述。
2. 写用例 1（目标是根评论 → 标出该条），红。
3. 在评论组件加 target 支持（展开所在组 + 标识），绿。
4. 写用例 2（目标是默认折叠的回复 → 组自动展开且该条标出），绿。
5. 加用例 3（目标不存在 → 不崩、不展开），绿。
6. 路由读 `comment` 并透传到详情；两条路由各加一条参数断言，绿。
7. 跑用例 + typecheck，提交。
