# 阶段A-01 · 图库原生依赖与配置（R-4）

## 1. 本任务的位置

- **阶段 A 校园内容一条线**，目标是「预览里能存图、发布页有模板预览、评论能定位」。
- 本任务把 **R-4 图库原生依赖与构建配置** 落地：让保存模块有真正的相册写入能力。
- **前置**：无。**后置**：A-02 适配器、A-04 路由注入。

## 2. 开发者需要知道的

**先读**

- `docs/app_stage2/task/丙/校园内容交甲接线材料/09-当前图片保存模块交付.md:26-70` — 用 `expo-media-library/legacy` 入口、writeOnly 权限、plugin 增量。
- `app/package.json` / `app/app.json` — 现有依赖与 plugins 位置。
- `docs/app/evaluation/App依赖准入登记.md` — 每个依赖必须有一行登记（`p1-02` 闸门）。
- `docs/app_stage2/task/角色甲-公共壳与消息/开发设计文档-甲-四角色接线整合.md:88-95` — R-4 的验收。

**已定**

- 用 `npx expo install expo-media-library` 装（版本由 SDK 解析），⛔ 不手写版本号。
- 权限只申请「仅保存」：`writeOnly` + 空 granularPermissions（依据 09 文档 :52-53）。
- 不改图标/启动画面配置；不碰丙的保存模块本体。

**边界与接缝**

- 只改 `app/package.json`、`app/package-lock.json`、`app/app.json`、准入登记文档。
- 接缝：既有依赖准入门禁 + `expo config --type introspect` 的权限解析结果。

**运行**

- `cd app && npx expo install expo-media-library`
- `cd app && npx expo config --type introspect --json`（看 iOS 用途说明与 Android 权限）
- `cd app && npx jest src/__tests__/p1-02-data-layer --ci`

**未知**

- `expo install` 可能自动把插件写进 `plugins`（`expo-image` 有过先例）：先看再补，避免重复项；若没有 `legacy` 入口就停下报告。

## 3. 工作流

1. 读四个入口并一句话复述。
2. 安装依赖，记录被装上的版本。
3. 在 `plugins` 合并丙给的增量（不覆盖其它插件），确认自动添加与否。
4. `expo config --type introspect` 核对权限与用途说明真的进了原生配置。
5. 在准入登记表补一行（版本/许可证/含原生/OTA/发布时间）。
6. 跑 `p1-02` + `typecheck`，提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接缝 |
|---|---|---|---|
| 1 | 装完依赖 | `package.json` 出现该包且版本由 Expo 解析 | 依赖清单 |

| 3 | 准入闸门 | `p1-02` 绿（没有未登记依赖） | 门禁用例 |
