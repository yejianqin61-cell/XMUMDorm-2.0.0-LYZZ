# 阶段0-03 · 真机验收清单（给非实现者执行）

## 1. 本任务的位置

- **阶段 0 联测与出包**：把 A/B/C/D 四阶段攒下的「真机未验证」写成**非实现者照着就能做**的清单。
- **前置**：阶段0-02 的 APK（构建号写进清单抬头）。**后置**：阶段0-04 总账引用本清单条目。
- 本任务**不做验收结论**：结论只能由拿设备的人填，⛔ 不预填「通过」。

## 2. 开发者需要知道的

**先读**

- `docs/app_stage2/test/Stage2验收矩阵.md:9-36,38-53,55-57` — 设备矩阵（Android 13/14/15 + iOS、手势/三键）、横向门槛、A2-xx 必测情形与证据模板。
- `docs/app_stage2/test/角色甲-公共壳与消息/阶段C-证据清单.md:38-43` — 通知点击/冷启动/课表定位三项待验。
- `docs/app_stage2/test/角色甲-公共壳与消息/阶段D-证据清单.md:41-47` — 分类切换、双账号会话未读、角标语义三项待验。
- `docs/app_stage2/summary/角色甲-阶段B-批小结.md` — B 阶段（旧线程深链、第二页、编辑入口、想要、已售、失败恢复）的真机口径。

**已定**

- 每条必须写：**前置数据与账号**、操作步骤、预期、判定方式、证据（截图/录像）、**是否写生产数据**。
- 写数据的步骤（发布、私聊、点赞、报名、保存图片）单独标 `⚠️ 写数据`，并注明「需团队领导授权，或改在隔离后端验证」；⛔ 不得为了取证在生产库造会话/商品。
- 角标一项按契约两条来源分别验：**分类角标 = 未读通知条数**、**会话行未读 = 会话维度**；⛔ 不要求两者相等。
- 无设备时清单照样交付，状态记 `❌ 未验证` 并写原因。

**边界与接缝**

- 只写 `docs/app_stage2/test/角色甲-公共壳与消息/阶段0-真机验收清单.md`；⛔ 不改乙/丙/丁/戊的验收表。
- 接缝：无代码；可检查物是清单条目与矩阵行的**一一对应**。

**运行**

- 无需命令；交付前用 `git diff --check` 与相对链接自检。

**未知**

- 设备是否可得、哪几台：由团队领导排期（D-7 未裁决）；清单先按矩阵要求列出，不缩水。

## 3. 工作流

1. 读四个入口并一句话复述：只写可执行清单，不下结论。
2. 从 A2-11 / A2-12 / A2-13 / A2-01 / A2-02 五组（甲主责）整理条目，每条对应矩阵行。
3. 从 A/B/C/D 证据清单抄出所有 `❌ 未验证`，逐条转成操作步骤（含双账号、冷启动、减少动态）。
4. 标注写数据风险项与替代方案（隔离后端）。
5. 抬头写清构建号/包名/后端地址/SHA-256（取自阶段0-02）。
6. 写文档并提交。
