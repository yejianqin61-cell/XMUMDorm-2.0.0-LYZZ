# 阶段A-03 · 保存词条入字典（R-5）

## 1. 本任务的位置

- **阶段 A 校园内容一条线**。本任务把保存动作需要的 5 条文案入中英字典，供 A-04 的注入使用。
- **前置**：无（可与 A-02 并行）。**后置**：A-04。

## 2. 开发者需要知道的

**先读**

- `docs/app_stage2/task/丙/校园内容交甲接线材料/09-当前图片保存模块交付.md:72-84` — 5 个候选键与中英文案。
- `app/src/i18n/zh.ts` / `app/src/i18n/en.ts` — 现有 `screen.campus.*` 键的排布。
- `app/src/i18n/` 的类型出口 — 键必须是字面量联合的一員。
- 既有词条门禁用例 — 中英同数、无内联三元的约束。

**已定**

- 键名与文案照 09 文档的候选表定稿（甲统一口径），不另起名。
- 失败动作复用既有 `action.retry`，不为保存再造一个动作词条。
- ⛔ 不改乙丙的键，不删既有键。

**边界与接缝**

- 只改两份字典（必要时改键类型出口）。接缝：既有词条门禁。

**运行**

- `cd app && npx jest src/__tests__/p0-03-i18n src/__tests__/p2d-01-i18n-gate --ci`
- `cd app && npm run typecheck`

**未知**

- 若门禁要求键按字母序或分组顺序，按现有文件的分组习惯插入。

## 3. 工作流

1. 读四个入口并一句话复述。
2. 在中文词典按现有分组补 5 键。
3. 在英文词典补同 5 键（同数同义）。
4. 若键类型是手写联合，同步补类型。
5. 跑词条门禁 + typecheck，提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接缝 |
|---|---|---|---|
| 1 | 中英两字典 | 新增 5 键两边都存在且同数 | 词条门禁 |
| 2 | 键值 | 无内联三元、无空串 | 同上 |
| 3 | 既有键 | 未被删除或改名 | 同上 |
