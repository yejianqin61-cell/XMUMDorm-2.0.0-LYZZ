## 2. 开发者需要知道的

**先读**

- `docs/app_stage2/task/丙/校园内容交甲接线材料/10-万能墙首模板与发布预览.md:15-18` — 期望在发布宿主内渲染预览。

- 只对万能墙生效，其它发布类型不出现预览。

- 不改发布成功/失败与门禁逻辑。

**边界与接缝**

- 改 `components/ui/Form.tsx`（加可选预览槽）与 `features/publish/PublishFormHost.tsx`（仅 wall 传）。

## 3. 工作流

1. 读五个入口并一句话复述。
2. 写用例 1（万能墙表单输入正文 → 出现模板预览），红。
3. 给表单骨架加可选预览槽（默认不渲染，既有表单零变化），绿。
4. 发布宿主仅在万能墙描述符下传入预览，绿。
5. 加用例 2（清空正文 → 预览消失）、用例 3（其它发布类型不出现），绿。
6. 跑用例 + typecheck，提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接缝 |

| 3 | 非万能墙发布类型 | 不出现预览 | 发布宿主 |
