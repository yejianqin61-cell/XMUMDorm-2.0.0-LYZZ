# 阶段3-03 · App 侧唯一目标映射函数

## 1. 本任务的位置

- **Phase 3 消息一条线**，目标是「点击通知进入对应内容；失效/未知目标给出可理解说明，⛔ 不猜 Web 路径」。
- **本任务把 J2-5 的映射收口**：一个纯函数负责"目标 → App 路由或说明"，页面里不再有第二处判断。
- **前置**：无（可与阶段3-01/02 并行）。**后置**：阶段3-04（行内展示与聚焦刷新）。

## 3. 工作流

1. 读四个入口，用一句话复述本任务。
2. 建 `targets.ts`：输入行/目标，输出 `{kind:'route', href}`、`{kind:'unavailable', reason}`、`{kind:'pending', reason}`。
3. 写用例 1（已存在路由的类型全部映射正确），红 → 绿。
4. 写用例 2（`available=false` → unavailable），红 → 绿。
5. 写用例 3（`campus_post`/`course_review` → pending），红 → 绿。
6. 让 `MailboxScreen` 改用它，源码断言页面里不再有第二处 `target.type` 判断。
7. 跑用例 + `tsc --noEmit`，提交。
