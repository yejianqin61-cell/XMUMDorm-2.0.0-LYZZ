# 阶段B-06 · 商品编辑入口（R-11）

## 1. 本任务的位置

- **阶段 B 二手页面接线**。本任务让卖家从详情进入编辑、回填已有字段并保存。
- **前置**：无。**后置**：无（金额最大的一卡，放最后）。

## 2. 开发者需要知道的

**先读**

- `app/src/features/marketplace/MarketScreens.tsx:113-148` — 详情屏（`canEdit` 已在 `model.ts:15` 解析）。
- `app/src/features/publish/PublishFormHost.tsx` 与 `app/src/features/marketplace/publishFields.ts` — 二手发布表单与描述符（丁已交，**编辑语义需另配**）。
- `shared/api/marketplace.js:36-47` — 详情与 `updateMarketplaceItem`（**目前无调用方**）。
- `app/src/app/market/[id].tsx` 与 `app/src/app/market/index.tsx` — 现有两条路由（无编辑路由）。

**已定**

- 编辑走**独立路由**（不动发布中心）；只有 `canEdit` 为真才显示入口。
- 回填字段与图片；提交失败保留输入；成功后回详情并显示新值。
- 图片沿用发布表单的既有媒体字段，⛔ 不新增图片编辑接口。

**边界与接缝**

- 新增编辑路由与编辑屏（甲域路由 + 复用丁的表单描述符）；不改服务端。
- 接缝：编辑路由的参数与 `updateMarketplaceItem` 调用（mock 断言回填与提交）。

**运行**

- `cd app && npx jest src/__tests__/s2-27-market-edit --ci`
- `cd app && npm run typecheck`

**未知**

- 若发布表单描述符无法承载"编辑（已有值 + 更新提交）"，停下报告，不硬改成第二条表单。

## 3. 工作流

1. 读五个入口并一句话复述。
2. 写用例 1（`canEdit` 真 → 详情出现编辑入口，仅卖家），红。
3. 加编辑路由与屏，回填详情数据，绿。
4. 写用例 2（提交调用更新接口并回详情）、用例 3（失败保留输入）、用例 4（买家不可进入）。
5. 跑用例 + typecheck，提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 接缝 |
|---|---|---|---|
| 1 | 卖家详情 | 出现编辑入口 | 详情屏 |

| 3 | 打开编辑 | 标题/正文/价格/分类/图片回填 | 编辑屏 |
| 4 | 保存失败 | 输入仍在、错误可见 | 编辑屏 |
