## 3. 工作步骤

1. 复述任务：登录返回后按当前账号重新确认详情与权限，关闭本次禁删缺口。
2. 记录基线，补四条恢复与旧响应行为测试，保存修复前失败。
3. 接入会话与聚焦，恢复取数期间关闭旧操作；取消登录保留恢复入口。
4. 处理失败重试、防重及迟到读/删回执，保留成功删除事实同步。
5. 跑专项、模块回归、完整验证及 lint，记录退出码和跳过项。
6. 测试与修复分别本地提交，easy-summary 交付；D-2、D-3 待复审，不关闭任务。

## 4. 测试用例

| 情形 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 同账号恢复 | 删除 401→登录成功→返回 | 新详情确认本人后，可再次确认删除 | 真实详情/会话/聚焦 |
| 换账号恢复 | 401→另一账号→返回 | 重新读取本人标记，他人无删除入口 | 同上 |
| 取消登录 | 401→取消→再次登录 | 无卡死/忙态，可继续恢复 | 同上 |
| 旧响应迟到 | 身份改变后旧读/删返回 | 不覆盖新权限、不错误导航/清新会话 | 同上 |
| 恢复失败与连点 | 在途重复聚焦/点击、401/403/404/断网 | 无重复有效请求；失败有适用恢复动作 | 同上 |
