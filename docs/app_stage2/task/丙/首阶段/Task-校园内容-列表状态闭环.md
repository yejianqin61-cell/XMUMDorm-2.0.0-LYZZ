## 3. 工作步骤

1. 重读第二部分，复述会话内状态目标与允许路径。
2. 在既有测试复现普通流、搜索、筛选的返回位置及追加行为，产出实际差异。
3. 仅修复已复现的模块快照或恢复问题，保留各 Tab 独立分页顺序。
4. 追踪登出/换号缓存清理，验证新账号不消费旧账号互动与本人标记。
5. 验证删除、发布及失效后列表刷新，网络失败仍保留可读内容及重试。
6. 运行验证并与甲联调顶部、刷新状态及吸顶返回；留存设备证据和未验证项。
7. 回写执行记录并显式暂存本任务文件，本地提交；阶段结尾调用 easy-summary 交协调 easy-audit。

## 4. 测试用例

| 情形 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 列表返回 | 第二页、选定筛选、打开详情返回 | 原筛选/位置/分页保留 | 列表状态/行为 |
| 搜索返回 | 非空搜索、滚动、详情返回 | 搜索结果与位置保留 | 列表状态/行为 |
| 双 Tab | 树洞与墙各自分页、切换 | 各自游标/页码不串用 | 列表状态/行为 |

| 删除与断网刷新 | 删除后返回；刷新失败 | 已删行消失；失败保留可读结果 | 列表/详情行为 |
