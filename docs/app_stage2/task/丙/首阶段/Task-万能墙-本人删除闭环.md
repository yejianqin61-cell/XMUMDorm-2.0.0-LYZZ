## 3. 工作步骤

1. 重读第二部分，用一句话复述任务及允许路径，输出开工记录。
2. 在既有行为测试加入布尔本人回执，先取得失败结果，不使用数字回执冒充真实契约。
3. 修正投影并验证他人不可删除，保留匿名字段白名单。
4. 复现成功删除后的已挂载列表，按实际结果同步快照与可见 rows。
5. 覆盖失败停留、重复点击与取消确认，给出成功前后状态证据。
6. 运行指定验证，留存设备证据与未验证项，提交甲所需词条清单。
7. 回写执行记录，只显式暂存本任务文件，本地提交；不推送。

## 4. 测试用例

| 情形 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 本人 | viewer_is_author=true | 出现删除；确认后仅一次请求 | 既有详情行为 |
| 他人 | viewer_is_author=false | 无本人删除；不暴露身份 | 既有详情行为 |
| 成功返回 | status=0、已挂载墙列表 | 返回后无已删帖，其他行保留 | 既有列表/详情行为 |
| 失败 | 401/403/404/断网 | 不假成功，有可理解下一步 | 既有详情行为 |
| 取消与连点 | 取消确认；删除中重复触发 | 取消无请求；执行期不重复删除 | 既有详情行为 |
