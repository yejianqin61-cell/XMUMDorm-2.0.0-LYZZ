# 按压变灰移除执行记录（2026-10-31）

## 1. 触发与现状

所有者 2026-10-31 提供两段对照截图：

- **信息流**：手指按到帖子卡片或缩略图时，整条卡片 / 全部图片瞬间变灰变暗；列表上下滑动会反复触发，一闪一闪，看起来像卡顿。
- **详情**：按住正文下方的轮播图，图片同样发灰（截图右边缘灰条）。

要求：**完全去掉"按下去变灰 / 变暗"的视觉反馈**，范围是信息流整条帖子卡片、信息流每张缩略图、详情正文下方轮播图、点图后的全屏看图器；同时**点击 / 跳转 / 翻页 / 打开大图 / 点赞评论一个都不能少**。

## 2. 原因

`A12 Pressable` 默认 `feedback="opacity"`：`pressed` 时给整块加 `opacity: 0.6`。
信息流里内容区与图组是同一层的两个 `Pressable`，按下即整块降透明度（白底透出来 = 发灰）；详情图区也是 `Pressable`，按住就整张图变淡。滑动浏览时手指刚落下就已进入 pressed，于是反复闪。
