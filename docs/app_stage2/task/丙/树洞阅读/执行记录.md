## 实现选择

先完成正文，再补媒体，最后验证列表到详情返回；未新增数据层、后端字段或公共框架。
现有 posts 接口只提供 URL；媒体复用稳定的 4:3 列表画框、16:9 详情画框，使用 contain 保留比例及原内容。
这是媒体区域比例，不是固定帖子高度。正文与操作在媒体之外，长文增加整行高度，不裁掉正文。
单图占正文列，多图两张等分同一列，第三张以既有总数徽标提示，进入详情可切全部图片。
加载用现有 Skeleton；失败用现有中英词条。feed 失败点击媒体仍进详情；详情重试后重新加载原 URL。
失败不阻断详情后续切图；没有新增 feed 手势或左右箭头，没有修改预览 Modal 宿主。
极长图完整缩入画框会缩小细节，可进入既有预览继续查看；细节可读性仍需设备评估。

API 核验：Expo ~57.0.26、expo-image ~57.0.5、React Native 0.86.3。
依据 [SDK 57 Image](https://docs.expo.dev/versions/v57.0.0/sdk/image/) 的 contain、onLoad/onError、recyclingKey。
布局依据 [React Native aspectRatio](https://reactnative.dev/docs/layout-props#aspectratio)。没有新增原生依赖或配置。
