## 1. 任务位置

- Phase 2 树洞可读并能保存当前图片；本批次只交自然高度阅读。
- 丙负责；自然正文完成后推进媒体，后继为返回验证。
- 复用详情叠卡与预览，不做图片保存及公共预览宿主改造。

## 2. 开发所需

**先读**
- `app/src/features/campus/TreeholeMedia.tsx` — feed 与详情的加载和切图在哪里？
- `app/src/__tests__/p2x-treehole-media.test.tsx` — 切图和读屏动作怎样验证？
- `app/src/features/campus/TreeholePostRow.tsx` — 媒体点击由谁处理？

**已定**：验收矩阵要求不拉伸、不遮挡操作；图片等比保留原内容。
**边界**：只允许前两文件；骨架与现有词条直接消费，feed 仍点进详情重试。
**运行**：app 下 `npm run test:ci -- --runInBand --testPathPattern=p2x-treehole-media --silent`；`npm run typecheck`。
**未知**：接口无宽高；保留稳定画框避免异步行高干扰保位，真机可读性另验。

## 3. 工作流

1. 读第二部分，重述等比可读媒体目标。
2. 写加载、失败及恢复行为断言，运行取得失败。
3. 单独提交测试。
4. 扩大内容列媒体，加入骨架和失败提示，详情保留重试。
5. 验证切图、读屏、无图与主题语言，类型检查后提交实现。

## 4. 用例

| 场景 | 输入 | 预期 | 接缝 |
| --- | --- | --- | --- |
| 无图 | 空 URL 列表 | 无媒体占位 | TreeholeMedia |
| 单图 | 加载到成功 | 骨架消失，图片等比完整显示 | feed/详情 |
| 多图 | 三个 URL | 前两图、总数；详情切到正确 URL | feed/详情 |
| 失败 | 首图失败、次图成功 | 失败仅影响当前图；仍可阅读其他图 | TreeholeMedia |
| 重试 | 失败后重试成功 | 原 URL 重载，失败提示消失 | 详情 |
