## 1. 任务位置

- Phase 2 树洞可读并能保存当前图片；本批次只交自然高度阅读。
- 丙负责；正文和媒体完成后验证阅读返回链路，结束本批次。
- 真实接口、设备、人类与甲广场接线分开记录。

## 2. 开发所需

**先读**
- `app/src/features/campus/TreeholeFeed.tsx` — 查询/分页/位置快照接缝是什么？
- `app/src/__tests__/p2x-bing-campus.test.tsx` — 既有返回与账号隔离怎样验证？
- `app/src/features/campus/CampusScreens.tsx` — 详情正文怎样组合？

**已定**：已复核刷新、账号隔离、删除不重写；列表查询和分页返回保持。
**边界**：只允许修改上列测试文件及丙文档；业务文件只读，发现回归另记具体最小修复。
**运行**：app 下专项 `npm run test:ci -- --runInBand --testPathPattern='p2x-bing-campus|p2x-treehole|p2x-bing-wall-publish' --silent`。
完整检查：`npm run verify:serial`，`npm run lint`；设备沿用无设备事实，不重复探测。
**未知**：Jest 不执行原生布局/系统返回；快照证据不等于真机保位录像。

## 3. 工作流

1. 读第二部分，重述长文多图返回原查询与位置目标。
2. 在现有返回测试接缝增加长文多图列表到真实详情组合验证。
3. 跑专项，确认查询、已加载页和偏移保持，提交测试。
4. 运行完整验证与 lint，记录原始结果和最终代码提交。
5. 补执行记录与交甲材料，easy-summary 五段式交付，停止待限定复核。

## 4. 用例

| 场景 | 输入 | 预期 | 接缝 |
