## 3. 工作流

1. 读第2节，复述为预览消费输入且提交沿用真实字段。
2. 添加预览切换保留正文及公告提交边界测试。
3. 实现预览，验证与阅读同组件且不发请求。
4. 完成针对性及最终完整验证，记录退出码。
5. 显式提交，安排固定差异只读独立审查。
6. 必要限定返工，更新执行记录与交甲材料。
7. 用easy-summary写五段交付并本地提交。
