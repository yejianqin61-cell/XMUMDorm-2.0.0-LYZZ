## 2. 字体核对（任务书 §七要求先查）

| 项 | 实测 |
| --- | --- |
| 自定义字体文件 | **0 个**（`app/assets` 无 ttf / otf / woff） |
| `fontFamily` 声明 | **0 处**（全仓 `app/src`） |
| `expo-font` | 依赖与 config plugin 存在，但**没有任何 `useFonts` 调用**（只有脚手架测试断言它被安装） |
| 令牌层约束 | `tokens/design-tokens.css` 明令「❌ 自有字体文件 / font-family 声明」；`scripts/gen-tokens.js` 对 `font-family` 直接 fatal |
| 实际字族 | 系统解析：Android = Roboto + Noto Sans CJK（中文回退），iOS = SF + PingFang SC；数字 / 标点 / Emoji 由系统兜底 |

**本轮决定**：继续使用系统无衬线字族，不引入字体包。设计感通过**字重（normal/bold）、现有 7 档字阶、对齐、行距、留白、底色**实现。
理由：① 令牌层与设计宪法的硬约束；② CJK 字体包体积大（数 MB 起），与「不必为体积引入大字体」冲突；③ 系统字体能保证中英 / Emoji / 数字断行稳定。
⚠️ 任务书允许「网上找可靠字体包」。若所有者希望给**英文短标题**加一款拉丁展示字体（约 50–120 KB，中文仍回退系统），需要一次令牌 / 宪法口径变更；本轮未擅自引入，登记为待决策。

## 4. 自动排版（§八）

`wallPosterLayout.ts` 全为纯函数，流程：**分析 → 硬约束过滤 → 评分 → 候选（有限随机）→ 渲染后实测复核**。

- **分析**：码点数、显示列宽（中文/Emoji 记 2，英文记 1）、段落数（空行分段）、硬换行、中英混排、Emoji、URL、最长不可断词。
- **硬约束**：长度区间、段落上限、长词上限。长文 / 多段 / 长 URL 不会进入 A / C / D；`plainEssay` 永远可兜底。
- **评分**：基础分 + 理想宽度契合 + 语种/Emoji/段落亲和 − 换行/长词扣分；全部参数写在模板配置里，⛔ 没有散落的 `if (id === …)`。
- **推荐确定性**：`recommendWallPoster(content)` 不含随机 → 同一段文字在信息流 / 详情 / 重开 App 得到同一模板（节点 B 写库前的稳定性保证）。
- **候选**：`generateWallPosterCandidates` 最多 3 个，按分数加权、无放回抽取；可用模板不足时返回 1–2 个，不硬凑；`exclude` 支持「换一批」优先换新。深蓝的抽样权重 ×0.55，避免信息流连续深色。
- **实测复核**：`WallPosterBody` 用原生 `onTextLayout` 取真实行数，超过模板容量按配置链回退（A/C/D → B → E），只换版式，⛔ 不缩字号、⛔ 不截断原文。
- **行数估算**：提供 `estimateWallPosterLines`（供测试 / 节点 B 预览初判），但它不参与截断决策。
