[服务端](../../../../../routes/posts.js)第 952–991、1001–1040 行。

[匿名投影](../../../../../routes/confessions.js)第 65–104、525–590 行。

摘要长度、清洗规则、父评论单独失效时的空值细节仍待甲确认，不在本包另立硬参数。

## 匿名与失效边界

| 项目 | 状态 | 边界与依据 |
| --- | --- | --- |
| 匿名墙服务端输出 | 已有且已核实 | confessions.js:65–104 白名单输出匿名名、布尔本人标记，不输出真实作者 |
| App 墙投影 | 已有且已核实 | campusModel.ts:60–74 丢身份/标题/图片；useCampusActions.tsx:75–95 评论固定匿名 |
| 树洞与校园此刻 | 已有且已核实 | posts.js:962–986、square.js:708–744 有具名作者，不能假称均匿名 |
| 删除、隐藏、失权 | 待甲确认或接线 | 【已定】D2-03 要 available=false、两段原文为空、类型加占位 |
| 旧摘要清除 | 待甲确认或接线 | 契约第 46–47 行要求聚焦刷新；不保留敏感原文快照 |
| 真实隐私/权限结果 | 未验证 | 未做双账号、存量通知及真实接口取证 |

App 证据：[campusModel](../../../../../app/src/features/campus/campusModel.ts)、
[评论投影](../../../../../app/src/features/campus/useCampusActions.tsx)。
当前通知组装仍返回 from_user_id/from_user，且未统一清理 extra.content；非标准 posts 的 available 直接为 true。
这属于甲通知投影待接线事实，不能把这个 true 当作 campus_post 当前有权且存在的证明。
未来若有匿名墙通知，真实发送者 ID、用户名、昵称、头像也不能因通用 from_user 投影而传播。
这只是隐私约束，不代表新增匿名墙通知接口获批。

## 脱敏构造样例

以下均为虚构测试夹具，非线上响应，未运行甲的测试。
`source_excerpt/reply_to_excerpt/target.comment_id` 按统一契约表达预期；尚未上线。

| 情形 | 构造输入 | 预期与状态 |
| --- | --- | --- |
| 正常回复 | post=42，新评论301，parent=300；来源“校园话题”，300“原评论”，301“新回复” | 待甲确认或接线：post目标；两摘要分别取来源/300，定位301 |
| 一级评论 | post=42，comment=302，parent=null | 待甲确认或接线：原评论摘要为空，不拿302新内容充当原文 |
| 评论缺失 | post42可读，301已删 | 丙后续需实现：文章仍可读，说明评论不可查看，不定位邻条 |
| 来源软删/隐藏 | post42不可读，extra.content仍含旧片段 | 待甲确认或接线：available=false，两摘要为空，旧片段不展示 |
| 先可见后失权 | 已显示来源，详情403 | 待甲确认或接线：刷新投影、清旧原文、无权限占位 |
| 父评论缺失 | post42与301可读，parent300已删 | 待甲确认或接线：【提案】原评论摘要空，保留来源与301定位机会 |
| 跨域同ID | post42、campus_post42、confession42 | 待甲确认或接线：按实体选择数据；后两者不冒充post |
| 无原生落点 | type=campus_post，id=42，path=/about/campus/42 | 待甲确认或接线：不可跳转，不能跳墙42 |
| 匿名注入 | 墙行/评论携带虚构user_id=9001、nickname=“测试身份” | 已有且已核实：本地投影丢身份；真实接口效果未验证 |

正常样例的拟投影结构如下；不代表当前 GET /api/notifications 的真实输出。

```json
{
  "type": "treehole_comment", "post_id": 42, "comment_id": 301,
  "extra": {"content": "新回复"},
  "source_excerpt": "校园话题", "reply_to_excerpt": "原评论",
  "target": {"type": "post", "id": 42, "available": true, "comment_id": 301}
}
```

未验证：上述构造样例的服务端投影、通知展示、跳转及清旧摘要全链路。
