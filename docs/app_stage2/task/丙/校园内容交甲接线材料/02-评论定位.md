## 接线提案，尚未协商

【提案】甲在既有 post 路由读取可选评论 ID，传给丙详情；参数名可候选 `commentId`，未确认为契约。
路由仍由甲维护，本包不创建或猜测新路由；墙无通知生产链，不据此增加通知目标类型。
target.comment_id 已在统一契约提出，URL 参数名与组件 props 是两个独立的待确认接口。

【提案】模块等待文章及评论加载，按实体与内容 ID 找目标；若是回复先展开根组，再测量滚动和短暂标识。
甲确认公共 CommentThread 的定向展开/布局能力及命名；丙后续接入详情定位与错误展示。
定位状态按实体、内容、账号和目标评论约束，避免旧异步结果滚动到新页；具体状态实现待施工时确认。
