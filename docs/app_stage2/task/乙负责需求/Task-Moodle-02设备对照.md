## 1. 任务位置

- 阶段 1 Moodle 登录原因可辨：解释问题设备的失败。
- 本任务推进 R-1 Moodle 登录与工作台；依赖主链路记录，结果供错误状态处理使用。

**已定**：不能关闭 TLS 校验；历史记录不能代替本次复现。
**边界与入口**：现有登录入口、系统浏览器和设备日志；不改校方服务。
**运行**：在 app 执行 `npm test -- --runInBand p3y3-moodle-host.test.tsx`，再执行 `npm run typecheck`。
**未知**：无问题机或正常机时记录缺口；不得臆测证书根因。

## 3. 工作流程

1. 阅读上述入口并复述目标。
2. 记录两台设备及各自网络和 WebView 版本。
3. 对照应用内登录与系统浏览器。
4. 记录错误码和脱敏日志。
5. 区分观察事实与待校方确认的原因。
6. 复核证据并按团队规范提交。
