# 课前通知任务 01主链路：贯通首次授权、课程排程、通知送达和点击定位

## 1. 任务位置

- 阶段 2 课前通知可送达并定位课程，推进 R-2 课前通知与权限。
- 本任务：贯通首次授权、课程排程、通知送达和点击定位。前置：阅读阶段计划；交付供后续任务和验收使用。

## 2. 开发者须知

**先读**
- `docs/app_stage2/task/乙负责需求/Task-乙-第二轮需求实施计划.md`：阶段目标与边界是什么？
- `docs/app_stage2/requirements/Stage2统一口径与接口契约.md`：提醒与交接契约是什么？
- `app/src/features/tools/TimetableScreen.tsx`：现有入口如何工作？
- `app/src/features/tools/reminders/native.ts`：提醒如何衔接系统调度？

**已定**：默认开启；提前 30 分钟提醒；首次进入课表触发权限流程。
**边界与入口**：课表、通知权限、提醒调度和点击目标；复用现有提醒计划、调度与权限入口。
**运行**：在 app 执行 `npm test -- --runInBand --silent reminder` 和 `npm run typecheck`。
**未知**：需甲接入公共导航；真机送达暂不验证。

## 3. 工作流程

1. 阅读上述入口并复述本任务。
2. 核对现有行为和前置条件。
3. 在既有入口验证预期行为。
4. 在负责范围内补齐缺口并记录交接。
5. 执行相关检查并记录未验证项。
6. 复核本任务改动并按团队规范提交。

## 4. 验证情形

| 情形 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 主要行为 | 有效课程及权限 | 首次授权能触发排程；通知携带稳定课程目标 | 现有提醒入口 |
| 失败状态 | 调度或权限不可用 | 如实反馈，不伪报成功 | 现有提醒入口 |
| 设备证据 | 当前无设备 | 标记未验证 | 验收记录 |
