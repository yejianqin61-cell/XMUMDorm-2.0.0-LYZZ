## 2. 这些变化意味着什么

工具首页与完整课表继续使用同一按周数据入口。
首页跨周一读取上一教学周的周日数据，跨学期数据不会混用。
自动测试不能代替设备截图和真实环境验证。

## 3. 尚未完成

- 冲突课程卡可能互相遮挡，网格交互仍需协调。
- 用户已确认跨周同课同色；不同课程可能共用颜色。该规则的真机显示尚未验证。
- 网格仍只显示周一至周五、08:00–21:00；窗口外课程的完整展示尚未覆盖。
- 下一节课仅在当天查找，未来日期的课程尚不会作为下一节显示。
- 当前没有真机截图和非实现者复核，阶段不能认定验收通过。
