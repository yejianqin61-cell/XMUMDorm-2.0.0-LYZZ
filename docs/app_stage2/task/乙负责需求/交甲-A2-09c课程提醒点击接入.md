# 交甲：A2-09c 课程提醒点击接入

日期：2026-10-30　状态：乙的解析与课程匹配已实现；公共导航待甲接入。

## 1. 可直接调用的模块

[reminders/navigation.ts](../../../../app/src/features/tools/reminders/navigation.ts) 导出：

- `resolveClassReminderTarget(data, currentOwner, semester)`：输入通知的 `content.data`、
  当前登录账号的 `user:<数字ID>` 和当前学期配置；返回 `ignored`、`unavailable` 或 `ready`。
- `ready.target` 只包含学期、课程码、学校日期、规范化开课时刻、周次及星期。
- `findClassReminderMeeting(week, target)`：在当前周数据中按课程码、星期和开课时刻匹配。
  返回唯一课程的副本；无结果、时间已改变、周次不符或存在多条匹配均返回 `null`。

## 2. 公共导航接入顺序

1. 使用现有通知点击适配读取载荷。未登录时走现有登录恢复流程。
2. 从当前会话和学期配置取得 owner 与 semester，再解析目标；不使用载荷提供的路由地址。
3. `ignored` 继续其他通知处理，避免吞掉 Moodle、消息等通知；`unavailable` 展示失效状态。
4. `ready` 后通过已登录接口重新获取目标周课表，不从旧缓存自动打开课程详情。
5. 请求完成后重新读取当前账号、学期并再次解析同一载荷，阻止等待期间换账号或换学期。
6. 核对响应的学期与周次；学期标识缺失或不符时仅回退课表，不自动进入详情。
7. 使用规范化的最新课表调用 `findClassReminderMeeting`。匹配成功后进入目标周并打开该课程；
   返回 null 时展示课程失效或普通课表，不替换成另一节课程。

词条和公共路由由甲统一接入。乙没有修改 `app/src/app/**` 或 `app/src/i18n/**`。
