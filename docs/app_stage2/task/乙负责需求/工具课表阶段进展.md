# 工具与课表阶段进展

日期：2026-10-28　状态：进行中

课表与工具首页共用按周数据入口。服务端返回的周次与请求不一致时，客户端不再展示或缓存错误周次；已有缓存仍可在失败时保留。

验证：在 `app/` 运行 `npm test -- --runInBand --silent p2y-a02-shared-timetable.test.tsx p3y2-timetable.test.tsx`，2 个套件、18 个用例通过；`npm run typecheck` 退出码 0。

完整验证曾因课程详情测试固定返回第 3 周而失败。测试模拟现已按请求周次返回，课表、课程详情与“我的”相关测试共 49 个用例通过。

最终在 `app/` 运行 `npm run verify:serial`，退出码 0；187 个套件、1900 个用例通过，2 个套件和 16 个用例跳过，设计检查通过。

未验证：设备截图、跨午夜和冲突课程的真实设备行为，以及其他阶段验收情形。

跨午夜课程在开课当日和次日可被识别为当前课程。首页会在周一读取上一教学周的周日课程；跨学期数据不混用。模拟测试覆盖周日晚课程在周一凌晨继续上课及结束边界。

冲突课程按实际显示高度分列，课程列随冲突数量扩展，支持横向滚动；每门课可分别进入详情。自动测试覆盖两门课程重叠和独立点击，真实设备仍需验收。

2026-10-28 用户确认课程色优先跨周同课同色；不同课程可能共用六色色板中的颜色。课程身份键稳定映射到色板，不依赖当周其他课程。
配色调整后重跑 `npm run verify:serial`，退出码 0；187 个套件、1900 个用例通过，2 个套件和 16 个用例跳过。

课表网格在有周末或窗口外课程时扩展日期和时间轴；跨午夜课程会在次日续显，包括前一周的周日跨到周一。设备截图仍未取得。

当天没有后续课程时，首页继续按教学周查找本学期内下一节课，并显示日期与时间。查询失败时提供重试；跨周和失败恢复已有自动测试，真实设备与网络条件尚未验证。
后续周逐周请求，最坏情况下需查询至学期末；无课周较多或弱网时可能较慢。

2026-10-29 最终验证：在 `app/` 运行 `npm run verify:serial`，退出码 0；187 个套件、1907 个用例通过，2 个套件和 16 个用例跳过，设计检查通过。设备验收按用户要求暂缓。
