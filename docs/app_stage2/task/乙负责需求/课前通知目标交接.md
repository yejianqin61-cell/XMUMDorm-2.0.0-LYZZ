# 课前通知目标交接

日期：2026-10-28　状态：目标载荷已实现，导航待甲接入

课程通知的 `content.data` 保留现有 `dormReminder`、`owner`、`domain` 字段，并为课程提醒添加 `target`：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `semesterId` | 学期标识 | `2026-09` |
| `courseCode` | 课程码 | `CS101` |
| `date` | 学校当地日期 | `2026-09-28` |
| `startTime` | 学校当地开课时刻 | `09:00:00` |

日期和时间按学校时区生成。载荷不包含讲师、地点或学号。甲负责解析通知点击并将目标接到课表；应校验当前账号与目标有效性，失效时显示可理解的状态。

目标字段的自动测试已覆盖从课程计划到调度载荷。通知点击、系统送达和设备恢复尚未真机验证。

课表首次进入时读取通知权限，并在尚未请求时显示现有通知用途说明并触发系统授权；请求记录保存在本机，避免反复弹窗。拒绝后提供系统设置入口。请甲统一补充“课程开始前 30 分钟提醒”的中英文词条，并核对现有设置文案与默认开启口径。

课表在排程失败、容量不足或会话失效时显示状态，并提供重试。现阶段复用现有状态词条，仍需甲核对课程提醒的文案。系统通知权限、真实送达和设置返回尚待设备验证。
