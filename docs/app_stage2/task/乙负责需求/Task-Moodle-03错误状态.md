# Moodle 任务 3：区分登录错误

## 1. 任务位置

- 阶段 1 Moodle 登录原因可辨：让用户理解实际失败。
- 本任务推进 R-1 Moodle 登录与工作台；依赖设备对照，结果供工作台状态使用。

## 2. 开发者须知

**先读**
- `docs/app_stage2/requirements/Stage2统一口径与接口契约.md`：错误需要如何区分？
- `app/src/features/tools/SchoolSystemWebView.tsx`：现有错误事件是否可获得？
- `app/src/features/tools/moodle/WorkspaceHost.tsx`：现有失败状态如何传递？
- `app/src/__tests__/p3y3-moodle-host.test.tsx`：现有入口如何测试？

**已定**：证书错误、账号错误、会话过期分开；保持 TLS 校验。
**边界与入口**：现有登录和工作台入口；词条与公共接线交甲。
**运行**：在 app 执行 `npm test -- --runInBand p3y3-moodle-host.test.tsx`，再执行 `npm run typecheck`。
**未知**：若平台事件无法可靠区分原因，不猜测，记录差异并协调。

## 3. 工作流程

1. 阅读上述入口并复述目标。
2. 根据设备证据核对平台事件。
3. 在现有入口逐例验证可辨识的失败。
4. 实现可理解的反馈和合规打开方式。
5. 运行针对性验证并交付词条需求。
6. 复核边界并按团队规范提交。
