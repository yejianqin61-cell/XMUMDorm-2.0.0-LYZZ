# A2-09c 课程通知解析与定位补充任务

日期：2026-10-30　依赖：现有通知目标载荷；公共导航仍由甲接入。

## 1. 任务位置

新增 `app/src/features/tools/reminders/navigation.ts`，由乙提供纯目标校验和课程匹配函数。
仅接收投影后的课程标识，不创建公共路由或词条，不读取校方凭据。

## 2. 开发者须知

先读提醒 plan.ts 的目标、scheduler.ts 的命名空间与账号、timetable.ts 的课程类型。
目标中的日期按学校日期计算周次，不受设备时区影响。
从当前账号重新获取课表后再匹配，不以通知正文或旧缓存代替当前课程。
运行：`npm test -- --runInBand --silent reminder`，之后 `npm run verify:serial` 和 `npm run lint`。

## 3. 工作流程

1. 核对现有载荷，不新增等价字段。
2. 为有效目标、账号不符、非法日期和失效课程写测试。
3. 实现校验与精确匹配，不能唯一匹配时返回不可定位。
4. 更新交甲文档并记录公共接线和设备验证状态。

## 4. 验证情形

| 输入 | 预期 |
| --- | --- |
| 当前账号、当前学期、周一日期 | 计算正确周次与星期 |
| 其他账号、其他学期、非法时刻 | 不产生可导航目标 |
| 非课程通知 | 忽略，继续其他通知处理 |
| 课程修改时间、删除或周次不符 | 不打开另一节课程 |
| 同课同时间出现多条记录 | 不任意选择其中一条 |
