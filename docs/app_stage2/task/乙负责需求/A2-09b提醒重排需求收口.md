# A2-09b 课表变化后提醒重排收口

日期：2026-10-30　基线：第二轮课前通知计划更新任务。

## 1. 实现结果

A2-09b 的实现与自动验证按下表核对，设备送达验证按用户要求暂缓。

| 情形 | 当前行为 | 自动验证入口 |
| --- | --- | --- |
| 导入成功 | 在提交成功并使课表缓存失效后重排；提交失败不重排 | p3y2-reminder-import.test.tsx |
| 课程时间改变 | 读取完整学期数据后替换旧计划 | stage2-reminder-refresh.test.ts |
| 课程删除 | 新计划为空时撤销该账号的课程提醒，保留 Moodle 提醒 | p3y2-reminder-scheduler.test.ts |
| 学期改变 | 作用域变化或回到前台后重新读取；旧学期响应不能提交 | stage2-reminder-account-switch.test.tsx、stage2-reminder-refresh.test.ts |
| 重复启动 | 启动重排采用替换语义，同一课程只保留一份 | p3y2-reminder-scheduler.test.ts |
| 并发刷新 | 较早的慢请求不覆盖最新一轮结果 | stage2-reminder-refresh.test.ts |
| 不完整或失败数据 | 完整读取成功之前不替换已有系统计划 | stage2-reminder-refresh.test.ts、p3y2-reminder-scheduler.test.ts |

## 2. 影响与边界

全局提醒宿主会在已登录启动、账号或学期变化、回到前台时刷新课程计划。
服务端改动通过现有按周查询接口读取；测试用修改和删除后的响应验证重排。
现有共享接口仅有导入预览、提交与按周查询，本项没有增加课程编辑服务接口。

代码入口：[运行时宿主](../../../../app/src/features/tools/reminders/ReminderRuntimeHost.tsx)、
[原生调度适配](../../../../app/src/features/tools/reminders/native.ts)。
