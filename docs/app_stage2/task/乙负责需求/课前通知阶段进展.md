## 2. 这些变化意味着什么

课程提醒已有从课表计划到通知载荷的目标数据。
课表可展示通知授权和排程结果；通知点击仍需要公共导航接入。
这些结论来自模拟测试，不能证明系统实际送达。

## 3. 尚未完成

- 当前没有真机证据，前台、后台、锁屏、重启和权限设置返回均未验证。
- 通知点击的公共导航尚未接入，因此目标数据还不能保证打开正确课程。
- 课程修改、删除、换学期后的完整真实链路尚未验证；导入后的重排已有模拟测试。
- 当前共享课表 API 仅提供导入预览、导入提交和按周查询；未找到 App 内课程单独修改或删除入口。
- 课前 30 分钟说明仍需统一中英文词条，当前课表复用现有通知说明。
- 本阶段尚未由非实现者验收，不能认定完成。
