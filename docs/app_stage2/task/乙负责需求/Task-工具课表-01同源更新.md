# 工具课表任务 01同源更新：贯通导入课程、首页摘要和课表详情的数据更新

## 1. 任务位置

- 阶段 3 工具摘要与课表一致，推进 R-3 工具首页与课表。
- 本任务：贯通导入课程、首页摘要和课表详情的数据更新；以阶段计划为前置，结果用于后续验收。

## 2. 开发者须知

**先读**
- `docs/app_stage2/task/乙负责需求/Task-乙-第二轮需求实施计划.md`：阶段目标是什么？
- `docs/app_stage2/test/Stage2验收矩阵.md`：需覆盖哪些状态？

**已定**：首页摘要和完整课表同源；按学校时区计算；保留现有设计体系。
**边界与入口**：现有课程摘要、课表和导入入口；公共路由、词条及公共组件交甲。
**运行**：在 app 执行 `npm test -- --runInBand --silent p2y-a02-shared-timetable.test.tsx` 和 `npm run typecheck`。
**未知**：设备截图暂不可用时标记未验证；与既定契约冲突时记录差异。

## 3. 工作流程

1. 阅读上述入口并复述任务。
2. 核对现有行为和对应需求。
3. 在既有入口验证缺口并记录结果。
4. 在乙的范围内修复缺口并补充验证。
5. 运行相关检查并记录未验证项。
6. 复核改动并按团队规范提交。
