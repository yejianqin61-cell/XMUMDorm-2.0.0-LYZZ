# Moodle 任务 5：收口阶段证据

## 1. 任务位置

- 阶段 1 Moodle 登录原因可辨：形成可复核验收记录。
- 本任务推进 R-1 Moodle 登录与工作台；依赖前四项，结果供非实现者验收。

## 2. 开发者须知

**先读**
- `docs/app_stage2/test/Stage2验收矩阵.md`：证据与设备要求是什么？
- `docs/app_stage2/team/协助者Agent守则.md`：汇报与验证要求是什么？
- `docs/app_stage2/task/乙负责需求/Task-乙-第二轮需求实施计划.md`：阶段证明是什么？

**已定**：缺设备必须标未验证；人工验收由非实现者复核。
**边界与入口**：现有登录、同步和详情入口及脱敏证据；不接触真实凭据。
**运行**：在 app 执行 `npm run verify:serial`，并执行 `npm run typecheck`。
**未知**：设备覆盖不足或测试失败时如实记录，不能宣布通过。

## 3. 工作流程

1. 阅读上述入口并复述目标。
2. 汇总真实设备、错误码和录像。
3. 运行验证并记录命令、退出码及失败项。
4. 整理脱敏证据与未验证项。
5. 请求非实现者按验收矩阵复核。
6. 按团队规范提交记录并使用 easy-summary 汇报。

## 4. 验证情形

| 情形 | 输入 | 预期 | 入口 |
| --- | --- | --- | --- |
| 正常设备 | 登录到详情 | 有脱敏记录 | 设备证据 |
| 问题设备 | 登录失败 | 有错误码与对照 | 设备证据 |
| 缺设备 | 未能测试 | 标记未验证 | 验收记录 |
| 检查失败 | 非零退出码 | 记录失败与原因 | 验证记录 |
