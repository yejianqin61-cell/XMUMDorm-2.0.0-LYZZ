# M03-Task006 - 食堂分区地点入口轻量化

**What to build:** 学生打开食堂首页后，能以地点头像和名称快速识别并进入每个食堂分区；页面为后续排行榜和吃货广场提供无阴影、无渐变、细分隔的信息流视觉基线。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 食堂分区继续展示所有现有可用分区，并保留进入对应商家列表的既有跳转。
- [ ] 每个分区只呈现圆形地点图片和单行名称；移除白底卡、外层圆角、阴影与缩放浮起动画。
- [ ] 分区、区段标题和相邻内容采用白色内容底与细分隔的统一视觉基线；不为本轮目标新增渐变、玻璃效果或装饰性图标。
- [ ] 地图入口仍可从食堂首页抵达，且不新增虚构入口或功能说明文案。
- [ ] 分区加载、失败或无数据时不出现失效点击区域或误导性空白。
- [ ] 在 375px、390px、430px 宽度下，分区名称不重叠、页面不产生横向溢出，所有分区入口具有至少 44px 的可点按区域。
- [ ] 现有生产构建通过。
