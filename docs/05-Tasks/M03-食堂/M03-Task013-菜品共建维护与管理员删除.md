# M03-Task013 - 菜品共建维护与管理员删除

**What to build:** 登录用户在任意商铺内可新增和编辑菜品、调整分类、价格与图片；菜品删除操作只向管理员提供，且服务端再次校验管理员身份。所有操作均在当前商铺上下文中完成。

**Blocked by:** M03-Task010 - 食堂共建写权限契约; M03-Task012 - 商铺与分类共建维护入口.

**Status:** ready-for-agent

- [ ] 商铺菜单页及空菜单状态均提供添加菜品入口；用户可从当前商铺的有效分类中选择归属并完成发布。
- [ ] 所有登录用户都可从菜品详情或商铺管理入口编辑任意未删除菜品的名称、描述、分类、价格和图片，不依赖原店主身份。
- [ ] 菜品删除入口只对管理员展示；管理员删除前必须二次确认，学生与商家既看不到入口，也无法通过服务端执行删除。
- [ ] 新增、编辑、删除后，商铺菜单、分类计数、菜品详情、分区/搜索/排名等受影响视图会刷新，不保留陈旧条目。
- [ ] 菜品目标或分类在提交期间已删除时，界面给出明确失败反馈并刷新数据；图片与字段校验错误可被用户理解和修正。
- [ ] 验证学生、商家、管理员对非本人创建菜品的新增与编辑，及三种身份的删除可见性和接口结果。
