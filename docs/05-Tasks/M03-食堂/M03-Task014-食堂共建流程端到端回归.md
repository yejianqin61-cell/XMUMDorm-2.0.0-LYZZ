# M03-Task014 - 食堂共建流程端到端回归

**What to build:** 在 Capacitor App 的真实移动尺寸下，食堂共建流程从分区新增商铺到菜单维护、管理员删除都能稳定运行，且不破坏原有浏览、搜索、点评、收藏和旧商家入口兼容性。

**Blocked by:** M03-Task011 - 分区页新增商铺共建入口; M03-Task012 - 商铺与分类共建维护入口; M03-Task013 - 菜品共建维护与管理员删除.

**Status:** ready-for-agent

- [ ] 使用学生、商家、管理员、未登录四种状态完整验证分区加店、编辑商铺、分类维护、菜品新增/编辑，以及商铺和菜品管理员删除流程。
- [ ] 验证每次成功写入后的列表、详情、搜索和排名刷新；删除后已软删除内容不再通过正常浏览路径出现。
- [ ] 验证未登录写入引导及回跳、目标被他人删除、无分类/无菜品、网络失败和校验失败等恢复路径。
- [ ] 在 375px、390px、430px 和 Capacitor WebView 或等价移动环境复验触控区、键盘、图片上传、确认对话、返回导航及中英文文案。
- [ ] 回归食堂已有的分区跳转、商铺菜单、菜品详情、搜索、点评、收藏、排行榜与旧商家入口，确认共建改造没有改变其非权限业务行为。
- [ ] 运行生产构建及本轮相关自动化检查；记录人工验收账号角色与结果。
