# M03-Task010 - 食堂共建写权限契约

**What to build:** 学生、商家和管理员都能通过既有食堂写接口，为任意有效商铺创建或编辑商铺、分类和菜品；商铺与菜品只有管理员能删除，分类继续允许所有登录用户删除。未登录请求始终被拒绝，现有内容与上传校验不被削弱。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 所有有效登录身份均可新增商铺，且同一账户可连续新增多间商铺；商铺创建者仍被记录用于追溯，但不再构成后续维护授权条件。
- [ ] 所有有效登录身份均可编辑任意未删除商铺，以及创建、编辑任意有效商铺下的分类和菜品；不再因商家身份或原店主身份被拒绝。
- [ ] 商铺和菜品删除只允许管理员，普通学生和商家请求均得到明确拒绝；分类删除仍允许所有已登录用户，并保留菜品转为未分类的既有结果。
- [ ] 未携带、过期或无效的登录凭证不能执行任何写操作；查询权限保持现状。
- [ ] 既有必填字段、目标存在性、敏感词、图片格式/大小/数量、multipart 与 JSON 更新校验继续生效。
- [ ] 覆盖学生、商家、管理员、未认证四类身份对商铺、分类、菜品写操作的接口测试，并覆盖非创建者维护、第二间商铺创建、删除权限和软删除结果。
