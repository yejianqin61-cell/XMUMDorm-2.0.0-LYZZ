# M03-Task012 - 商铺与分类共建维护入口

**What to build:** 登录用户进入任意商铺菜单后，可以在该商铺上下文内编辑商铺资料，并新增、编辑、删除分类；不再被引导到只面向本人店铺的旧商家管理页。分类为空或菜单为空时，同样能完成内容补充。

**Blocked by:** M03-Task010 - 食堂共建写权限契约.

**Status:** ready-for-agent

- [ ] 商铺菜单页为所有登录用户提供不干扰正常浏览的维护入口，至少能编辑店名、营业时间、店铺图片，以及进入分类管理。
- [ ] 分类管理可在当前商铺上下文中完成新增、重命名、排序和删除；删除前二次确认，并清楚说明菜品将保留为未分类。
- [ ] 未登录用户从维护入口进入登录，成功后回到同一商铺；普通用户和非创建者不因店主关系受到前端隐藏或服务端拒绝。
- [ ] 商铺资料或分类变更成功后，当前商铺详情、分类导航、菜单和相关列表即时刷新；失败不显示虚假的成功状态。
- [ ] 菜单无分类、分类下无菜品、商铺资料缺失、加载与错误状态仍保留可达的共建路径。
- [ ] 在 App 目标窄屏及中英文下验证编辑表单、分类操作、确认提示和返回路径可用，无横向溢出。
