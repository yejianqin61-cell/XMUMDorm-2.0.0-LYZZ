# M03-Task007 - 食堂排行榜文字 Tab 与紧凑榜单

**What to build:** 学生可在食堂首页清晰切换单品、店铺和新上榜三类真实排行榜，并从紧凑榜单继续进入相应菜品、商家或完整排行榜。

**Blocked by:** M03-Task006 - 食堂分区地点入口轻量化。

**Status:** ready-for-agent

- [ ] 保留现有三类排行榜查询、排序规则、前五条预览、加载/失败/空状态和“查看全部”入口，不新增后端接口或改变排行榜算法。
- [ ] 三类排行榜使用等宽文字 Tab；选中项用正文色和底部强调线表达状态，未选中项无灰色轨道、白色选中卡或阴影。
- [ ] Tab 具备可理解的按钮语义、选中状态、焦点状态与内容区关联，键盘用户可完成类别切换。
- [ ] 每条榜单项稳定展示名次、缩略图、名称及真实来源信息；有综合评分时展示评分，没有评分时不以 `0.0` 补齐。
- [ ] 商品预览仍进入菜品详情，店铺预览仍进入商家详情；名次不得使用奖牌、火焰、渐变或“爆款”等营销装饰。
- [ ] 在 375px、390px、430px 宽度下，三个 Tab 不造成页面横向滚动，名称与评分不相互遮挡，榜单行的主要点击区域至少为 44px。
- [ ] 现有生产构建通过。
