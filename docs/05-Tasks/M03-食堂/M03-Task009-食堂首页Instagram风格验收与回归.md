# M03-Task009 - 食堂首页 Instagram 风格验收与回归

**What to build:** 学生在 Android Capacitor App 中获得一个连续、地点和内容优先的食堂首页，同时既有导航、发布、登录与数据状态在视觉重构后保持稳定可用。

**Blocked by:** M03-Task007 - 食堂排行榜文字 Tab 与紧凑榜单；M03-Task008 - 吃货广场媒体优先内容流。

**Status:** ready-for-agent

- [ ] 在 375px、390px、430px 完成视觉验收：三个目标区段默认无阴影卡、无渐变背景、无圆角分段控件，且页面没有横向溢出。
- [ ] 在 Android Capacitor WebView 或等价真实移动环境复验图片加载、滚动、分区跳转、排行榜 Tab、榜单详情跳转、帖子详情、未登录发布跳转和已登录发布。
- [ ] 验证分区、三类排行榜和吃货广场在加载、成功、失败、空数据与继续分页状态下均有可理解反馈，且一个区段失败不妨碍其他区段使用。
- [ ] 验证中文与英文切换后，区段标题、Tab、发布、空状态、失败提示和加载操作均无硬编码或截断。
- [ ] 验证键盘焦点可见、Tab 选中状态可被辅助技术识别、图片替代文本符合内容语义，主要操作触控区域不小于 44px。
- [ ] 运行现有生产构建并完成必要的静态检查；不修改后端接口、权限模型、排行榜算法或废弃的 React Native 与 Web 前端。
