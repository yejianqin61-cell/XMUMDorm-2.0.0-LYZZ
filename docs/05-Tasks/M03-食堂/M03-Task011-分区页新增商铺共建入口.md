# M03-Task011 - 分区页新增商铺共建入口

**What to build:** 登录用户在浏览任意食堂分区时，可以直接添加该分区的商铺；未登录用户点击同一入口后登录，并回到原分区继续操作。创建成功后，新商铺立即出现在当前分区列表中。

**Blocked by:** M03-Task010 - 食堂共建写权限契约.

**Status:** ready-for-agent

- [ ] 每个有效分区的商铺列表提供清晰、轻量的“添加商铺”入口，不依赖旧商家后台或“我的店铺”数据。
- [ ] 已登录用户进入创建表单时，当前分区默认被带入；表单继续使用现有商铺名称和分区校验，并允许按现有规则调整分区。
- [ ] 未登录用户点击入口后进入登录流程，登录成功后能返回对应分区，不暴露无凭证写入。
- [ ] 创建成功后关闭或离开表单并刷新受影响的分区商铺列表；失败时保留可恢复的输入并展示可理解错误。
- [ ] 空分区、加载失败、窄屏和中英文状态下，入口不失效、不遮挡列表，且无横向溢出。
- [ ] 验证学生、商家、管理员分别可从分区页创建商铺，并验证同一用户第二次创建不再被“一人一店”限制阻止。
