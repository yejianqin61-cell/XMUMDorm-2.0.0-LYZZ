# 02 - 个人设置容器与账号操作收束

**What to build:** 在个人空间建立统一的“设置”入口，将编辑资料、语言设置、退出登录和注销账号放入清晰分组，并区分普通设置与危险操作。

**Blocked by:** 01 - 关于我们信息收束与旧入口兼容

**Status:** completed

- [x] 已登录用户能从个人空间进入设置页，未登录用户不会看到需要身份的设置内容。
- [x] 编辑资料、语言设置、退出登录和注销账号均可从设置页完成，不再分散在个人空间多个位置。
- [x] 普通设置与危险操作有明确视觉分组，避免将注销账号与普通操作混在一起。
- [x] 注销账号需要二次确认，并明确说明不可逆后果；取消不会改变账号状态。
- [x] 退出登录成功后清理本地会话、缓存的用户态数据，并回到合理的登录/公开页面。
- [x] 设置只作用于当前用户，不能通过前端状态切换操作其他用户账号。
- [x] App/Web、中文/英文、浏览器返回和 Android 返回键均能正确回退。
