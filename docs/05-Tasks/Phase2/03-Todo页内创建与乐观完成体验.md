# 03 - Todo 页内创建与乐观完成体验

**What to build:** 用户在 Todo 页面内完成浏览、创建和勾选操作；创建入口收束到页面内按钮触发的表单/抽屉/弹层，勾选完成采用乐观更新并在失败时恢复。

**Blocked by:** 02 - 个人设置容器与账号操作收束

**Status:** completed

- [x] Todo 页面提供清晰的“创建”按钮，点击后在当前上下文打开创建表单，不跳转到孤立的创建页面。
- [x] 创建表单支持必填校验、提交中状态、成功反馈和取消/关闭，不遮挡底部 Tab 或系统安全区。
- [x] 创建成功后表单自动关闭，新 Todo 出现在正确的未完成列表位置。
- [x] 勾选 Todo 后界面立即反映完成状态，不等待后端响应。
- [x] 更新失败时恢复原状态，并通过现有 Toast/错误状态给出明确反馈。
- [x] 加载、空列表、错误、完成列表和未完成列表状态布局稳定，窄屏不溢出。
- [x] App/Web 使用同一业务语义，键盘、返回键和 reduced-motion 场景可用。
