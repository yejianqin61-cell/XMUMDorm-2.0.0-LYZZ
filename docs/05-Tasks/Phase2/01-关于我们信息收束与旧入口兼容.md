# 01 - 关于我们信息收束与旧入口兼容

**What to build:** 将免责声明、联系我们等低频信息收束到“关于我们”内，使用户从一个稳定入口找到团队、特别鸣谢、免责声明和联系我们，同时保留必要的旧路径可达性。

**Blocked by:** None - can start immediately

**Status:** completed

- [x] “关于我们”页面提供团队、特别鸣谢、免责声明、联系我们等明确分区或子入口。
- [x] 顶层导航和个人空间不再重复展示免责声明、联系我们入口。
- [x] 原有页面内容、外部链接、联系方式和法律文本完整保留，不能因收束而丢失。
- [x] 旧路径通过重定向或等价入口继续可访问，刷新、返回和深链接均不产生空白页。
- [x] App 与 Web 的入口语义、中文/英文文案一致，语言切换后不出现混搭或乱码。
- [x] 键盘焦点、Android 返回键和移动端安全区下的页面可达性通过验证。
