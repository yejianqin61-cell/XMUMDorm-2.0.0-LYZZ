# 04 - 广场四入口完整展示与轻量化布局

**What to build:** 将广场的“社团广场、马校一站通、帮帮我、出物”从横向滑动入口带改为一次性完整可见的轻量导航矩阵，保留原有业务入口和路由。

**Blocked by:** 03 - Todo 页内创建与乐观完成体验

**Status:** completed

- [x] App 在 375px、390px、430px 宽度下以固定两列两行展示四个入口，四项无需左右滑动即可看见。
- [x] Web 宽屏可使用四列布局，但与 App 保持相同的图标、标题、分隔线和层级规则。
- [x] 入口只保留黑色线描镂空图标和短标题，图标统一线宽；不使用渐变、阴影、大圆角、箭头、emoji 或解释性副文案。
- [x] 入口单元具备至少约 44px 的触控高度，整个单元可点击，焦点态和按下态清晰但克制。
- [x] 四个原有目标保持可达：社团广场、马校一站通、帮帮我、出物。
- [x] 入口与轮播图、校园通知流之间使用留白或细分隔线组织，不形成卡片套卡片。
- [x] 中英文切换后标题可自然换行，单元高度稳定，不出现裁切、横向滚动或布局跳动。
- [x] `prefers-reduced-motion` 下不出现额外滑入、浮动或缩放动画。
