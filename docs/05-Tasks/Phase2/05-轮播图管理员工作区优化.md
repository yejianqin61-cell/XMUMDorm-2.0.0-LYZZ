# 05 - 轮播图管理员工作区优化

**What to build:** 管理员在一个清晰、可持续管理的工作区内查看和维护全部轮播图，包括已上线、未上线、未开始、已过期项目；普通用户不能进入或执行管理操作。

**Blocked by:** 04 - 广场四入口完整展示与轻量化布局

**Status:** ready-for-agent

- [ ] 管理列表展示全部轮播图，不因上线状态、开始时间或结束时间而隐藏项目。
- [ ] 每项显示缩略图、标题、类型、排序、上线状态和必要的时间状态，未上线状态一眼可识别。
- [ ] 管理员可在同一工作区完成预览、新建、编辑、排序、启停和删除；编辑后项目仍留在列表中。
- [ ] 新建和编辑表单具备稳定的保存、取消、失败恢复和成功反馈，上传/URL 图片预览清晰。
- [ ] 启停状态、排序和时间窗的修改在刷新列表后仍保持一致，用户端只展示满足发布条件的项目。
- [ ] 删除操作需要确认，删除失败不能从界面伪造成功；保存失败不丢失当前表单输入。
- [ ] 普通用户访问管理路由或直接调用管理接口均被拒绝；前端隐藏入口不替代后端鉴权。
- [ ] App/Web 管理界面在窄屏和桌面宽度下均可操作，中文/英文文案完整且不乱码。
