# Task009: App 广场 X 风格信息流改造

**Status:** completed (Tasks 009-01 to 009-05 complete; final device acceptance handed off)

## Problem Statement

Capacitor App 的广场首屏以 Hero、热搜面板、快捷入口卡片和通知入口卡片堆叠呈现。大圆角、渐变、阴影、装饰 emoji、箭头和模块功能说明占据了首屏，用户需要先理解页面模块，才能看到校园内容。广场应当让学生快速浏览和参与校园讨论，而不是介绍产品能力。

## Solution

将广场收敛为白底、单列、连续的校园信息流。页面顶部保留“广场”、发布和刷新操作；现有轮播图作为唯一的首屏媒体位保留；“校园”与“热搜”作为真实的数据筛选 Tab。社团广场、马校一站通、帮帮我、出物四个现有功能入口继续保留，但从大面积四宫格改为 Tab 下方的一行轻量入口栏，每项只显示图标和短名称，不显示解释文案。内容以统一的行级结构呈现，使用 1px 分割线而不是浮层卡片。正文可进入详情，评论、点赞和更多操作保持在内容行内。

借鉴 X 的时间线信息架构和互动密度，不复制其品牌、图标、文案或视觉资产。

## User Stories

1. 作为学生，我希望打开广场后立刻看到校园内容，以便不必阅读功能介绍。
2. 作为学生，我希望在“校园”和“热搜”间切换，以便按内容来源浏览。
3. 作为学生，我希望快速进入社团广场、马校一站通、帮帮我和出物，以便继续使用这些核心功能。
4. 作为学生，我希望系统记住上次查看的 Tab，以便返回广场时保持上下文。
5. 作为学生，我希望以连续列表阅读内容，以便快速扫读多个动态。
6. 作为学生，我希望点击帖子正文或图片进入详情，以便阅读完整讨论。
7. 作为学生，我希望在列表中直接看到评论数和点赞数，以便判断讨论活跃度。
8. 作为学生，我希望用图标操作评论、点赞和更多菜单，以便减少冗余按钮文案。
9. 作为学生，我希望热搜只展示标题、排名和真实讨论数，以便理解其真实热度信息。
10. 作为学生，我希望没有校园内容时看到明确的空状态，以便知道当前没有可浏览内容。
11. 作为学生，我希望加载失败时能重试，以便恢复浏览。
12. 作为学生，我希望在 375px 至 430px 宽度下都能阅读和点击，以便在不同机型上使用。
13. 作为管理员，我希望继续管理热搜话题，以便不改变现有运营能力。
14. 作为内容作者，我希望发布、评论、点赞和举报路径保持不变，以便改版不影响已有流程。
15. 作为中英文用户，我希望两种语言的 Tab、空状态和操作均不溢出，以便稳定使用。
16. 作为使用辅助技术的用户，我希望图标按钮带有可读名称，以便理解其作用。

## Implementation Decisions

- 改造边界为广场首页的内容编排层；继续使用既有的广场摘要、校园动态、热搜列表、详情和互动接口。
- 顶栏仅保留页面名“广场”及明确命令。发布使用图标按钮和无障碍名称；刷新仅在确有刷新行为时出现。
- 保留现有轮播图及其后台管理能力，作为标题和内容流之间唯一的媒体模块；不为它补充营销文案或额外卡片容器。
- “校园”和“热搜”是持久化的双 Tab，使用文字与 1px 底部指示线，不使用胶囊、渐变或卡片式分段控件。
- 移除首页 Hero 和其说明性内容；保留四个功能入口，但改为 Tab 下方横向入口栏。入口只保留图标、短名称和链接行为，不显示 hint、emoji 装饰、渐变和大卡片背景。
- 内容主单元采用头像（可选）、作者、时间、正文、单张主图和互动行的固定顺序；不在内容单元外包裹圆角卡片。
- 热搜视图使用普通数字排名、标题和讨论数。前三名不使用“爆热/上升/关注”等推断性标签，除非后端提供可验证的趋势数据。
- 快捷入口采用单行横向排列，窄屏允许横向滚动；不得因为四个入口而重新引入页面级卡片堆叠。
- 页面背景使用白色，分区背景仅允许中性浅灰；以 1px 分割线区分内容。信息流无阴影、无玻璃效果、无渐变。图片圆角不超过 8px，命令按钮圆角不超过 8px。
- 正文使用 15-16px，次级信息使用约 13px，内容左右内边距 16px。图标命中区域至少 44px。
- 仅保留加载、Tab 切换和点赞反馈动画；移除入场上浮、装饰漂浮与背景动画，并遵守减少动态效果设置。
- 不修改热搜的后端运营排序、权限、表结构或 API 契约。

## Testing Decisions

- 在现有页面级测试或可运行检查中覆盖用户可见行为，而不是 CSS 类名或组件内部状态。
- 验证校园/热搜 Tab 切换、上次 Tab 恢复、加载、错误重试、空状态、详情跳转、点赞和评论入口。
- 验证热搜显示真实讨论数，不显示无后端依据的趋势结论。
- 对 375px、390px、430px 视口进行截图检查：首屏可见第一条内容、Tab 无横向溢出、操作区可触达、文字不重叠。
- 保留并运行前端生产构建与现有 lint；新增检查只覆盖本次改造所触及的行为。

## Out of Scope

- 不改变 Web 端视觉方案。
- 不改弃用的 `mobile` React Native 前端。
- 不抓取或展示外部平台热搜。
- 不复制 X 的商标、logo、专有图标或品牌视觉资产。
- 不调整热搜运营排序算法或新增推荐算法。
