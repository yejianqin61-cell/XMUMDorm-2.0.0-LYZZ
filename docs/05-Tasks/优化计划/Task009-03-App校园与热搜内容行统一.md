# Task009-03: App 校园与热搜内容行统一

**Status:** completed

**Blocked by:** Task009-01 - App 广场信息流壳层与 Tab

## What to build

让校园动态和热搜内容都使用连续信息流节奏展示：作者/时间、正文、媒体和互动行按固定顺序排列，以 1px 分割线分隔，不再使用嵌套卡片。继续复用现有查询、详情和互动 API。

## Acceptance criteria

- [x] 校园 Tab 显示连续内容行，正文或媒体可以进入详情。
- [x] 热搜 Tab 显示标题、普通数字排名和真实讨论数。
- [x] 内容行没有外层阴影、渐变、浮层卡片或排名装饰徽章。
- [x] 点赞、评论、更多操作保持原有功能，图标按钮具备无障碍名称和至少 44px 命中区。
- [x] 热搜不出现没有后端数据支持的“爆热/上升/关注”等推断性文案。
