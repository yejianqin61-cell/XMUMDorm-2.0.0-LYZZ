# Task009-02: App 广场四项功能入口重构

**Status:** completed

**Blocked by:** Task009-01 - App 广场信息流壳层与 Tab

## What to build

保留社团广场、马校一站通、帮帮我、出物四个入口，将原来的大卡片/四宫格改为 Tab 下方的单行轻量入口栏。每项保留图标、短名称和原有链接，不再展示 hint、emoji 装饰或功能说明。

## Acceptance criteria

- [x] 四个入口均可见或可通过水平滚动访问，链接目标不变。
- [x] 每项只展示图标和短名称，不显示解释性副文案。
- [x] 入口栏不使用渐变、玻璃、阴影或大面积圆角卡片。
- [x] 375px、390px、430px 宽度下无不可用的横向溢出，水平滚动可触达。
- [x] 入口栏不会把信息流推迟成新的首屏模块堆叠。
