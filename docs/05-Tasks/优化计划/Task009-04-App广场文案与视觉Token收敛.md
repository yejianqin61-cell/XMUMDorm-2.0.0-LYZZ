# Task009-04: App 广场文案与视觉 Token 收敛

**Status:** completed

**Blocked by:** Task009-01 - App 广场信息流壳层与 Tab; Task009-02 - App 广场四项功能入口重构; Task009-03 - App 校园与热搜内容行统一

## What to build

为广场建立局部的简约视觉基线：白色主背景、中性浅灰分割线、单一强调色、紧凑字阶和有限圆角。删除只解释功能而不帮助完成任务的文案，保留空状态、错误、重试和无障碍标签。

## Acceptance criteria

- [x] 广场首屏不出现渐变背景、玻璃效果、装饰性漂浮元素或连续阴影。
- [x] 信息流外层不设置大圆角；图片圆角不超过 8px，按钮圆角不超过 8px。
- [x] 删除 Today on Campus、Quick Access、查看全部箭头及同类解释性文案。
- [x] 空状态和错误状态仍能告诉用户下一步动作。
- [ ] 中文和英文版本在窄屏下均不溢出、不重叠。
