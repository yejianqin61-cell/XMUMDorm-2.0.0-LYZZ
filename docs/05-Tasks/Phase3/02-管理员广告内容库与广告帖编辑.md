# 02 — 管理员广告内容库与广告帖编辑

**What to build:** 在现有轮播管理工作区内提供广告内容库，管理员可以使用现有帖子编辑能力创建、编辑、保存草稿和预览广告帖。

**Blocked by:** 01 — 广告元数据和权限接口必须先可用。

**Status:** ready-for-agent

- [ ] App/Web 管理端在现有轮播管理入口提供“广告内容库”，不增加新的顶层导航。
- [ ] 复用现有帖子编辑器的标题、正文和图片能力，增加广告帖模式，隐藏普通帖子发布选项。
- [ ] 新建广告时投放方名称必填，Logo 可选；广告正文和素材支持草稿保存。
- [ ] 管理员可以编辑、预览、恢复草稿、结束投放和逻辑归档广告内容。
- [ ] 管理员预览不要求广告已上线；普通用户仍不能通过预览路径访问草稿或失效广告。
- [ ] 广告库列表显示投放方、生命周期、关联轮播数量和最近更新时间，并提供清晰的空态、错误态和保存反馈。
- [ ] App 与 Web 均完成管理员权限、中文/英文模式和返回路径测试。
