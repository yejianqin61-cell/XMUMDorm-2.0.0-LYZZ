# 01 — 广告数据模型与服务端边界

**What to build:** 建立管理员广告帖的独立元数据、生命周期和服务端隔离边界，让广告内容可以复用现有帖子正文，但不会进入普通用户发现入口。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 新增广告元数据模型，与现有帖子正文通过 `post_id` 关联，支持草稿、已投放、已结束和已归档生命周期。
- [ ] 保存投放方名称、可选 Logo、CTA 配置、创建/更新管理员和时间信息。
- [ ] 管理员才能创建、更新、预览、归档广告元数据；普通用户无法执行管理接口。
- [ ] 服务端统一识别广告帖，并从树洞、食堂、广场普通流、搜索、热搜、推荐和个人帖子列表过滤。
- [ ] 广告帖只有在自身有效且存在有效广告轮播关联时才允许普通用户访问。
- [ ] 广告轮播关联失效、过期、删除或取消跳转时，广告内容返回稳定的不可用语义，不重定向到普通信息流。
- [ ] 为创建、更新、归档、公开访问和过滤补充路由级测试；测试覆盖越权、过期和无关联场景。
