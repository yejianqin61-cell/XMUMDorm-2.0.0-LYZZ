# 08 — Phase3 跨端回归与上线验收

**What to build:** 对 Phase3 广告系统、底部 Tab 和树洞话术清理进行 App/Web 双端的端到端验收，确保高频入口、权限和现有信息流没有回归。

**Blocked by:** 01、02、03、04、05、06、07。

**Status:** ready-for-agent

- [ ] App 和 Web 构建通过，路由和共享后端接口无阻断错误。
- [ ] 管理员可以完成广告创建、草稿预览、投放位配置、上线、下线、归档和点击统计查看。
- [ ] 普通用户无法从任何普通信息流、搜索或旧 URL 绕过广告入口访问失效广告。
- [ ] 有效广告轮播可以进入广告详情，CTA 在 App 内部路由和 HTTPS 外链场景均正确工作。
- [ ] 广告详情的 sponsor 标识、隐藏互动、长内容、不可用状态和中文/英文模式通过验收。
- [ ] 底部 Tab 在小屏 Android、手势导航、三键导航、返回键、字体放大和减少动效设置下通过验收。
- [ ] 树洞中英文页面不再显示算法推荐话术，内容排序和分页结果与改动前一致。
- [ ] 记录测试账号角色、环境、设备、构建版本和发现的问题；阻断问题单独建立缺陷 Task。
