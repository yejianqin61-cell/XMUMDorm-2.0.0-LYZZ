# 05 — 广告点击记录与管理员基础统计

**What to build:** 在广告轮播点击和广告详情访问链路上记录最小点击事件，并在管理员广告内容库提供基础点击总数。

**Blocked by:** 03、04 — 点击必须绑定经过校验的投放位和广告详情入口。

**Status:** ready-for-agent

- [ ] 记录广告帖、轮播投放位、投放位置、点击时间和必要的匿名/登录用户标识。
- [ ] 只有经过有效广告轮播校验的点击才计入统计；无效广告访问不产生有效点击。
- [ ] 重复点击按事件记录，不在第一版引入复杂去重、曝光归因或转化归因。
- [ ] 管理员广告内容库显示每个广告的基础点击总数，并区分不同投放位。
- [ ] 统计接口只允许管理员访问，不泄露普通用户身份信息。
- [ ] 路由测试覆盖有效点击、无效广告、跨位置投放和统计权限。
