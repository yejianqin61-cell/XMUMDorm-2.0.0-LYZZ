# 03 — 轮播投放位、广告关联与 CTA

**What to build:** 在轮播管理工作区配置广告投放位；一篇广告帖可以被多张轮播图复用，每张投放位独立管理创意、排期和跳转。

**Blocked by:** 01、02 — 需要广告元数据接口和广告内容库。

**Status:** ready-for-agent

- [ ] 轮播管理页分为广告内容库和轮播投放位，管理员可以从投放位选择已有广告帖。
- [ ] 同一广告帖可被广场、食堂或同一位置的多张轮播图复用。
- [ ] 每张轮播图可以独立配置图片、标题、副标题、排序、启用状态和开始/结束时间。
- [ ] 广告轮播只允许“不跳转”或“跳转广告帖”；服务端拒绝指向普通帖、无权限内容或不存在广告帖的配置。
- [ ] 广告帖支持一个可选 CTA，目标支持店铺、菜品、分区、站内页面和 HTTPS 外链。
- [ ] App 内目标使用应用内路由；HTTPS 外链使用 Capacitor Browser；第一版拒绝微信、WhatsApp、电话和其他特殊协议。
- [ ] 站内 URL 不打开新窗口；外部 URL 做 HTTPS 协议校验并提供 Web/Capacitor 各自稳定的返回体验。
- [ ] 保存、编辑、下线、排期冲突和非法目标均有明确反馈；管理员列表能看到当前关联和投放状态。
