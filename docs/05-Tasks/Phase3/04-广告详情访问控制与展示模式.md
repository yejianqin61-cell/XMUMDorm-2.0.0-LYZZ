# 04 — 广告详情访问控制与展示模式

**What to build:** 提供广告帖专用详情展示模式：普通用户只能从有效广告轮播进入，页面复用帖子详情容器但不表现为普通社区帖子。

**Blocked by:** 01、03 — 需要服务端公开访问校验和可用投放位。

**Status:** ready-for-agent

- [ ] 广告轮播点击进入广告专用详情路由，并在服务端校验广告状态、轮播关联和投放排期。
- [ ] 无效、过期、下线、取消关联或归档广告显示“广告已结束或暂不可用”状态。
- [ ] 管理员可以通过受保护预览路径查看草稿、下线和过期广告。
- [ ] 详情页复用现有图片预览、正文滚动、返回和布局能力。
- [ ] 详情页显示“广告”和投放方名称，不显示代发布管理员身份。
- [ ] 详情页隐藏点赞、评论、分享、作者主页和普通帖子操作，只保留正文、图片和 CTA。
- [ ] 长正文、换行、特殊字符、空内容和中英文界面均可稳定显示。
- [ ] 路由测试证明复制普通帖子 URL、搜索或信息流路径不能绕过广告访问边界。
