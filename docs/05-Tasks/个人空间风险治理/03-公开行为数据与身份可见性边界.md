# 03 - 公开行为数据与身份可见性边界

**What to build:** 让公开个人空间只展示用户明确允许公开的校园身份信息和公开帖子，移除默认对外展示的收藏、点评、社团关系、活动报名与最近参与画像。

**Blocked by:** 02 - 公开资料响应字段白名单

**Status:** ready-for-agent

- [ ] 学院、年级、专业继续遵循已有可见性开关；关闭的字段在接口和 UI 中均不可见。
- [ ] 公开查看他人资料时不返回、不展示收藏数量、点评数量、社团关注/报名数量或最近参与记录。
- [ ] 本人资料的点评和收藏仍通过已有本人鉴权接口和本人 Tab 正常展示，不因公开边界收紧而丢失。
- [ ] 公开帖子仍保留已删除、管理员隐藏和广告帖隔离规则。
- [ ] 数据库相关表缺失或查询失败时，不得把失败静默伪装成用户没有行为；应返回稳定的降级状态并留下可诊断错误。
- [ ] 测试覆盖可见性开关组合、公开访客和本人访客，确认不存在跨用户数据串读。
