# 06 - 个人空间跨端安全回归

**What to build:** 对个人空间完成 App、Web 和公开资料接口的整体验收，确认前序修复在真实链路中同时生效。

**Blocked by:** 01 - 个人空间稳定渲染与状态分支；02 - 公开资料响应字段白名单；03 - 公开行为数据与身份可见性边界；04 - 帖子分页与统计一致性；05 - 用户 ID 校验与双语错误状态

**Status:** ready-for-agent

- [ ] 未登录访问他人资料时，页面可加载、邮箱等私密字段不泄露、身份可见性开关生效。
- [ ] 登录后访问本人资料时，帖子、点评和收藏入口按既有权限可用，且不会误显示给他人。
- [ ] 资料请求成功、失败、重试、刷新、返回、切换用户和切换语言均无白屏或控制台渲染错误。
- [ ] 帖子数量超过单页上限时可以完整浏览，统计数与可见列表一致。
- [ ] 非法用户地址不会打开其他用户资料，公开广告帖不会出现在普通帖子列表。
- [ ] Web 浏览器和 Capacitor APK 至少各完成一轮真实设备/运行环境回归，并记录截图、接口响应和控制台错误结果。
- [ ] 现有用户路由测试、公开字段测试和新增页面渲染测试全部通过。
