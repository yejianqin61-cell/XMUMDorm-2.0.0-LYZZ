# 04 - 帖子分页与统计一致性

**What to build:** 让个人空间的帖子列表支持完整连续浏览，并使帖子总数与实际可见列表使用同一套过滤规则。

**Blocked by:** 02 - 公开资料响应字段白名单

**Status:** ready-for-agent

- [ ] 前端请求页大小不超过服务端契约上限，服务端返回的页码、页大小和是否还有下一页含义一致。
- [ ] 当存在下一页时，个人空间提供明确的加载更多或分页操作；加载过程中保留当前内容，不重复插入帖子。
- [ ] 加载下一页失败时显示可重试状态，不清空已加载内容。
- [ ] 帖子统计只计算资料页可见的帖子，排除已删除、管理员隐藏和广告帖。
- [ ] 空列表、单页列表、恰好一页、超过一页和最后一页场景均有验收覆盖。
- [ ] App 与 Web 的列表排序、去重、图片和详情跳转行为保持一致。
