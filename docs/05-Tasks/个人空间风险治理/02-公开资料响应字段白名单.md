# 02 - 公开资料响应字段白名单

**What to build:** 收紧公开个人资料接口的响应契约，确保未登录或查看他人资料时只返回公开展示所需字段，不泄露邮箱、学号、账号状态和其他联系信息。

**Blocked by:** None - can start immediately.

**Status:** ready-for-agent

- [ ] 未登录访问公开资料时，响应不包含邮箱、学号、账号状态、认证信息或其他非展示字段。
- [ ] 本人访问公开资料时仍能正常看到公开资料页所需的基础信息，不依赖公开响应返回私密联系字段。
- [ ] 头像、昵称、等级展示字段保持兼容，现有帖子作者渲染不出现空白或字段缺失。
- [ ] 公开资料响应使用显式字段白名单，未来新增用户表字段不会自动进入响应。
- [ ] 后端测试覆盖未登录、他人登录和本人登录三种访问者，并断言字段集合而非仅断言状态码。
