# 01 - 个人空间稳定渲染与状态分支

**What to build:** 修复个人空间在资料请求完成后可能白屏的问题，并统一加载中、成功、失败、无效用户和语言切换时的稳定渲染行为。

**Blocked by:** None - can start immediately.

**Status:** ready-for-agent

- [ ] 个人空间所有 Hook 在任意渲染分支中保持相同调用顺序，不因加载态或错误态提前返回而改变。
- [ ] `/user/:id` 首次加载、成功返回资料、请求失败和用户不存在时分别显示对应状态，不出现空白页或 React Hook 错误。
- [ ] 请求重复触发、组件卸载和路由切换时不会用旧请求覆盖新用户资料。
- [ ] 中英文切换不会造成资料状态丢失、重复请求竞态或渲染崩溃。
- [ ] App 与 Web 使用相同的状态行为，并补充至少一个成功渲染和一个失败渲染回归测试。
