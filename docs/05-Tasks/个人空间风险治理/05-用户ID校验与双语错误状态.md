# 05 - 用户 ID 校验与双语错误状态

**What to build:** 收紧个人空间用户 ID 的输入校验，并清理个人空间中的中英混杂和技术型错误文案。

**Blocked by:** 01 - 个人空间稳定渲染与状态分支

**Status:** ready-for-agent

- [ ] 客户端只对完整正整数用户 ID 发起资料请求。
- [ ] 服务端拒绝带前后缀字符、小数、负数、空值和超出有效范围的用户 ID，不把它们解析为其他用户。
- [ ] 无效地址显示本地化的用户不存在状态，并提供返回入口。
- [ ] 中文模式下不出现英文标题、技术错误文本或原始接口字段名。
- [ ] 英文模式下不出现中文标题、乱码或技术错误文本。
- [ ] 图片加载失败使用本地化的用户可理解提示，不显示 `image error` 等内部文案。
