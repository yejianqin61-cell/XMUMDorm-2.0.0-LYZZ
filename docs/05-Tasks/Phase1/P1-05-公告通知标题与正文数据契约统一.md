# P1-05 - 公告通知标题与正文数据契约统一

## Parent

GitHub Issue #5：补全公告弹窗与信箱展示内容链路

## What to build

统一管理员公告发布入口产生的通知数据，使标题、正文、公告帖子 ID、发布者和时间在未读弹窗、信箱列表和公告详情中使用同一语义。兼容现有历史通知，缺少正文时提供明确的安全回退。

## Blocked by

None - can start immediately.

## Acceptance criteria

- [ ] 管理员所有支持的公告发布入口都写入统一的标题和正文数据。
- [ ] 通知列表接口和未读公告接口返回一致的公告识别字段、目标帖子和正文信息。
- [ ] 新旧通知格式均可被前端识别；历史通知缺少正文时不显示 raw JSON、`undefined` 或错误的互动通知文案。
- [ ] 公告只创建给符合现有业务规则的用户，不能因统一字段改造扩大通知收件人范围。
- [ ] 标题、正文、发布者、时间和详情路径的字段语义形成简短契约说明，并有接口级验证样例。
