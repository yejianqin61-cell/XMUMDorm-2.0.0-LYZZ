# P1-02 - App 帖子详情页面横向锁定

## Parent

GitHub Issue #4：统一 App 帖子详情原生浏览体验

## What to build

在 App 共享详情容器和页面布局层建立统一的横向锁定行为。帖子详情只能沿垂直方向阅读，左右滑动不得移动页面、显示相邻页面或触发浏览器式历史导航；图片轮播和全屏图片预览仍由各自组件处理。

## Blocked by

- P1-01 - 帖子详情横向位移现状盘点与交互边界

## Acceptance criteria

- [ ] 页面在左右滑动时始终贴合设备视口，无横向滚动条、横向溢出或页面平移。
- [ ] 页面级左右滑动不会改变路由、显示相邻 Tab 或触发非预期返回/前进。
- [ ] 详情页的垂直滚动、评论输入、点赞、举报、删除和链接点击不受影响。
- [ ] 多图帖子在媒体区域左右滑动仍能切换图片，图片预览可正常打开和关闭。
- [ ] 桌面 Web 端不因 App 的锁定策略失去正常浏览能力。
