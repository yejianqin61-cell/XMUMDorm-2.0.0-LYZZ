# Phase 1 治理任务

本目录对应 GitHub Issue #4、#5，仅覆盖 Capacitor App 上线前的两项治理目标：

- Issue #4：统一 App 帖子详情原生浏览体验
- Issue #5：补全公告弹窗与信箱展示内容链路

任务按阻塞关系编号。每个 Task 应完成一条可独立验证的用户路径；实现时不应修改已废弃的 `mobile` RN 前端。

## Issue #4

1. `P1-01` 帖子详情横向位移现状盘点与交互边界
2. `P1-02` App 帖子详情页面横向锁定
3. `P1-03` 多类型帖子详情入口统一迁移
4. `P1-04` 帖子详情 Capacitor APK 回归验收

## Issue #5

1. `P1-05` 公告通知标题与正文数据契约统一
2. `P1-06` 未读公告弹窗完整展示与已读操作
3. `P1-07` 信箱公告文本与详情跳转治理
4. `P1-08` 公告链路端到端回归验收
