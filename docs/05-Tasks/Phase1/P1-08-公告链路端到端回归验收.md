## What to build

从管理员发布公告开始，验证普通用户收到公告、看到弹窗、在信箱阅读并进入详情、完成单条或批量已读后的完整链路。覆盖 App 和 Web 共享后端下的关键兼容场景。

## Blocked by

- P1-07 - 信箱公告文本与详情跳转治理

## Acceptance criteria

- [ ] 使用管理员账号分别验证所有公告发布入口，确认普通活动账号收到对应通知。
- [ ] 验证未读公告接口、登录弹窗、信箱全部/系统分类、公告详情和已读接口的完整顺序。
- [ ] 验证刷新、重新登录、重复打开、单条已读、批量已读和发布多条公告后的状态一致性。
- [ ] 验证正文含长文本、换行、特殊字符、无正文和历史格式数据时，弹窗与信箱均不乱码、不溢出。
- [ ] 在 Web 浏览器和 Capacitor Android APK 各完成一次回归，并记录后端环境、账号角色和结果。
