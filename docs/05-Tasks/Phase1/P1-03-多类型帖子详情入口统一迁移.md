# P1-03 - 多类型帖子详情入口统一迁移

## Parent

GitHub Issue #4：统一 App 帖子详情原生浏览体验

## What to build

将所有帖子详情入口接入同一套页面级横向交互规则，避免某一种详情页仍保留网页式滑动体验。保持不同业务类型的标题、组织信息、评论能力、权限操作和返回路径不变。

## Blocked by

- P1-02 - App 帖子详情页面横向锁定

## Acceptance criteria

- [ ] 树洞、热搜、校园通知、社团帖子和社团活动详情均使用统一的页面级横向行为。
- [ ] 从广场信息流、热搜列表、校园今日、社团主页和信箱进入详情时，行为一致。
- [ ] 详情页返回后回到正确的来源页面和滚动位置，不被横向锁定逻辑改写。
- [ ] 业务专属组件（组织信息、活动报名、评论区、图片轮播）仍保持原有权限和操作语义。
