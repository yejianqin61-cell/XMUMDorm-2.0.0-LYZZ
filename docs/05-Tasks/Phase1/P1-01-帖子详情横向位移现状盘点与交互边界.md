# P1-01 - 帖子详情横向位移现状盘点与交互边界

## Parent

GitHub Issue #4：统一 App 帖子详情原生浏览体验

## What to build

建立所有 App 帖子详情页面的行为清单，确认哪些横向移动来自页面容器、路由切换、详情页动画或媒体组件。明确页面级手势与图片轮播、图片预览等组件级手势的边界，为后续统一治理提供验收基线。

## Blocked by

None - can start immediately.

## Acceptance criteria

- [ ] 覆盖树洞帖子、热搜帖子、校园通知、社团帖子、社团活动详情及其他复用帖子详情壳的入口。
- [ ] 在 Android 真机或 Capacitor 调试包中记录左滑、右滑、上下滚动、图片轮播、图片预览和返回操作的当前结果。
- [ ] 明确页面级横向手势必须被禁止，媒体区域允许保留的手势，以及系统返回键的预期行为。
- [ ] 输出一份回归用例表，后续 Task 以此为唯一交互验收基线。

## 2026-08-12 盘点结果

### 页面范围

| 内容类型 | 当前详情实现 | 是否需要纳入本期治理 |
| --- | --- | --- |
| 树洞普通帖子 | 独立详情页 | 是 |
| 热搜主题帖子 | 共享帖子详情壳 | 是 |
| 校园通知 | 共享帖子详情壳 | 是 |
| 社团日常帖子 | 独立社团详情页 | 是 |
| 社团活动详情 | 独立活动详情页 | 是 |

### 已确认的页面级边界

- 帖子详情容器目前没有统一的 `overflow-x` 与触摸轴约束，因此不能保证 App WebView 不会产生横向位移或系统浏览器手势。
- 主页 Tab 使用独立的横向位移轨道，但详情路由不属于该轨道；治理不得影响主页 Tab 切换。
- 图片轮播和全屏图片预览是唯一允许处理横向手势的详情内组件。它们的手势必须在组件范围内消化，不能传导为页面位移或路由导航。

### 回归基线

| 操作 | 预期 |
| --- | --- |
| 详情页空白内容区左右滑动 | 页面不横移、不换路由、不露出相邻页面 |
| 上下滑动 | 正常纵向阅读 |
| 多图媒体区域左右滑动 | 仅切换图片 |
| 图片预览打开/关闭 | 正常可用，关闭后回到原详情位置 |
| 评论框输入 | 输入、聚焦与键盘顶起正常 |
| Android 系统返回 | 返回进入详情前的来源页面 |
