## 4. 真实事务与故障注入

- 在真实 MySQL 事务中执行主记录、受众、图片关系、版本和版本图片 SQL；仅在准备执行快讯审计 INSERT 时，通过测试连接包装器抛出受控错误。验证审计前版本 SQL 确实执行过，随后主记录、受众、当前图片、版本、版本图片、审计六类表数量均回到事务前值。
- 这是“真实 MySQL + 注入失败”，不是生产故障，也没有篡改数据库 schema、建立故障触发器或杀死服务。
- 在真实资产 pending 记录已建立后，测试磁盘适配器在写文件前抛错；数据库状态变为 failed。没有自动删除文件或资产记录。
- 对真实已存在对象再次调用不可变磁盘存储的 put，返回 EEXIST，原文件字节完全不变。
- 逐帖核对版本数量等于 revision，审计数量等于版本数量，revision 连续，审计 version_id 正确，最新快照与当前标题、正文、生命周期、隐藏/删除状态、受众和图片顺序一致。
- 未模拟真实断电、网络中断、MySQL 崩溃或全部磁盘满场景；没有证明所有故障组合都已穷尽。
