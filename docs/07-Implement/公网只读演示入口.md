# 公网只读演示入口

2026-10-30：按用户要求提供异地可访问的新版广场和校园快讯管理预览。

本次临时地址：`https://mazda-fiber-pci-illustrations.trycloudflare.com`。

- `/about`：新版广场，读取现有本地测试快讯。
- `/myzone/admin/campus-news`：快讯列表、筛选、详情、版本。
- `/myzone/admin/campus-news/new`：发布编辑表单。

底部固定切换入口；访客自动使用演示身份。仅展示测试数据，不连接生产数据库。
服务端拦截全部非 GET/HEAD 请求，返回 403，不允许访客保存、发布、删除、点赞或发送评论。
网关仅代理校园快讯及必要身份读取接口；其他后台模块未开放数据接口。
真实管理员 JWT 和已有测试账号密码仅在本地网关内使用，不发送到浏览器；浏览器存储的是无授权作用的演示标记。
仅发布编译产物，不公开 Vite 文件服务、源码目录或 `.local`。

## 启动与更新

分别在项目根目录运行，保持进程存活：

```powershell
node scripts/stage2-local/launch.cjs backend
node scripts/stage2-local/build-public-demo.mjs
node scripts/stage2-local/public-demo.cjs
.local/public-demo/cloudflared.exe tunnel --url http://127.0.0.1:8787 --no-autoupdate --protocol http2
```

构建只在需要更新前端时运行。后端绑定本地4040，演示网关绑定本地8787。
现有本地配置和测试凭据沿用忽略目录内的文件，不需要录入生产配置。
Cloudflare Quick Tunnel 重新启动会产生新的临时域名；电脑关闭、断网或相关进程结束后，链接不可用。
这不是独立云部署或长期托管站点。
