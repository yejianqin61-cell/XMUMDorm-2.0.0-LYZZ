# 校园助手 App 本地接入

2026-10-24。入口按所有者选择放在广场首页，四个模块入口下、二级标签上，进入独立原生页面 `/agent`。沿用 Expo Router、现有登录会话、主题令牌和中英文词条；没有新增底部主标签、依赖或原生工程。

## 已实现

- 原生消息列表、Markdown 回答和流式接收；输入框无占位文字，另有读屏标签。
- 每次离开后重新进入都是空白新对话，首次发送时才创建后台会话。
- 右上角打开历史记录，支持恢复、删除、撤销删除；与 Web 共用同一账号的历史。
- 复用 Web 的政策、指南、个人课表、待办及放假日能力。课表和待办仍只查询。
- 账号退出时卸载聊天状态；历史和聊天正文不落到 App 本地存储，异步旧请求不能回填离开的页面。
- 进入后台或点击“稍后查看”会停止接收；回来读取后台已保存的结果，运行中的回答定时查询，不自动重复发送问题。停止接收不等于取消后台生成。
- 会话忙碌、额度用尽、需处理确认及服务不可用均有状态提示；后台生成或恢复读取期间阻止重复发送。

`app/src/features/agent/api.ts` 适配现有 `shared/api/agent.js`。JSON 沿用已注入的 API 地址和 token；流请求显式使用 `expo/fetch`，共享解析器只增加可选 fetch 注入，Web 默认行为保持原状。所有请求通过 Dorm `/api/agent`，App 不携带 Agent 内部密钥，不直接连接知识库或数据库。

为使历史弹层主体可被读屏访问，将 `BottomSheet` 的模态无障碍范围从标题扩展到整张弹层；`InputSheet` 增加独立的可选无障碍标签，不改变其他使用处的占位文字。

## 本地联调

先按同目录 `Web本地接入.md` 启动 Dorm 和独立 Campus Copilot 服务。现有本地启动器默认 Dorm 4040、Agent 8001；模型、知识库和个人数据回查配置均留在服务器。

在 App 目录通过进程环境指定 Dorm API 地址后启动：

```powershell
$env:EXPO_PUBLIC_API_BASE_URL = 'http://127.0.0.1:4040'
npm start
```

上面的回环地址只适合能直接访问该主机地址的运行环境。Android 模拟器可使用宿主机映射地址 `http://10.0.2.2:4040`；真机需使用手机可访问的开发服务地址，并确认该服务确实对手机开放。现有回环绑定的启动器不能仅通过改成电脑局域网 IP 就供真机访问。不要将内部密钥写入 `EXPO_PUBLIC_*`。

使用自己的 Dorm 账号登录，从广场进入校园助手。后端未部署或未配置 Agent 时，入口仍存在，接口返回服务不可用提示。正式发布仍需单独部署并配置 Agent 服务。

## 追加：继承的 CI 规则修复

PR 的首次线上检查确认，主分支已有的两项登录布局规则会使 App 全量单测失败：主题底色经局部变量简写后被源码扫描误判；窗口尺寸读取清单未登记既有 LoginLayout。颜色改为同一主题令牌的直接引用，保持实际界面不变；同时补齐测试与安全区台账，不将窗口尺寸计算等同于平板适配验收。登录动画未包含在修复提交中。
