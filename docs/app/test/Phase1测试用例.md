## 1. 测试分层（沿用 Phase 0，**不另立一套**）

| 层 | 目录 / 形式 | 跑在哪 | Phase 1 新增覆盖 | 为什么不用别的层 |
|---|---|---|---|---|
| **① 纯函数单测** | `app/src/**/__tests__/*.test.ts` | Jest（`jest-expo`） | 分页状态机、筛选持久化、字段 DSL 校验、错误分类、课表解析、区域/榜单排序、TTL 计算、`unwrapArray` | 这些是**规则**；纯函数才能让它们进 CI |
| **② 组件渲染测** | 同上（RNTL 14，`render` 是**异步**，必须 `await`） | Jest | 四态渲染、骨架 props 契约、a11y label、匿名投影断链、命中区 | 需要断言渲染结果与 a11y 角色/状态 |
| **③ 源码扫描测** | 同上（读文件 + 正则） | Jest | 0 `#hex` / 0 `fontSize:` 数字字面量 / 0 内联三元 / **0 平台分支 in `shared/`** / 0 第二套安全区或 store | 结构约束渲染测测不出来 |
| **④ 尺子（外部脚本）** | 仓库根 `scripts/*` | CI + 本地 | `design-debt-report` / `contrast-check` / `brand-ramp` / `gen-tokens` | 宪法 14.1 要求；⛔ **不得在测试里重实现** |
| **⑤ 真机人工** | 记录表（`安全区机型矩阵记录.md`、R1 结论） | 真机 | 两个切片的真机可用性、最大系统字号下的布局复验、WebView 会话跨重启 | 无真机不可替代 |

> **⛔ 两条纪律**（与 Phase 0 同）：层 ③ **只能**用来防止"已写好的规则被改回去"，⛔ 不得用来把不合规写法"扫过去"；层 ④ 的判据是**渲染出来对不对**，不是脚本变绿。

## 2. 测试接缝（**先写清测哪里，再写测试**）

Phase 1 的全部自动化用例**只落在下面 6 个接缝**上，⛔ 不对内部实现细节写测试：

| # | 接缝 | 公开接口 | 由谁提供 |

| **S-4** | 纯规则 | 分页状态机 / DSL 校验 / 错误分类 / 排序 / TTL / 解析 | P1-02、P1-06、P1-15…17 |
| **S-5** | 结构约束 | 源码扫描（正则） | 全部 |
| **S-6** | 构建产物 | `tsc` / `jest` / `expo export` / 四把尺子 | 全部 |

## 5. 宪法条款 → 用例映射（Phase 1 部分）

| 条款 | 判据 | 用例 |
|---|---|---|
| 9.5 / 9.11 组件被真消费 | 第 0 批每个组件 `引用 ≥1`；`ownUiComponentRefs ≥1` | 尺子 `rulers:debt` + 各组件任务 |

## 6. 运行方式（本地 = CI 同一套）

```bash
cd app && npx tsc --noEmit      # 层 ⑥ 类型
cd app && npx jest --ci          # 层 ①②③
cd app && npm run rulers         # 层 ④（四把尺子）
cd frontend && npx vite build    # P1-01 的 Web 不回归证据
```
