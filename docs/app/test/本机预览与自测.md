# App 本机预览与自测

**日期**：2026-11-14　**版本**：v1.0
**性质**：test 层工具手册。对应第三期治理目标的前置条件：**先让 agent 能看见 App、能自己点、能自己判断坏没坏**，再谈逐页治理。
**工具**：[`app/tools/preview/devicectl.mjs`](../../../app/tools/preview/devicectl.mjs)（零依赖 Node 脚本）· agent 入口：[`.claude/skills/app-preview/SKILL.md`](../../../.claude/skills/app-preview/SKILL.md)

## 1. 它解决什么

之前的验收记录写着"无真机证据"、"development build 未产出"（[Phase3-Task01](../evaluation/Phase3-Task01-development-build记录.md)）。根因是**本机没有一条能出画面的通道**，agent 只能跑单测和 typecheck，看不见界面。

现在这条通道是：

```
Android 模拟器（Pixel_API35） ← adb → devicectl ← agent / 人
        ↑ debug 原生壳（一次构建）
        ↑ JS 从 Metro :8081 实时取（改代码即热更新，不用重建）
        ↑ 接口走 EXPO_PUBLIC_API_BASE_URL（local / prod）
```

agent 用 `shot` 拿截图（用 Read 打开即可"看见"），用 `ui` 拿当前页的元素树与坐标，用 `tap / type / scroll / key` 操作，用 `logs` 与 `smoke` 判断有没有崩。

## 2. 第一次跑（在 `app/` 下）

```bash
npm ci
node tools/preview/devicectl.mjs doctor
node tools/preview/devicectl.mjs boot
node tools/preview/devicectl.mjs build
node tools/preview/devicectl.mjs metro --api prod
node tools/preview/devicectl.mjs reverse
node tools/preview/devicectl.mjs restart
node tools/preview/devicectl.mjs smoke
```

之后日常只要一条：`node tools/preview/devicectl.mjs up --api prod`（或 `--api local`）。
也可以 `npm run preview -- <命令>`。

### 什么时候要重新 `build`

| 改动 | 要不要重建原生壳 |
|---|---|
| `src/**` 的 TS/TSX、样式、词条 | ❌ 不用，Metro 热更新；看不到变化就 `restart` |
| `app.json`、`plugins/**`、新增/升级带原生代码的依赖 | ✅ 要（`build` 检测到这些变化会先自动 `expo prebuild`；`--prebuild` 可强制） |
| `package-lock.json` 变化 | ✅ 要（镜像目录会自动 `npm ci`） |

## 4. 后端：`--api local` 与 `--api prod`

| 模式 | 起法 | 数据 | 用途 |
|---|---|---|---|
| **A · 本机后端 + 生产库**（团队日常做法） | `devicectl backend start --prod-db` → `devicectl metro --api local` | ⚠ **线上** | 改了后端代码要连着 App 一起看。跑的是**本 worktree 的后端代码**，env 取主检出的 `.env`（等价根目录 `npm start`），后台定时任务强制关闭 |
| **B · 线上后端** | `devicectl metro --api prod` | ⚠ **线上** | 只改前端时最省事 |
| **C · 本机后端 + 隔离库** | 见下表五步 | 本地 `xmumdorm_preview` | 要放开手脚写数据（发帖、下单、删改）时 |

**线上数据的写守卫**：A、B 两种模式下，`devicectl tap` 落到「发布 / 提交 / 发送 / 下单 / 支付 / 删除 / 保存 / 接单 / 举报 / 注销 …」类按钮时**直接拒绝**（按文字或坐标点都会反查落点控件；底栏的发布格只开发布中心，不拦）。确需写入时加 `--allow-write`，并在汇报里写明写了什么、写到哪。
**登录**：`devicectl login` 读 `app/.preview/test-account.json`（gitignore）。线上数据下这个文件由所有者放一个**专用测试账号**；⛔ 不用任何人的真实账号。C 模式下由 `backend seed` 自动生成。

⛔ **不要直接用仓库根目录的 `.env` 起本机后端**：里面的 `MYSQL_URL` 指向云上数据库（`database.js` 优先读 `DATABASE_URL` / `MYSQL_URL`），同时配了对象存储和发信，起来就等于对线上读写。

C 模式用 [`scripts/preview-backend.js`](../../../scripts/preview-backend.js)（`devicectl backend …` 是它的转发；A 模式的 `start --prod-db` 也在这里）：

| 步骤 | 命令 | 做什么 |
|---|---|---|
| 1 | `devicectl backend init --from <含本地 DB_* 的 .env>` | 生成仓库根 `.env.preview`（gitignore）：**只抄** `DB_HOST/PORT/USER/PASSWORD`，库名固定 `xmumdorm_preview`，JWT_SECRET 新随机 |
| 2 | `devicectl backend db` | 建库，跑 `init-db.sql` + 全部 `migrations/*.sql`（幂等） |
| 3 | `devicectl backend seed` | 建已验证的测试学生账号，凭据写在 `app/.preview/test-account.json`（gitignore） |
| 4 | `devicectl backend start` | 起 `:4040`，日志 `app/.preview/backend.log` |
| 5 | `devicectl metro --api local` → `devicectl login` | App 连本机后端，并用测试账号自动登录 |

护栏（写死在脚本里）：`DB_HOST` 必须是本机、`DB_NAME` 必须含 `preview`；启动时把 `MYSQL_URL / DATABASE_URL`、对象存储、SMTP/Resend、Moodle 账号、GitHub token、VAPID、后台定时任务**全部强制置空**。上传因此回退到本地磁盘，邮件不会发出。`backend reset` 只会删预览库。

## 5. Windows 长路径（为什么有 `D:\xmdb\…`）

RN 原生库（screens / worklets / reanimated）的 CMake 会把源文件绝对路径拼进 `.o` 文件路径，上限 250 字符。worktree 路径（`…\.claude\worktrees\<名字>\app`）本身就 150 字符，Gradle 必然报 `ninja: manifest 'build.ninja' still dirty after 100 tries`。

试过、**不可行**的办法：
- `subst` 盘符 / 目录联接：Node 会 `realpath` 回长路径，Gradle 报 `this and base files have different roots`。
- 开系统长路径：ninja 仍不认，且属系统设置改动。

**采用的办法**：`build` 在 Windows 深路径下，把 `app/` 源文件（不含 `node_modules / android / .preview`）用 robocopy 镜像到 `<盘符>:\xmdb\<6 位哈希>`，在那里 `npm ci` + `expo run:android`。
debug 包运行时从 Metro 取 JS，**Metro 仍然从真实工作目录启动**，所以改代码立刻生效，镜像只承担原生壳。
用 `PREVIEW_BUILD_DIR` 可以指定别的目录。镜像可随时删除，下次 `build` 会重建。

## 6. 已知限制

| 限制 | 现状 / 绕法 |
|---|---|
| 中文输入 | `adb input text` 只支持 ASCII。需要中文时，在测试代码里预置数据，或装 ADBKeyboard（未纳入，需走依赖准入） |
| iOS | 本机是 Windows，无 Xcode；iOS 仍只能靠 EAS 或 macOS |
| 校方系统（AC / Moodle / 签到） | 只在校内网络可达（[R3 结论](../evaluation/R3-校方系统内嵌可行性结论.md) D-08），模拟器在校外看不到真实页面；这几页的验收仍需校内真机 |
| 推送 | 模拟器镜像是 `google_apis`，本地通知可测；FCM 远程推送未接 |
| 生物识别 / 相机 | 模拟器只能模拟，不作为验收证据 |
| 旧系统版本 | 另有 AVD `Pixel_7haha`（Android 13）。校方证书类问题必须在它上面复测（Android ≤13 的系统根库缺 Sectigo R46/E46）。启第二台：`emulator -avd Pixel_7haha -port 5556 -no-window`，再 `adb -s emulator-5556 install -r <镜像>/android/app/build/outputs/apk/debug/app-debug.apk` + `adb -s emulator-5556 reverse tcp:8081 tcp:8081` |
| Git Bash 里的深链 | Git Bash 会把 `/tools` 改写成 `C:/Program Files/Git/tools`；跑 `launch` 前先 `export MSYS_NO_PATHCONV=1`，或用 PowerShell |
