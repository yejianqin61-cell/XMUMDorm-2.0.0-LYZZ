# research —— 做决定之前的调研

**本目录放什么**：**外部事实的取证**与**方案对比**。回答"**凭什么这么定**"里的"**证据在哪**"。
**本目录不放什么**：我们自己的验收结果（→ [`../test/`](../test/)）、对已定方案/已跑系统的**评估判定**（→ [`../evaluation/`](../evaluation/)）。

> **判据（一句话）**：这份文档是**为了决定**而写的（查事实、比方案）→ `research/`；是为了**判定某个已经存在的东西**好不好而写的（准入评估、专项自评、审计、复盘）→ `evaluation/`。

## 二、读法纪律

1. **数值来源标注**：`【已定】`（所有者裁决 / 官方原文 / 实测）、`【算得】`（由实测机械推导）、`【提案】`（**待复核，不得当已验证规格使用**）。
2. **读到 `【提案】` 时不要当规格用。**
3. **本目录的结论不是宪法**。凡被宪法或页面清单采纳的，**以那两份为准**；本目录的旧结论若与它们冲突，**冲突处一律以宪法为准**（宪法 15.3.1）。
4. ⚠️ **调研-03 的 IA 建议已被取代过多次**（发布 FAB → 顶栏信箱 → 四格 → **五格**）。引用它时**只引能力面与端点事实，不要引它的 IA 结论**。
5. **新增调研一律落在本目录**，命名格式 `App<主题>调研-<子题>.md`；不要放回 `docs/06-Analyze/`。
