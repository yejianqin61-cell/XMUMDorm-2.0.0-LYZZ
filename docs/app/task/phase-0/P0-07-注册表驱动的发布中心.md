## 1. 目标

把"发布中心"做成**数据驱动的注册表**：⛔ 不得把七类发布动作硬编码成七个按钮；**新增一类发布 = 注册表加一条**，⛔ 不改导航壳、不改布局、不改底栏（宪法 4.9.5）。

## 2. 依据

- 宪法 **4.9.5**（注册表：`{ id, 标题词条, 图标名, 权限判据, 目标表单页 }`；**权限过滤由后端布尔字段驱动**，UI 不得自行推断）
- 宪法 **4.9.3**（入口唯一，⛔ 不得保留第二个发布入口）· **4.9.8**（A-05 合规门禁仍挂在**每个发布表单的提交链路**上）
- 宪法 **1.4**（一改全部改）· **16.1/16.5**（发布中心条目图标 = 第 1 层 **Lucide**，逐图标子路径导入，⛔ 禁 barrel）
- 骨架规范 **§3.5**（注册表四项要求）· **§3.6**（FAB 处置：S-01/S-17/C-01 的发布 FAB 删除）
- [TODO](../../TODO.md) **TD-01 拼车 / TD-02 问答**（后端未建 → 正是注册表存在的理由）

## 4. 实现要点

### 4.1 条目契约

```ts
type PublishEntry = {
  id: string;                    // 'confession' | 'marketplace' | ...
  titleKey: MessageKey;          // 词条（⛔ 不写字面量）
  icon: string;                  // Lucide 逐图标子路径名（16.5）
  permission: (v: Viewer) => boolean;   // ⛔ 只读后端布尔字段
  route: string;                 // 目标表单页；⛔ 必须存在
  status: 'ready' | 'planned';   // planned = 后端未建（拼车/问答）
};
```

### 4.2 四条硬纪律

1. **一一对应**：注册表里有 `route` ⇒ 路由存在；路由存在但注册表没有 ⇒ **不许出现在界面上**（含灰度/占位）。用**一致性校验函数**保证（构建期跑，测试断言）。
2. **权限由后端布尔驱动**：`permission` 只读 `viewer.*`（如 `viewer.canManageClub`、`viewer.isOrgMember`），⛔ 不含任何本地推断（如"帖子数 > 3 就能发活动"）。
3. **入口唯一**：全仓扫描 `发布`/`publish` 的**入口**只有第 5 格 + 发布中心内条目；⛔ 无 FAB、⛔ 无第二处入口（宪法 4.9.3）。
4. **合规门禁在提交链路上**（⛔ 不是注册弹窗）：`complianceGate.canSubmit(viewer)`；未接受条款时**每个**发布表单提交前都会被拦。

### 4.3 图标（第 1 层）

- 逐图标子路径导入：`import X from 'lucide-react-native/icons/<kebab-name>'`（⛔ 禁 barrel：Lucide RN 官方说明 tree-shaking 对 barrel 不可靠）；
- **图标名必须来自已核实名单**（[图标方案调研](../../research/App图标方案-Lucide与平台图标.md) 的 20 条缺口替换）→ ⛔ 不得凭记忆写 `filter` / `more-horizontal` / `alert-circle` / `trash-2`；
- 每个条目**必须同时有文字标签**（图标不得承担唯一语义，宪法 16.2-4）。

## 5. 验收标准

| # | 判据 |
|---|---|
| G1 | 注册表条目数 ≥5 可发布 + 2 planned；**无任何硬编码按钮数组**（条目只能来自注册表） |
| G2 | 每条 `id` 唯一；`route` 唯一；`titleKey` 在 zh/en 字典中都存在 |
| G3 | `visibleEntries(viewer)`：`planned` 条目**永不出现**；权限为 false 的条目**不出现**（且不显示为禁用占位） |
| G4 | 一致性校验：注册表 route 集合 ⊆ 实际路由集合；无"有路由未注册"的发布表单 |
| G5 | 权限判据全部读 `viewer.*` 布尔字段（源码扫描：注册表内无比较运算如 `length >`/`count >=`） |
| G6 | 全仓**只有一处**发布入口（第 5 格）+ 注册表条目 |
| G7 | 每个条目有 `titleKey`（文字标签）与 Lucide 子路径导入；⛔ 0 处 barrel 导入 |
| G8 | `complianceGate.canSubmit()` 未接受条款 → 返回拦截 + 可改正动作 |

## 7. 风险与降级

| 风险 | 降级 |
|---|---|
| 社团活动/校园帖的权限字段后端没有 | 该条目 `permission` 读不到布尔字段 → **默认不可见**（⛔ 不猜"应该可以"）并登记 TD（后端补字段） |
| 拼车/问答后端未建 | `status: 'planned'`，**永不显示**（宪法 4.9.5-4）；TD-01/TD-02 跟踪 |
