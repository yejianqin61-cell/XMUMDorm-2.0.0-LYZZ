# P0-11 · 四把尺子接入 CI

| 项 | 值 |
|---|---|
| 负责人 | 甲 |
| 依赖 | P0-01…P0-08 |
| 写作用域 | `.github/workflows/app-rulers.yml` · `app/package.json`（`scripts`）· 本文件 |
| 状态 | ⏳ |

## 1. 目标

把宪法 **14.1** 的"四把脚本必须接入 CI，作为合并门"落成**可跑的工作流**，并让 **App 自己的单测**也进同一条门。

## 2. 依据

- 宪法 **14**（验证门槛表）· **14.1**（四把脚本接入 CI）· **11.2**（CI 用 `EXPO_TOKEN` 非交互认证）
- 生产计划 §2（甲：CI 跑四把尺子）

## 3. 四把尺子的**正确调用口径**（⛔ 写错会永远红或永远绿）

| 尺子 | 命令 | 说明 |
|---|---|---|
| 设计债 | `node scripts/design-debt-report.js --path app/src --fail-on-zero` | 判据：`#hex`=0 · `fontSize` 字面量=0 · 自有 UI 组件引用 ≥1 · 内联双语三元=0 · `t('key')` ≥1 |
| 对比度 | `node scripts/contrast-check.js --file tokens/generated/tokens.check.json --fail` | ⚠️ **必须带 `--file`**，否则走内置候选预设会永远红 |
| 品牌色阶 | `node scripts/brand-ramp.js --hue 261.2 --fail` | ⛔ `--compare --fail` 被脚本拒绝（退出码 2） |
| 令牌生成 | `node scripts/gen-tokens.js --check` | `--check` 为**只读**校验；`textSafe` 逐个实测达标 |

## 4. 交付物

| 文件 | 说明 |
|---|---|
| `.github/workflows/app-rulers.yml` | 两段 job：`rulers`（四把）· `app-tests`（`npm ci` + `npx tsc --noEmit` + `npx jest`） |
| `app/package.json` | `scripts`：`test` / `typecheck` / `rulers`（一条命令跑四把，便于本地复现） |
| `docs/app/task/phase-0/P0-11-*.md` §7 | 本地复现命令（CI 能跑的，本地必须同样能跑） |

## 5. 实现要点

1. **触发**：`pull_request` + `push` 到 `main`；`paths` 过滤（`app/**`、`tokens/**`、`scripts/**`）。
2. **Node 版本**：`node-version: 22`（宪法 3.1 要求 ≥22.13；本机 24 亦可，CI 钉 22 LTS 线）。
3. **⛔ 不需要 `EXPO_TOKEN`**：四把尺子 + 单测**不碰 EAS**；需要 EAS 的构建是**独立**工作流（本轮不建，避免把"能跑测试"与"能发构建"耦合）。
4. **失败即红**：四把**分别**一步，任一步非 0 即失败（⛔ 不用 `|| true` 掩盖）。
5. **本地一条命令**：`cd app && npm run rulers` → 在 `app/` 里跑仓库根的四个脚本（相对路径 `../scripts/...`）。
6. **不缓存凭据**：`actions/setup-node` 的 npm cache 即可；⛔ 不写任何 secret。

## 6. 验收标准

| # | 判据 |
|---|---|
| K1 | 四把尺子**各自一步**，无 `continue-on-error`、无 `|| true` |
| K2 | `npm run rulers` 本地 exit 0；四把的**参数与宪法 14 表逐字一致** |
| K3 | `app` 单测 job 存在且 `npm ci`（⛔ 不用 `npm install`，保证 lockfile 生效） |
| K4 | 工作流语法合法（YAML 可解析），且在 `app/**` 变更时触发 |
| K5 | CI 里没有 EAS secret 依赖（可跑即证明） |
