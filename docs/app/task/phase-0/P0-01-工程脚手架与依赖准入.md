## 1. 目标

在 `app/` 建出 **Expo SDK 57 线**的可编译工程：依赖版本**全部由 `npx expo install` 决定**（宪法 3.1，⛔ 禁止手写 npm latest），`android/`/`ios/` 保持 gitignored，EAS 通道配置就位。

## 2. 依据

- 宪法 **3.1/3.2/3.3**（SDK 57 = `expo@57.0.26` + RN `0.86.3` + React `19.2.3`；一律 `npx expo install`；禁 `next`/`canary`；⛔ 不保留 `newArchEnabled`）
- 宪法 **3.4 / 9.13**（依赖准入五项：许可证 / 是否含原生代码 / OTA 影响 / **最后发布时间（读该版本自己的时间戳，不用 `time.modified`）** / 是否强加视觉身份）
- 宪法 **11.1/11.2**（CNG + `prebuild`；`android/` `ios/` gitignored；构建走 EAS）
- 生产计划 §2（甲：`npx expo create` → `npx expo install` → EAS 项目）

## 3. 交付物

| 文件 | 说明 |
|---|---|
| `app/package.json` | `expo@57.0.26` 线；`scripts`：`start/android/ios/test/lint/typecheck/doctor` |
| `app/app.json` | `scheme`（深链必需）· `android.package` / `ios.bundleIdentifier` · `userInterfaceStyle: automatic`（暗/亮双主题）· `edgeToEdgeEnabled`（target 36 既定事实）· ⛔ 不写 `newArchEnabled` |
| `app/tsconfig.json` | 继承 `expo/tsconfig.base`；`strict: true`；路径别名 `@/*` → `src/*` |
| `app/eas.json` | `development` / `preview` / `production` 三个 profile；`preview` 出 **APK**（内测分发用） |
| `app/jest.config.js` | `preset: 'jest-expo'`；`roots: ['<rootDir>/src']`；只匹配 `**/__tests__/**/*.test.tsx?` |
| `app/.gitignore` | `.expo/` `dist/` `android/` `ios/` `*.jks` `*.keystore` `google-services.json` `GoogleService-Info.plist` |
| `docs/app/evaluation/App依赖准入登记.md` | **准入表**：每个直接依赖一行（五项判据 + 版本 + 取样来源） |

## 4. 实现要点

1. `npx create-expo-app@latest app --template expo-template-blank-typescript`（得到被 SDK 锁定的核心三元组）。
2. `npx expo install expo-router expo-linking expo-constants expo-symbols react-native-safe-area-context react-native-screens react-native-webview expo-secure-store expo-localization react-native-svg lucide-react-native`。
   - ⚠️ **`expo-symbols` 是硬依赖，不是可选**：R2 已核实 —— `unstable-native-tabs` 的 Android 图标走 `md="add"`（Material Symbols 名），由 `expo-symbols` 的 `unstable_getMaterialSymbolSourceAsync` 转成图；**缺了它 Android 底栏图标会静默空白**（不报错）。
   - ⛔ **不装**：`nativewind` / `restyle` / `unistyles` / 任何自带调色板的 UI kit（宪法 9.11）· 自绘 Tab 栏库 · `expo-linear-gradient`（宪法 1.3.5）· 第二套图标库（宪法 16.2）。
   - ⚠️ **`react-native-webview` 属"含原生代码"** → 按 11.4 登记：**引入后 OTA 不覆盖它的变更，必须重建**（P0-08 的准入依据）。
3. 主入口改为 `expo-router/entry`，`app.json` 加 `plugins: ['expo-router']` 与 `scheme`。
4. `npx expo-doctor` 必须无 fatal；`npx tsc --noEmit` 必须 0 error。
5. `.gitignore` 追加（根 `.gitignore` 已全局忽略 `node_modules/`）：`app/.expo/`、`app/dist/`、`app/android/`、`app/ios/`。
6. 依赖准入表逐条填 **最后发布时间**：`npm view <pkg> time --json` 里**该版本自己的时间戳**（⛔ 不用 `time.modified`，宪法 9.13）。

## 5. 验收标准

| # | 判据 |
|---|---|
| A1 | `cd app && npx tsc --noEmit` → exit 0 |
| A2 | `app/package.json` 里 `expo` = `57.0.26`、`react-native` = `0.86.3`、`react` = `19.2.3`（**三元组逐一核对，不许"差不多"**） |
| A3 | `app/app.json` 里**没有** `newArchEnabled`；有 `scheme` |
| A4 | `git check-ignore app/android app/ios app/.expo` 三项都被忽略 |
| A5 | 依赖准入表**每个直接依赖一行**，五项判据齐全，无"未知"空格 |
| A6 | `npx expo-doctor` 无 fatal（warning 可登记） |

## 7. 风险与降级

| 风险 | 降级 |
|---|---|
| `create-expo-app` 拉到 SDK 58 模板 | 显式改用 SDK 57 的模板 tag；⛔ 不为了"省事"接受 58（宪法 3.2） |
| `react-native-webview` 与 SDK 57 不匹配 | 以 `bundledNativeModules.json` 为准；若无线内版本 → R3 走降级路径 A（外链 + 粘贴文本） |
| `npx expo-doctor` 报 warning | 记进本文件 §8 执行记录，不阻塞 |
