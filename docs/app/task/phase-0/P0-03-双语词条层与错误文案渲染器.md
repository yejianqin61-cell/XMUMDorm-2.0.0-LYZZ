## 1. 目标

建出**唯一**的双语词条层与**错误文案渲染器**：⛔ 屏内不得出现内联双语三元（`isZh ? '甲' : 'B'`，宪法 14 尺子会拦）；每条错误都必须能产出「**可感知 / 可理解 / 可改正**」三要素（宪法 10.4）。

## 2. 依据

- 宪法 **6.x**（双语、标签宽度按英文定尺寸、⛔ 不用截断掩盖放不下）
- 宪法 **10.4**（错误三要素 + 网络类必须分「无网络 / 服务不可达 / 超时」+ 技术细节不外泄）
- 宪法 **10.5**（文案纪律：按钮/标签 ≤6 汉字、标题 ≤12、正文说明 ≤30；⛔ 无说明性旁白、无"加载中…"占位废话）
- 宪法 **14**（尺子：`i18nInlineTernary` = 0、`t('key')` ≥ 1）

## 3. 交付物

| 文件 | 说明 |
|---|---|
| `app/src/i18n/zh.ts` / `en.ts` | **平坦 key → string** 字典（`tab.square` / `publish.title` / `error.net.offline.fix` …） |
| `app/src/i18n/index.tsx` | `I18nProvider` / `useI18n()` → `{ t, locale, setLocale, isReady }`；`t(key, params?)` 支持 `{n}` 插值 |
| `app/src/i18n/errors.ts` | `AppError` 分类 + `toErrorCopy(err, t)` → `{ perceive, understand, fix, actionKind }`（10.4 三要素） |
| `app/src/i18n/keys.ts` | `zh` 的 key 类型导出（`type MessageKey = keyof typeof zh`）→ **编译期拦缺词条** |

## 4. 实现要点

1. **key 类型化**：`t` 只接受 `MessageKey`，**缺词条是 TypeScript 错误**，不靠运行时兜底。
2. **缺词条运行时兜底**：dev 下 `console.warn` + 返回 key（⛔ **不返回空串**，空串会让界面出现"看不见的洞"）。
3. **`zh` 与 `en` 键集合必须完全相等**（用例断言）——这是"双语无缺词条"（DoIT 第 7 条）的机器判据。
4. **错误分类（10.4 的硬要求）**：
   - 网络类必须**三分**：`offline`（无网络）/ `unreachable`（服务不可达）/ `timeout`（超时）——**用户能做的事不同**；
   - 业务类：字段校验 / 权限 / 内容违规 / 冲突；
   - ⛔ **不外泄**：不显示 HTTP 状态码、堆栈、SQL、内部错误码原文；⛔ 也不得用"未知错误"掩盖已知原因；
   - ⛔ 禁止词表（尺子 + review 双查）：「出错了」「操作失败」「网络错误」「请稍后重试」「系统繁忙」。
5. **文案纪律**：按钮/标签词条 ≤6 汉字、标题 ≤12、说明 ≤30；⛔ 不写说明性旁白；⛔ 不写"加载中…"/"暂无数据"（空态必须有动作，宪法 10.2）。
6. **语言集合**：Phase 0 只落 `zh` + `en`（`ms` 是否预留 = TO-CONFIRM C-13，未定前不建空字典）。

### 8.1 与本文档原口径的差异

| 项 | 文档原口径 | 实际做法 | 原因 |
|---|---|---|---|
| 默认语言 | 未写 | 跟随系统；`normalizeLocale` 把非 `zh*` 一律收敛为 `en`；两者都缺失时回落 `zh` | **C-13（语言集合与默认语言）仍未拍板**，Phase 0 只落一个可实现、可改的默认 |
| 长度约束 | "按钮/标签 ≤6 汉字" | 测试按 **key 前缀**分类执行（`tab.` / `publish.entry.` / `action.` 为标签；`screen.` / `secondary.` / `publish.title` 为标题；`error.*` 按 10.5-6 豁免；`*Hint` 豁免） | 把"文案纪律"变成可运行的规则，而不是口头约定 |
| 词条层读系统语言 | 未写 | **不自己读** `expo-localization`，由根布局把 `systemLocale` 传进来 | 与主题层同构（单一真源 + 可测）；原生模块调用集中在根布局 |
