## 5. 十条验收清单（逐条打勾才结案）

- [ ] 顶栏背景铺满到屏幕顶边，内容从 inset 之下开始
- [ ] 底栏/手势条**没有**遮挡任何可点内容；且**没有**双倍空白
- [ ] 列表最后一项可完整滚动到可见区域（不被底栏压住）
- [ ] 键盘弹出时输入框与提交按钮**都可见**
- [ ] 横屏下左右内容不贴边
- [ ] `sw≥600dp` 下布局不是简单拉伸
- [ ] 每个模态/Sheet/Toast/WebView 页**各自**处理了 insets（S7）
- [ ] 暗色与亮色两种主题下**状态栏图标颜色正确**

- [ ] 上述机型/形态逐台通过

### 9.1 与本文档原口径的差异

| 项 | 文档原口径 | 实际做法 | 原因 |
|---|---|---|---|
| R7 结论成形 | §3 交付物只写"记录表 + 自动断言" | 记录表增加了**"自动已覆盖什么"**一列，把"已证的"与"待真机的"分开写 | 否则很容易把"规则过了"误读成"机型过了"，这正是 S1/S3 类缺陷的温床（测试机对、用户机错） |
| 结论措辞 | README §1 的 G4 要求三态结论 | 本任务给出 **"部分成立"** | 真机未跑就不能写"成立"；⛔ 也不写"未成立"（规则级已全过） |
