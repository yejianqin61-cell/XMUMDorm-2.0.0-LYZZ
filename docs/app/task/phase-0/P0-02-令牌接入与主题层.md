## 1. 目标

把 **`tokens/generated/native-tokens.ts`** 接成 App 唯一视觉来源：**业务代码只能消费语义令牌**（`colors[theme]` + `scale`），⛔ 不得按调色板档位取色、⛔ 不得在 `app/src` 出现 hex 或 `fontSize:` 字面量。主题跟随系统且可显式锁定（宪法 9.12-②）。

## 2. 依据

- 宪法 **2.1**（令牌是唯一事实源；生成产物不得手改）· **2.3**（每条色令牌六项元数据）
- 宪法 **2.5**（系统字体；**字阶不写绝对 pt 常量**，"数值分端生成"）
- 宪法 **9.12**（⛔ 运行期动态取色不作令牌取值；`colorScheme` 显式 lock，不用 `unspecified`）
- 宪法 **1.4**（全局组件化：视觉只能来自令牌或消费令牌的组件）
- 宪法 **14**（尺子：`#hex` = 0 · `fontSize` 字面量 = 0）

## 3. 交付物

| 文件 | 说明 |
|---|---|
| `app/src/design-system/tokens.ts` | 从根目录生成物**重导出**（`colors` / `colorsFor` / `scale` / `platformSeed` / 类型）；⛔ 不复制、不改写数值 |
| `app/src/design-system/px.ts` | `px('16px') → 16`：令牌里的 `"16px"` 是字符串，RN 要 number；**唯一转换点** |
| `app/src/design-system/theme.ts` | `ThemeProvider` / `useTheme()`；`Theme = { scheme: 'dark'\|'light', color: ColorToken 表, space, radius, borderWidth, touchTarget, motion }`；`scheme` 来自系统 `useColorScheme()`，可被显式覆盖（宪法 9.12-②） |
| `app/src/design-system/typography.ts` | **字阶角色**（`display/title/headline/body/label/caption/mono`）→ `{ role, weight, variant }`；⛔ **Phase 0 不含绝对字号**（见 §7 缺口） |
| `app/src/design-system/index.ts` | 聚合出口（`useTheme` / `tokens` / `px` / `typography`） |

## 4. 实现要点

1. **重导出，不复制**：`tokens.ts` 只做 `export { colors, colorsFor, scale, platformSeed } from '../../../../tokens/generated/native-tokens'`（路径按实际层级定）。⛔ 生成物**不得手工修改**（宪法 2.1 末句）。
2. **语义取值**：组件一律 `theme.color['text-primary'].value`；⛔ 不得写 `palette.brand[500]`（宪法 2.3 禁止"按档位推断"）。
3. **`textSafe` 是硬门**：任何承载文字的表面，其文字令牌 `textSafe` 必须为 `true`；`Text` 组件在 dev 下对 `textSafe=false` 的令牌打日志（不静默）。
4. **`px()` 唯一转换**：`scale.*` 全是 `"Npx"` 字符串 → 用 `px()` 转 number。⛔ 不允许在组件里写 `16`。
5. **主题切换**：`useColorScheme()` 给系统值；`ThemeProvider` 允许 `override`（供设置页"深色/浅色/跟随系统"三态，宪法 9.12-② 要求显式 lock）。
6. **Dynamic Type 前提**：`Text` 一律 `allowFontScaling` 默认 true，⛔ 不关掉系统字号放大（宪法 7.1）。

## 7. ⚠️ 已知缺口（必须登记，不得假装没有）

**字阶绝对值的唯一来源尚未建立。** 宪法 2.5-② 要求"字阶不写绝对 pt 常量，数值分端生成"，而 M3 官方字阶数值**必须人工读取**（宪法 15.2-1：m3.material.io 是 SPA，抓取只能拿标题）。因此：

- Phase 0 的 `typography.ts` **只声明角色与相对关系**（与 `tokens/design-tokens.css` §3.1 一致），**不发明数值**；
- 组件渲染时走平台默认字号 + 字重/颜色令牌区分层级，**登记为设计债**；
- 缺口登记：`docs/app/TODO.md` **TD-44**（M3 字阶表人工读取 + `gen-tokens.js` 分端生成字号），**归属 Phase 1 交付**（生产计划 §3 甲的"设计系统内测子集"）。

> ⛔ 不允许的"解法"：在 `app/src` 里写 `{ fontSize: 16 }` 凑绿尺子（宪法 9.11-3 的判据是"默认渲染是不是我们的视觉"，不是"脚本是否变绿"）。
