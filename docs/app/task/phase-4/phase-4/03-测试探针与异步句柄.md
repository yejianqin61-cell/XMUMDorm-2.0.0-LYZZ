# Phase 4 Task 03 · 测试探针与异步句柄

## 1. Where this task sits

- Phase 4 工程出口稳定化：修复测试探针问题并定位 Jest 未关闭异步句柄。
- This task moves R-8 让 verify 在资源边界内稳定完成 at the test lifecycle seam.
- Starts after：Task 01 baseline and Task 02 source fixes. Waits on：Task 04 verify boundary.

## 2. What the developer needs to know

**Read first**

- `app/package.json` — current Jest and verify scripts.
- `app/jest.config.*` — test environment and teardown settings.
- historical Phase 1/2 verification records — known open-handle evidence.
- Task 01/02 output — warning and test failures that must not be conflated.

**Settled**

- Diagnose real handles before lowering worker count.
- Do not add `--forceExit` as a substitute for cleanup.
- Test-only warning fixes must preserve the behavior the probe verifies.

**Edges and seam**

- Touches test helpers, test cleanup, and test scripts only. Leaves product code alone unless a real leak is proven there.
- Seam: Jest exit status and open-handle report.

**Run**

- Run the affected tests with `--runInBand --detectOpenHandles`.
- Run the same tests without diagnostic flags after each fix.

**Unknowns**

- If the handle comes from an external library or the environment, record proof and keep it separate from app leaks.

## 3. The workflow

1. Read this brief and restate the suspected lifecycle failure.
2. Reproduce the open-handle signal with the narrowest test set.
3. Identify the owning timer, listener, server, or mock.
4. Add the smallest cleanup at the owner seam.
5. Re-run diagnostic and normal commands.
6. Commit the cleanup and its regression evidence.

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | affected suite | exits without open handle | Jest lifecycle |
| 2 | cleanup path | cleanup runs once | test helper |
| 3 | normal suite | behavior remains green | Jest |
| 4 | unrelated suite | no new leak | Jest |
