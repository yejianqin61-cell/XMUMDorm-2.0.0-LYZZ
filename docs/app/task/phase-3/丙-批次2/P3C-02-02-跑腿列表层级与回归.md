## 1. Where this task sits

- **批次 2 服务列表完成**：跑腿要形成一致的二级页签和全宽任务卡体验。
- 本任务实现 FR-03：两行文字页签、全宽任务卡，并保持列表/详情主链路正确。
- **开始前**：批次 0 完成。**后续依赖**：甲接入广场入口与公共词条。

## 2. What the developer needs to know

**Read first**

- `app/src/features/errand/ErrandScreens.tsx` — 现有列表快照、详情权限和状态动作。
- `shared/api/errands.js` — 跑腿列表、详情、接单、完成与举报契约。
- `routes/errands.js` — 服务端状态机与错误返回。
- `app/src/components/ui/TopTabStrip.tsx` — 页签组件及其无障碍/滚动约束。

**Settled**

- 页签是两行可滚动文字和下划线，不使用胶囊分类按钮。
- 任务卡占内容宽度，不在窄屏或大屏缩在中心。
- 动作只由服务端状态驱动，不显示不能完成的伪操作。

**Edges and seam**

- 触及 `features/errand` 与业务契约适配；不修改公共组件、导航和鉴权。
- Seam：`ErrandListScreen`、`ErrandDetailScreen`。

**Run**

- `cd app && npm test -- --runInBand p2x-bing-market-errand`
- `cd app && npm run typecheck`

**Unknowns**

- 若二行页签需要公共组件新能力，停在需求清单，不复制新组件。

## 3. The workflow

1. 阅读入口并重述跑腿状态机。
2. 为页签层级与全宽卡写失败测试。
3. 使用现有公共页签与列表组件调整布局，保留筛选/分页状态。
4. 回归接单、完成、删除、权限拒绝和冲突反馈。
5. 补四态及无障碍验证。
6. 运行测试、typecheck，提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 类型和状态切换 | 文字页签可切换且不丢失对应列表状态 | `ErrandListScreen` |
| 2 | 窄屏/宽屏任务列表 | 卡片使用合理内容宽度 | 卡片布局 |
| 3 | 未登录接单 | 显示登录处理，不改变本地状态 | `ErrandDetailScreen` |
| 4 | 服务端 409 冲突 | 显示冲突反馈并可刷新 | 详情动作 |
| 5 | 完成或删除后返回列表 | 列表数据刷新且不进入已提交表单 | 查询缓存 |
