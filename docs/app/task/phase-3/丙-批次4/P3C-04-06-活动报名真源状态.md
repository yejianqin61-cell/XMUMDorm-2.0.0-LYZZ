# P3C-04-06 社团活动报名真源状态

## 范围

为社团活动详情提供可复用的报名状态 Hook；不接入页面、路由、国际化文案或公共组件。

## 验收

- 未登录时不请求报名接口，并给出 `login` 状态。
- 报名、取消报名只采用服务端返回的 `registered`、`count`、`deadline`，不得在客户端猜测人数。
- 401/令牌类 403 进入统一会话失效处理；带处罚标记的 403 仅为 `denied`。
- 同一请求期间不能重复提交；活动切换后忽略旧请求返回。
- 对错误响应结构拒绝更新状态。

## 证据

- 先写 Hook 测试，再实现。
- 运行对应 Jest 测试与 TypeScript 检查。
