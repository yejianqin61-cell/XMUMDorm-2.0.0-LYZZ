# P3C-04-02 社团发现 App 适配

## 目标

把 `/api/clubs/list` 的响应收敛为 App 可安全消费的分页领域模型；拒绝缺失主键、未知分类和伪分页响应。

## 边界

- 新建 `app/src/features/clubs/model.ts` 与对应单元测试。
- 不创建临时中文/英文文案；屏幕挂载与词条由甲统一接线。
- 不读取客户端推断的管理员权限。

## 验收

- 只接受服务端白名单分类与正整数主键。
- `hasMore` 必须是布尔值，分页字段必须合法。
- `viewer.following` 只能是布尔值；缺失或错误响应当作内容异常。
