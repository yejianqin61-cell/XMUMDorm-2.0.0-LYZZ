# P3C-04-01 社团发现真源

## 目标

为 App 社团发现页建立可分页、可搜索、可按服务端分类筛选的 `GET /api/clubs/list` 契约；不依赖 Web 端关键词猜分类。

## 范围

- `routes/clubs.js`：仅扩展既有社团列表读取端点。
- `shared/api/clubs.js`：透传 `category` 查询参数。
- `__tests__/routes/clubs.test.js`：先锁定分类、分页与非法输入行为。

## 不做

- 不改 App 路由、导航、共享 UI 或 i18n（甲负责）。
- 不改社团数据模型，不新增分类枚举。
- 不把客户端隐藏当作权限控制。

## 验收

1. `category=music` 只下推已白名单化的分类条件，响应行带 `category`。
2. 请求多于当前页一条时，返回 `hasMore: true` 且不泄露多取的行。
3. 非法分类返回 400，且不执行数据库查询。
4. 空页不构造 `IN ()` 关注关系查询。

## 验证

`npm test -- __tests__/routes/clubs.test.js --runInBand`
