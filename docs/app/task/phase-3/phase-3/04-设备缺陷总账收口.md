# Phase 3 Task 04 · 设备缺陷总账收口

## 1. Where this task sits

- Phase 3 设备证据与发布材料收口：让每个设备失败项都有唯一归属和复测条件。
- This task moves R-4 完成 13.1 development build 设备验收 from observations to traceable closure.
- Starts after：Task 02 and Task 03 observations. Waits on：Phase 3 acceptance record.

## 2. What the developer needs to know

**Read first**

- `docs/app/task/phase-2/甲-已知缺陷与更正总账.md` — current defect vocabulary.
- `docs/app/test/甲-逐屏13.1验收记录.md` — evidence rows to reconcile.
- `docs/app/test/乙-逐屏13.1验收记录.md` — second batch evidence rows.
- `docs/app/evaluation/Phase2收口验收记录.md` — external evidence boundary.

**Settled**

- One observed defect has one canonical id.
- Unverified is not pass.
- A defect is closed only with a retest condition and result.

**Edges and seam**

- Touches the existing defect ledger and acceptance indexes. Leaves implementation fixes to the task that owns them.
- Seam: the existing unique defect ledger.

**Run**

- Run link and duplicate checks over the acceptance records.
- Run affected tests only when this task exposes a missing test link.

**Unknowns**

- If the current ledger has no stable location or duplicate ids, stop before inventing a second ledger.

## 3. The workflow

1. Read this brief and restate the task as: reconcile observations with one defect ledger.
2. Enumerate failed and unverified rows from both device records.
3. Reuse existing ids or add one canonical row per new defect.
4. Add owner-independent repro and retest conditions.
5. Recheck that no row is marked pass without evidence.
6. Commit the ledger and index changes.
