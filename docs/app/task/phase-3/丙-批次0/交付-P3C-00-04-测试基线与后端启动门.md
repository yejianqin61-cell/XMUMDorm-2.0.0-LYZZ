## 后续变更必须遵守的启动门

1. 仅触及 App 业务屏幕/域 API：至少运行 `npm run typecheck` 与对应 Jest 用例；涉及 UI 状态时补充页面级行为测试。
2. 触及 `routes/**` 或 `shared/**`：除上述测试外，先确认文件保持 CommonJS（不得新增静态 `import`/`export`），再在隔离的本地数据库/端口环境执行实际 `node server.js` 与健康检查。
3. 绝不以 `--forceExit`、伪造健康响应或跳过真实启动来宣称通过。
4. 真机媒体、上传、日期控件、键盘、手势、原生 Clipboard/分享等，必须在开发构建或真机中留存证据；Jest 与 Web 页面不能替代。
5. 任何数据库验证先确认目标环境；默认不连接生产或 Railway 数据库。
