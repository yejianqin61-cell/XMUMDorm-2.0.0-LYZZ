# P3C-00-01 广场入口与路由接线清单

> 状态：已盘点（2026-10-10）  
> 依据：`Dormapp第三期治理目标.md`、`Phase3上线前收口改进工程计划.md`、`Phase3全面治理工程计划.md`；以下“现状”均以当前 `main` 代码为准。

## 结论

当前 App 已存在二手、跑腿、新生指南、树洞、万能墙的列表与详情页面；**社团没有 App 路由或页面**。现有 `/(tabs)/campus` 仍是旧的“校园里”一级 Tab，只承载树洞/万能墙，不能被当作 Phase 3 的新“广场”壳。广场一级入口、五格导航注册和新路由挂载由甲负责；丙交付下表所列业务屏幕与路由清单。

食堂虽属于广场入口，但由乙负责；丙不实现其业务页面。

## 甲需要完成的接线

1. 在 Phase 3 的“广场”一级屏内注册七个业务入口；其中食堂指向乙交付，其他六项指向上表的丙域屏幕。
2. 保持底栏五格定义不被丙直接修改；不要复用旧 `/(tabs)/campus` 作为新广场容器。
3. 从广场进入各列表、再进入详情时优先使用导航栈返回；只有无历史栈时才使用各业务屏已有的回退路径。
4. 社团路由在丙批次 4 交付屏幕导出和目标路径后再注册，不能在此阶段用空白占位页替代验收。

## 丙后续交付顺序

- 批次 2：补齐二手、跑腿、新生指南的页面能力后，复核现有 `/market`、`/errand`、`/guides` 接线。
- 批次 3：完成树洞、万能墙、话题能力后，复核 `/campus` 的过渡关系及详情返回行为。
- 批次 4：交付社团列表/详情/管理页面的屏幕导出、目标路由和参数表给甲。
