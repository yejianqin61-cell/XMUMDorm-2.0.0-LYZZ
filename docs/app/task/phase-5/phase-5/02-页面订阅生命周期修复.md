# Phase 5 Task 02 · 页面订阅生命周期修复

## 1. Where this task sits

- Phase 5 出口根因清偿：让 R-8 的页面订阅随组件卸载。
- 本 task 修复已确认的 `QueryCache.subscribe` 清理缺口。
- Starts after：Task 01 定位边界。Waits on：Task 03 完整 verify 回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/CampusScreens.tsx` — CampusFeed 订阅 effect。
- `app/src/features/errand/ErrandScreens.tsx` — ErrandFeed 订阅 effect。
- `app/src/features/marketplace/MarketScreens.tsx` — MarketFeed 订阅 effect。
- `app/src/shared/queryClient.ts` — QueryClient 单例边界。

**Settled**

- React effect 必须返回 unsubscribe；订阅不能跨卸载保留。
- 保持发布后刷新行为，不改 query key 和请求顺序。

**Edges and seam**

- Seam 是三个 feed 的现有 `useEffect` 订阅；不新增订阅抽象。
- 只修生命周期清理，保留既有刷新回调。

**Run**

- 相关 suite：`p2x-bing-campus*.test.tsx`、`p2x-bing-market-errand-*.test.tsx`。
- `npm.cmd run typecheck` 和 targeted Jest。

**Unknowns**

- 若最小复现指向别的资源，保留本修复并另开 task，不扩散修改范围。

## 3. The workflow

1. 读取三个 effect，确认每个订阅返回值可解绑。
2. 为卸载后的订阅行为补最小回归探针。
3. 先运行失败探针，证明旧代码仍会收到事件。
4. 返回 cleanup，保持回调逻辑不变。
5. 运行 targeted Jest、typecheck 和 detectOpenHandles。
6. 提交本 task 的代码与测试。

| Case | Input | Expected | Seam |
|---|---|---|---|

| 3 | mount then unmount MarketFeed | 订阅被解绑 | MarketFeed |
