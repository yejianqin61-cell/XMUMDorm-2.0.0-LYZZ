# Phase 1 Task 02 · 真实私信契约矩阵

## 1. Where this task sits

- Phase 1 真实私信链路恢复：目标是证明 M-11 在真实后端上可加载有效数据和空数据。
- This task moves R-1 恢复真实私信会话列表链路：把买家、卖家、空列表和权限错误固定成可复跑证据。
- Starts after：Task 01 跨商品会话列表路由核对。Waits on：M-11 页面真实联调。

## 2. What the developer needs to know

**Read first**

- `docs/app/task/phase-2/P2B-02-后端跨商品会话列表接口.md` — 接口字段和验收边界。
- `docs/app/task/phase-2/P2B-03-M11会话列表页.md` — 页面如何消费会话列表。
- `docs/app/test/甲-真实后端契约验证.md` — 当前真实环境的响应基线。
- 现有会话列表测试 — mock 数据和页面行为的边界。

**Settled**

- 真实 API 结果优先于 mock 结果。
- 空列表是正常业务状态，不转换成网络错误。
- 不在本任务实现消息历史游标。

**Edges and seam**

- 触及真实契约测试和会话列表消费；不改消息聊天页。
- Seam：现有 live backend contract 入口和 M-11 页面测试。

**Run**

- 运行 live backend contract 的会话列表用例。
- 运行 `npm.cmd test -- --runInBand --silent` 和 `npm.cmd run typecheck`。

**Unknowns**

- 真实账号可能缺少买家或卖家数据。若无法获得测试数据，记录缺失样本，不伪造通过。

## 3. The workflow

1. 阅读本 brief，并重述：固定四种真实私信列表响应。
2. 盘点现有契约测试的请求、认证和数据准备方式。
3. 补齐买家、卖家、空列表和无权限用例的独立断言。
4. 让 M-11 消费真实字段并保留空态与错误态。
5. 运行目标测试、全量串行测试和类型检查。
6. 提交本任务的单一变更。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 买家有效令牌 | 会话包含商品摘要和未读字段 | live backend contract |
| 2 | 卖家有效令牌 | 会话列表可返回并可进入详情 | live backend contract |
| 3 | 无会话账号 | 页面显示业务空态 | M-11 页面测试 |
| 4 | 缺失或过期令牌 | 页面显示可修正错误 | live backend contract |
| 5 | 后端字段缺失 | 不渲染技术性异常文案 | M-11 页面测试 |
