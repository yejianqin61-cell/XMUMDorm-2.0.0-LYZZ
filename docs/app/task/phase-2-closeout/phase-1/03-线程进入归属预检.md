# Phase 1 Task 03 · 线程进入归属预检

## 1. Where this task sits

- Phase 1 真实私信链路恢复：目标是错误深链不能进入他人会话。
- This task moves R-6 增加私信线程归属校验：在会话页读取消息前拒绝非法线程。
- Starts after：Task 02 真实私信契约矩阵。Waits on：读取与发送共享归属判断。

## 2. What the developer needs to know

**Read first**

- `app/src/features/mailbox/ChatScreen.tsx` — 当前路由参数和首次读取流程。
- `app/src/features/mailbox/conversations.ts` — 会话列表的线程形状和归一化规则。
- `docs/app/task/phase-2/甲-已知缺陷与更正总账.md` — D-3 的影响与修复要求。
- `docs/app/task/phase-2/P2B-06-M12私信会话.md` — 聊天页行为和测试接缝。

**Settled**

- 后端仍是最终授权边界，客户端预检不能代替服务端拒绝。
- 非法线程进入可修正错误状态，不执行读取或发送。
- 不在本任务修改登录后深链回跳策略。

**Edges and seam**

- 触及 ChatScreen、会话状态和错误展示；不新增导航层接缝。
- Seam：现有 ChatScreen 业务测试。

**Run**

- 运行目标 ChatScreen 测试和 `npm.cmd run typecheck`。
- 完成后运行 `npm.cmd test -- --runInBand --silent`。

**Unknowns**

- 当前会话列表可能只提供线程 ID。若没有可验证的归属数据，停止并说明需要的后端字段或请求。

## 3. The workflow

1. 阅读本 brief，并重述：读取消息前确认线程属于当前用户。
2. 追踪会话列表到 ChatScreen 的数据流和当前错误状态。
3. 写非法、未知和非归属线程的失败测试。
4. 在现有业务接缝增加归属预检和可修正错误状态。
5. 验证失败路径没有触发消息读取、发送或账号清理副作用。
6. 运行目标测试、类型检查和串行全量测试。
7. 提交本任务的单一变更。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 缺失 threadId | 不请求消息，显示错误 | ChatScreen |
| 2 | 非正整数 threadId | 不请求消息，显示错误 | ChatScreen |
| 3 | 当前用户不拥有线程 | 不请求消息，显示可修正错误 | ChatScreen |
| 4 | 后端返回 403 | 不清理当前账号会话 | ChatScreen |
| 5 | 合法归属线程 | 可以读取并显示消息 | ChatScreen |
