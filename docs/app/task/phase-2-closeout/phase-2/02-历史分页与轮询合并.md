# Phase 2 Task 02 · 历史分页与轮询合并

## 1. Where this task sits

- Phase 2 私信消息完整性与合规门禁：长会话读取和轮询共存。
- This task moves R-2：把历史页、首屏和 4 秒轮询结果统一排序去重。
- Starts after：Task 01。Waits on：长会话夹具回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/mailbox/ChatScreen.tsx` — 首屏与轮询生命周期。
- `app/src/features/mailbox/chat.ts` — `mergeMessages`、`messagesAfter` 和排序。
- `app/src/__tests__/p2b-06-chat.test.tsx` — 当前消息页接缝。
- `shared/api/marketplace.js` — 消息请求参数。

**Settled**

- 复用现有纯函数，不新增 mailbox 基础抽象。
- 同一消息按服务端 id 去重。
- 轮询仍为 4 秒，不改实时通道。

**Edges and seam**

- 触及 ChatScreen 状态和 chat 纯函数；不改后端授权。
- Seam：现有 ChatScreen 业务测试。

**Run**

- `cd app && npm.cmd test -- --runInBand --silent src/__tests__/p2b-06-chat.test.tsx`
- `cd app && npm.cmd run typecheck`

**Unknowns**

- 若历史页与轮询同时更新造成状态覆盖，停止并先厘清状态更新顺序。

## 3. The workflow

1. 阅读本 brief，并重述：历史分页和轮询必须合并成一条稳定消息序列。
2. 标出现有消息状态和分页入口。
3. 为交错返回、重复 id 和同秒排序写失败测试。
4. 实现最小合并状态。
5. 验证合法发送、标已读和轮询不回归。
6. 提交本任务。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 1 | 首屏后加载更早页 | 旧消息插入正确位置 | ChatScreen |
| 2 | 轮询与历史页含同一 id | 只显示一条 | chat merge |
| 3 | 同秒不同 id | 按 id 稳定排序 | chat merge |
| 4 | 历史页为空 | 保持已有消息且标记末页 | ChatScreen |
| 5 | 合法发送后轮询 | 自己消息不重复 | ChatScreen |
