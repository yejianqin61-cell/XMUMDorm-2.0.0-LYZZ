# P2C-01 · `K09 StatTile` + `K10 MetricRow`

**Phase C1 我的域页面**，其目标是「我的」这一格的 9 个内测页都能进、四态齐全。
**本任务推进 JR-4 组件缺口偿付**：仪表盘要是没有指标件，`M-01` 就只能手写数字块（违反 1.4）。
**Starts after**：无。**Waits on it**：`P2C-03 M-01 我的仪表盘`。

## 1. 本任务需要知道什么

**Read first**

- `docs/app/design/App组件类型定义.md:234-235` — `K09`（数字 + 标签 + 可选图标，`sm`/`md`）与 `K10`（横向指标行）的登记规格
- `app/src/components/ui/Card.tsx` 与 `Surface.tsx` — 容器原语怎么消费令牌（本任务不新造容器）
- `app/src/components/ui/Text.tsx` — 14 个 `role` 与 `colorToken` 的用法（⛔ 不许写 fontSize 字面量）
- `app/src/__tests__/p1-06-k-composites.test.tsx` — K 层用例的写法与 a11y 断言口径
- `docs/app/task/phase-2/开发设计文档-甲.md` §3-JR-4 — 组件交付的三条硬规则

**Settled**

- 组件内**0 文案**：标签全部由页面传词条。
- 视觉只能来自令牌（⛔ 无 `#hex`、⛔ 无 `fontSize:` 数字）—— 尺子会拦。
- `K09` 的图标是**第 1 层（Lucide）**；⛔ 不用 Emoji。
- 数值展示要能容忍缺失（⛔ 不显示 `NaN`/`undefined`）。

**Edges and seam**

- 只碰 `app/src/components/ui/**` + 自己的用例。
- Seam：**S-1 组件契约**（RNTL 断言 props → 渲染）+ 尺子。

**Run**

- `cd app && npx jest src/__tests__/p2c-01 --ci`
- `cd app && npm run rulers`

**Unknowns**

- `K09` 的数字可能是 0：**0 要显示**（⛔ 不能像未读那样藏起来）。
- 图标与文字必须**同时**给语义（16.2-4：图标不得承担唯一语义）。

## 2. 工作流

1. 读上面五处，用一句话复述本任务。
2. 写 1 号用例（`K09` 渲染数字 + 标签；`sm`/`md` 两态）—— 先红。
3. 实现 `StatTile`，让它绿。
4. 加 2–3 号用例（0 要显示、可选图标、缺失值不崩）。
5. 实现 `MetricRow`（横排多个指标 + 分隔），加 4–5 号用例。
6. 跑两条命令，提交。
