## 2. 它意味着什么

Phase C 一开始就撞上"零件不够"：`M-01` 要的四块内容里有两块没有对应组件，所以本轮先把零件补齐（`K09 K10 K15 K16`）。
一个值得记下来的设计判断：后端 `/api/users/me` 返回的 `badgeEmoji`（🌱🧭✨…）**不能画** —— 宪法禁 Emoji 图标，等级只能用"数字 + 词条名 + Lucide 图标"表达；这条已写进组件注释并有用例钉住，避免后来者看到有这个字段就顺手渲染。
