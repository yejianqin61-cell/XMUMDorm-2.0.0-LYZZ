# P2Y-D02 · 原生选择器与 Lint 准入

## 1. Where this task sits

冲突收尾第二项，所有者已授权原生依赖准入。
依赖 D01 公共表单；用于待办日期时间和点评选图。

## 2. What the developer needs to know

先读冲突处理方案的五项准入、SDK57 文档、C15/C16/C20 规格。
按 Expo install 锁兼容版本；不手写原生目录。
日期时间用系统控件，可取消与清除；24 小时制。
点评图片≤3、单张≤8MB、不含GIF，取消不丢旧值。
Lint 为开发工具；不得把自动回归写成真机通过。

## 3. The workflow

1. 按准入版本安装选择器和 ESLint。
2. 加选图取消、图片载荷和日期时间边界回归。
3. 公共日期时间控件接 K01 字段描述符。
4. 系统相册接点评，关闭不需要的原生权限。
5. 加 Expo 标准 Lint 配置，修复本轮范围问题。
6. 运行类型、lint 和回归，独立提交。

## 4. The test cases

| 输入 | 期望 | 接缝 |
|---|---|---|
| 取消/清除日期时间 | 保留/清空字段，无非法值 | 控件 |
| 取消相册 | 草稿不变 | 适配器 |
| 3张图片提交 | 合法 RN multipart 载荷 | 表单 |
| 新依赖 | 五项齐全，锁文件可安装 | 配置 |
