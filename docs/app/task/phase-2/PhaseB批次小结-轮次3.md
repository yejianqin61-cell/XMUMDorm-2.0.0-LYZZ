## 2. 它意味着什么

「未读真源」这条线走完了：角标 → 信箱 → 会话列表 → **会话本身**，四个环节都能用了；私信从"后端没接口"到"两个人能聊"。
本轮有一处**按裁决取消**的工作（`D06`）和一处**按事实新增**的工作（`O08.sendDisabled`）：前者是同一判据的第三次应用（`K22`/`C14`、`D06`/`O08`），后者是"复用现成组件"这条路唯一的真实成本 —— 复用不是零成本，但**改一个 prop 比新建一个同语义组件便宜**，这一点已连同证据写进组件定义。
