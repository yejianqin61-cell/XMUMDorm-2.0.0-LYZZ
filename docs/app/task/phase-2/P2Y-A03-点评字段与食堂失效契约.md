# P2Y-A03 · 点评字段与食堂失效契约

## 1. Where this task sits

- Wave A 打通共享数据；推进 R-Y4 食堂发点评与 R-Y6 食堂读缓存。
- Starts after：上游字段核对；Waits on it：S11表单与缓存接线。
- 只定义域契约，不改全局发布注册表或 S10 写控件。

## 2. What the developer needs to know

**Read first**
- `routes/canteen.js` — 评级、字数、图片数量的服务端规则是什么？
- `app/src/features/square/canteen.ts` — 五档枚举与匿名投影如何复用？
- `app/src/components/ui/FormField.tsx` — RatingScale 如何作为custom字段？
- `shared/api/canteen.js` — 点评提交载荷与搜索响应是什么？

**Settled**：K01 Form为唯一表单状态机；图片neverDraft；全域读缓存失效。
**Edges and seam**：字段校验纯函数与既有食堂resource接缝，不加第二套UI骨架。
**Run**：`cd app; npm.cmd test -- --runInBand p2y-a03 p1-17`；`npm.cmd run typecheck`。
**Unknowns**：图片原生依赖未准入，任务只交数量约束和载荷契约。

## 3. The workflow

1. 阅读第2部分并复述：合法五档与正文边界由同一域定义。
2. 写五档和300/301字边界失败用例。
3. 实现K01字段工厂及载荷校验。
4. 定义成功写入后的全域版本失效通知。
5. 验证图片上限、退订与版本递增。
6. 运行回归与类型检查，提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 五档 | hot/top/above/npc/dead | 服务端五档枚举逐项对应 | 字段/载荷 |
| 正文边界 | 300/301字 | 300可提交，301拒绝 | 校验 |
| 无评级 | null | 就近字段错误 | 校验 |
| 图片边界 | 3/4张 | 3合法，4拒绝，不落草稿 | 校验 |
| 失效订阅 | 通知一次后退订 | 版本+1；退订后不调用 | 版本通知 |
