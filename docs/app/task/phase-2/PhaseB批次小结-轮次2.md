## 2. 它意味着什么

信箱是「未读真源」这条线的**出口**：上一轮把真源接上了（角标会动），这一轮把页面做出来，于是"看见有未读 → 进去读掉 → 角标跟着变"这个闭环第一次真的闭合。
有一处刻意的**不做**：通知点击不做页面跳转。后端给的 `target.path` 是 Web 路径（`/post/12`、`/about/campus/3`），App 的路由不是这套；硬套就是让用户点一下就 404。映射属于系统契约 **S03 DeepLinkRouter**（页面清单 §5），本轮把它留成空函数并如实标注，而不是猜一套路径出来。
