# P2Y-C02 · 导入错误与边界回归

## 1. Where this task sits

- Wave C 缓存与验收收尾；推进 R-Y7 错误与逐页验收。
- Starts after：独立页面交付；Waits on it：全量验证。
- 400提示要给对象、原因与修正步骤；不输出后台技术消息。

## 2. What the developer needs to know

**Read first**
- `app/src/app/tools/schedule-import.tsx` — 原400如何被归类？
- `app/src/features/tools/scheduleImport.ts` — 导入的已定输入门槛是什么？
- `app/src/i18n/errors.ts` — 三要素如何由统一模型生成？
- `app/src/__tests__/p1-15-schedule-import.test.tsx` — 预览/确认的既有交互是什么？

**Settled**：客户端不少于10字；400可能为无课程；规则通过双语词条参数传给K04。
**Edges and seam**：导入页渲染与toErrorCopy；不修改共享错误组件。
**Run**：`cd app; npm.cmd test -- --runInBand --silent p2y-c02 p1-15`；`npm.cmd run typecheck`。
**Unknowns**：预览异步期间改文本可导致旧预览回写；加入竞争回归后独立修复。

## 3. The workflow

1. 阅读第2部分并复述：400要让用户知道怎样修正粘贴表格。
2. 写400中英文三要素失败用例。
3. 加规则词条与错误对象映射。
4. 验证修改文本作废旧预览与提交失败不清缓存。
5. 运行回归与类型检查并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 400中文 | 无可解析课程 | 对象为课表文本；说明表头/课程；给修正方法 | 页面 |
| 400英文 | 同上 | 无中文与词条key泄漏 | 页面 |
| 预览失败 | offline | 保留输入，网络三要素 | 页面 |
| 文本变化 | 旧预览晚到 | 不允许导入旧表 | 页面 |
| 提交失败 | commit拒绝 | 缓存未失效 | 页面/hook |
