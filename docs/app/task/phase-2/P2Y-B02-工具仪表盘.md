# P2Y-B02 · 工具仪表盘

## 1. Where this task sits

- Wave B 四张可用页面；推进 R-Y2 工具首页三块。
- Starts after：共享课表、待办页面；Waits on it：甲公共Tab接线。
- 交可复用内容与乙域直接访问入口，保留原工具入口。

## 2. What the developer needs to know

**Read first**
- `app/src/features/tools/timetable.ts` — 如何共享课表并显示cache来源？
- `app/src/features/tools/schoolSystems.ts` — 三格的唯一配置在哪里？
- `shared/api/todos.js` — 今日摘要是什么形状？
- `app/src/app/(tabs)/tools.tsx` — 原入口与testID需要保留哪些？

**Settled**：不改甲的Tab文件；不新增放假日页；每块失败单独重试。
**Edges and seam**：仪表盘页面渲染和既有hook；只改features/tools及tools路由。
**Run**：`cd app; npm.cmd test -- --runInBand --silent p2y-b02 p1-14 p1-16`；`npm.cmd run typecheck`。
**Unknowns**：默认周由学期配置计算；学期间显示有说明的空态，不假造课程。

## 3. The workflow

1. 阅读第2部分并复述：三块与三个旧入口同屏可用。
2. 写真数据摘要与校方系统入口用例。
3. 实现独立content组合及tools域路由。
4. 加入空态、局部失败和陈旧提示。
5. 运行回归与类型检查并提交。
