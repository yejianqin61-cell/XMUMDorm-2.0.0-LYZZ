## 1. 本任务需要知道什么

**Read first**

- `docs/app/design/App组件类型定义.md:240-241` — `K15`（6 级徽章，`icon`/`iconWithName`）与 `K16`（经验条，`compact`/`full`）

- `docs/app/task/phase-2/开发设计文档-甲.md` §3-JR-4

**Settled**

- ⛔ **不渲染后端的 `badgeEmoji`**：那是 Emoji，宪法明令 Emoji 不得当图标（两层图标体系）。等级用**数字 + 词条名 + 可选 Lucide 图标**表达。
- 等级词条由**页面**给（组件内 0 文案）；⛔ 不在组件里写"新生/探索者"。
- `progress` 是 0–1；`progressText` 是 `"12/200"` 这种**纯文本**，直接用。
- 视觉只能来自令牌。

**Edges and seam**

- 只碰 `app/src/components/ui/**` + 自己的用例。
- Seam：**S-1 组件契约** + 尺子（含一条"组件里 0 个 Emoji"的源码扫描）。

**Run**

- `cd app && npx jest src/__tests__/p2c-02 --ci`
- `cd app && npm run rulers`

**Unknowns**

- 满级（`level ≥ 6`）时 `nextMin` 仍在：进度要显示成满而不是溢出。
- `progress` 缺失时⛔ 不显示 `NaN`。

## 2. 工作流

1. 读上面五处，用一句话复述本任务。
2. 写 1 号用例（`LevelBadge` 显示级别数字 + 词条名；两态）—— 先红。
3. 实现 `LevelBadge`，让它绿。
4. 加 2–3 号用例（满级、无词条名时不崩、**源码里 0 个 Emoji**）。

6. 跑两条命令，提交。
