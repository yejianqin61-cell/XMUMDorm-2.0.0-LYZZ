# P2Y-D01 · 公共接线与审计修复

## 1. Where this task sits

Wave C 后的冲突收尾。所有者于 2026-10-06 授权冲突处理方案。
依赖已有仪表盘与 K01；后续选择器和 S10 消费新接口。

## 2. What the developer needs to know

先读冲突处理方案、Form、Screen、工具 Tab、Session 与旧测试。
保留唯一 Screen、信箱角标、K01 草稿与校验机制。
换账号须重挂表单；服务端校验失败须有对象、规则、动作。
使用 SDK57 的 Expo Router 导出；不从外部 React Navigation 包导入。
运行 App 针对性测试、全量测试、lint、typecheck。

## 3. The workflow

1. 先加换账号与错误规则回归用例，单独提交。
2. 修复点评和导入的账号边界，统一网络错误分类。
3. 接工具 Tab，保留校方系统、课表、导入入口。
4. Form 接标题和信箱；未保存内容拦截系统返回。
5. 旧食堂测试清理缓存，保留所有断言。
6. 运行回归、提交，记录未测真机行为。

## 4. The test cases

| 输入 | 期望 | 接缝 |
