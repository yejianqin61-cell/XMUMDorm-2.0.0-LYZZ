## 2. 它意味着什么

`M-04` 是第一个把「我的」从"纯展示"变成"能操作"的页面，也是**入口账本第一次真正翻转**：`ME_ENTRIES` 里 `posts` 置为 `available:true`，用例立刻要求 `/me/posts` 这个路由文件**真的在磁盘上**（⛔ 不做 404 入口），缺口账本从 3 条减到 2 条。
两处刻意的"不做"：**行不可点**（帖子详情 `C-02` 是丙的页面，App 里还没有这个路由）；**列表标题就是正文**（后端 `posts` 载荷只有 `content`，没有 title —— 不编一个假标题）。
