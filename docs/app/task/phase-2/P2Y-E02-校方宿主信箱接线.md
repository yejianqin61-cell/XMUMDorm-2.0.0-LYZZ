**Settled**：顶栏只保留信箱；校方系统名、读表、关闭属于页面工具栏；不复制TopBar或未读商店。
**Edges and seam**：只写校方宿主页与乙测试；真实Screen/TopBar，替身原生WebView和角标hook。
**Run**：App `npm.cmd test -- --runInBand --silent p2y-e02 p1-14`；`npm.cmd run typecheck`及lint。
**Unknowns**：未知id继续重定向；校内登录、Cookie保持与设备布局仍待实测。

## 3. The workflow

1. 读第2部分，复述：信箱回到统一顶栏，读表关闭留在内容工具栏。
2. 写唯一信箱、角标与动作去向的红测试并提交。
3. 宿主页消费useMailboxBadge和Screen标准顶栏。
4. 原工具栏移到内容首行，保留AC读表、Moodle无读表与关闭。
5. 运行新测试与原校方系统回归、类型和lint检查。
6. 独立提交接线，关闭TD-71并回写逐屏记录。
