## 2. 接线边界

ListScreen.tsx的filters/cursor仅以首次挂载值初始化。scope改变会重新计算restored，却不会重新初始化useState，因此不能只换scope就当作完全恢复。
setFilters重置pagination reducer，但未清本地cursor和仓库cursor，使用旧游标续取会跨筛选。

当前可复用机制：各栏使用不同scope与独立挂载。后续页面怎样切换须按公共组件契约接入；“清旧游标”不能遗漏。
数据列表本身尚未缓存，状态仓库只存位置、游标、筛选，不存数据页、hasMore或加载状态。返回后续页如何恢复仍需业务数据层核对，不能凭游标恢复宣称完整分页恢复。
