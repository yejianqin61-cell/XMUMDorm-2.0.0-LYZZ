# 第六批：逐页证据复核

## 1. 任务位置
第六批验收收口；目标：建立13个页面或表单的机器证据、人工边界与依赖清单。
前置为已有五批本地提交；公共接缝与设备验收仍按用户决定保留。

## 2. 开发依据
- outputs/xmumdorm/丙实施框架/实施框架与验收约定.md — 第六批目标与验收分账。
- docs/app/task/phase-2/README.md — 内容域逐屏检查与写作用域。
- app/src/__tests__/p2x-bing* — 已有机器验证接缝。
- docs/app/task/phase-2/丙实施记录 — 历史证据与未验收边界。
运行：npm run test:ci -- --runInBand p2x-bing；npm run verify。
不操作共享数据库，不发布EAS，不替代用户确认；公共组件不擅改。

## 3. 工作步骤
1. 核对任务范围及原始证据。
2. 需求、规范两轴只读复核。
3. 丙域缺陷先写失败测试，再修复并提交。
4. 汇总自动回归原始结果。
5. 为未验收行为保留具体人工步骤。
6. 保存记录并提交文档。

## 4. 验证用例
| 检查 | 期望 |
|---|---|
| 逐页登记 | 每页有真实证据和人工状态 |
| 四态与双语 | 可重试、返回，不泄漏技术错误 |
| 组合流程 | 可运行接缝通过，公共入口缺失不假报 |
| 人工与自动 | 不用测试通过冒充真机或用户确认 |
