# 指南任务 02：分页与状态保留

2026-10-06；分支 dev-zjr。已实现并通过自动化检查，等待用户验收。

## 实现

- 服务端 hasMore 决定是否追加；页码只在成功后推进。
- 追加失败保留列表，页脚重试同页；按 id 去重，末页停止。
- 刷新从第一页开始；成功替换旧页并归零滚动位置，失败保留内容并显示重试按钮。
- 重复触底只发送一个追加请求；刷新后忽略旧追加响应，卸载后的响应不写回。
- 复用 App QueryClient 缓存文章、页码和 hasMore，公共分页 reducer 管理请求状态。
- 复用 SecondaryTabStore 的 square/guides 范围保存游标和滚动位置。
- 返回时优先恢复会话缓存及位置，不重新请求第一页；缓存按现有 QueryClient 的回收策略管理。
