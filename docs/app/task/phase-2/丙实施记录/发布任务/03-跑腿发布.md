# 跑腿发布

## 1. 任务位置
第五批发布表单，依赖第四批阅读链路，交付丙域描述符。
公共宿主、注册表、媒体选择器及导航接线归甲；不重复实现布局。

## 2. 开发依据
- routes/errands.js — 真实接口字段与限制。
- app/src/features/publish/descriptor.ts — 描述符、媒体草稿与成功路由契约。
- app/src/components/ui/FormField.tsx — 字段及选项方言。
- shared/api — 已有提交封装。
运行：npm run test:ci -- --runInBand p2x-bing-publish；npm run verify。
媒体通过公共控件注入，远程选项通过宿主加载，不复制分类列表。

## 3. 实现步骤
1. 阅读契约并明确当前任务。
2. 写非法值不得请求的失败测试。
3. 实现字段、边界与允许字段白名单提交。
4. 成功清理本域列表缓存，返回新内容路由。
5. 验证公共描述符不变量与草稿边界。
6. 提交并记录公共注册接线缺口。

## 4. 测试用例
标题120；正文5000；联系必填；期限合法。
接口失败保留输入，不清缓存；成功id必须有效；媒体不存草稿。
