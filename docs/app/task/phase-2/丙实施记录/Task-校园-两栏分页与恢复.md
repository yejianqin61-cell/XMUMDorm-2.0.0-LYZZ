# 校园任务 02：两栏分页与恢复

日期：2026-10-07。分支：dev-zjr。业务实现与机器检查通过；设备验收待完成。

## 实现与边界

- TopTabStrip 使用既有 getSecondaryTabs('campus') 集合；只挂载选中栏的 keyed CampusFeed。
- 树洞按 page/pageSize=10 分页；万能墙按 direction=older、limit=5 和响应 oldest_cursor 续取。
- 同栏重复 id 合并；追加失败重试同一页或窗口，末页停止；缺失或不推进的窗口游标报内容错误。
- 两栏的数据页分别存入已有 QueryClient，由 QK 派生业务快照键；公共 SecondaryTabStore 保存位置和游标。
- 已加载数据返回后不重拉；选中栏写入路由 tab 参数，万能墙详情深链无返回历史时回 /campus?tab=wall。
- 刷新归零当前栏的位置、替换当前数据，不清另一栏；刷新可抢占追加，迟到响应不更新页面或缓存。
- 万能墙列表和详情只保留 id/content，不保留原响应作者、标题和图片，统一匿名展示。
- 复用 ListScreen 与 DetailScreen，未修改公共 UI、导航壳、状态仓库或后端。
