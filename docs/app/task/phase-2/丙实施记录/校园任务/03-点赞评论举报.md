# 校园任务 03-点赞评论举报

## 1. 任务位置

- 第三批校园可互动：浏览两栏并操作帖子详情。
- 本项：接通详情的真实交互。前置：任务 02；后续：搜索与发布。
- 边界：只写丙业务域、路由及增量词条，公共 UI 与导航壳归甲。

## 2. 开发入口

**先读**
- docs/app/task/phase-2/README.md — 两栏匿名与所有权规则是什么？
- shared/api/posts.js、confessions.js — 阅读与分页接口如何返回？
- app/src/components/ui/ListScreen.tsx、proto/P3/DetailScreen.tsx — 可用公开接缝是什么？
- app/src/features/navigation/secondaryTabs.ts — 两栏如何保存各自状态？

**已定**：复用 ListScreen 与 DetailScreen；万能墙强制匿名；按阶段实现，不写公共替代布局。
**接缝**：上述公共组件与共享 API；不改公共 UI、路由壳或后端。
**运行**：app 内 npm test -- --runInBand p2x-bing-campus；npm run typecheck；npm run rulers。
**未知**：公共状态缺口不由丙修；若公开接缝不足，记录缺口并暂停依赖部分。

## 3. 步骤

1. 阅读入口并用一句话重述本项。
2. 按下表写失败行为测试。
3. 接入业务数据映射与路由。
4. 逐例实现并运行相关测试。
5. 执行类型、规则及适用回归，记录未验证项。
6. 单独提交，交用户逐项验收。

## 4. 用例

| 场景 | 输入 | 预期 | 接缝 |
|---|---|---|---|
| 点赞 | 服务端状态 | 按响应更新 | 公共页面与共享 API |
| 评论 | 有效正文 | 提交并显示 | 公共页面与共享 API |
| 举报 | 支持的目标 | 调用既有举报接口 | 公共页面与共享 API |
| 权限 | 游客或拒绝 | 友好提示 | 公共页面与共享 API |
| 失败 | 请求拒绝 | 保留内容并可重试 | 公共页面与共享 API |
