# 二手详情与想要

## 1. 任务位置
第四批：二手与跑腿阅读和操作。前置：01。后续：第五批发布表单。

## 2. 开发信息
- shared/api/marketplace.js：确认请求方法与返回值。
- routes/marketplace.js：确认字段及服务端权限。
- app/src/proto/P3/DetailScreen.tsx：详情组合。
- app/src/components/ui/ListScreen.tsx：分页和四态。
- 已定：复用P2/P3，业务写在丙域；不修改公共壳和UI；发布留第五批。
- 接缝：既有ListScreen、DetailScreen及共享API。
- 运行：app内 npm test -- --runInBand p2x-bing-market-errand；收尾 npm run verify。
- 未知：公共接入和设备实测分别记录依赖。

## 3. 工作步骤
1. 读入口并复述任务。
2. 核对接口，先补失败测试。
3. 实现字段适配和页面组合。
4. 补分页或操作、并发和失败恢复。
5. 添加双语和四态，运行检查。
6. 本地提交，记录验收边界。

## 4. 测试用例
| 场景 | 预期 | 接缝 |
|---|---|---|
| 列表到详情 | 字段、金额与目标一致 | P2/P3 |
| 跑腿列表 | 接口不含联系方式 | API契约 |
| 分页与筛选 | 按服务端页大小，筛选独立 | ListScreen |
| 想要/接单/完成 | 尊重权限，重复点击仅一次请求 | API |
| 失败与旧请求 | 可重试，不覆盖其他目标 | 业务请求代次 |
