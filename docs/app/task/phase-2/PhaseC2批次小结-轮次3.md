## 2. 它意味着什么

鉴权这一层现在是**闭环**：冷启动不闪屏（`A-01` 的门）→ 登录（P1-13）→ **注册**（`A-03`，含开发期验证码回传那处共享层修复）→ **找回密码**（`A-04`）。
`A-04` 的结构性设计是"**洞从结构上不存在**"：未发码时后两步（验证码 + 新密码）**根本不渲染**，纯函数 `canSubmitReset` 再拦一次 —— 而不是靠"界面上禁用一下按钮"。
