## 2. 它意味着什么

本轮最有价值的一处不是新页面，而是**一个被静默丢掉的字段**：后端在 `NODE_ENV=development` 时会把验证码放在响应体顶层，而 `shared/api/auth.js` 一直把它丢掉 —— 所以"开发期用回传的验证码注册"这条路**从来就不通**，只是没人试过。按任务书的纪律，这一处**单独一个提交**（先例是 P1-13 给 `request.js` 补 `err.body` 那次独立修复），改动只增字段，Web 行为不变。
另一处口径：注册成功后后端直接返回 token → 与登录走**同一条**落地路径（写令牌 + 进 `signedIn`），所以"注册完还要再登一次"这件事不存在。

## 3. 仍未闭合

- **开发期回显验证码**是 `NODE_ENV=development` 专属：生产下后端不返回该字段，界面自然不显示（判据是"服务端给没给"，⛔ 不在客户端读环境变量）。
