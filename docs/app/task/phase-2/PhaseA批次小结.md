## 2. 它意味着什么

发布表单是"表单 + 列表"这两个最大桶里甲占的那一半，本轮把它从**设计**落成了**可被别人接着写的骨架**：
域作者现在不需要碰路由、骨架、发布中心，只交一份描述符；而"A 类发布还没上线"这件事被记在**代码里的账本**上，逐条变短，不靠人记。
代价有两处已经写在明处：门的真源（`acceptedTerms`）后端**完全没有**，本轮按 `Q2-A` 临时放行并登记；`M-11` 私信会话列表后端**没有跨商品接口**，Phase B 开工前需要所有者裁一次（`Q1`）。
