## 1. 本任务需要知道什么

**Read first**

- `routes/users.js:297-380` — `PATCH /api/users/me`（只接受 `nickname`/`username`/`college`/`grade`/`major`/`show_*`，**无长度上限**）与 `PATCH /api/users/me/avatar`（multipart 字段 `avatar`，**≤8MB，允许 gif**）
- `app/src/features/publish/usePublishForm.ts` — 宿主 hook 的写法（`P4` 骨架的装配；本页复用同一套提交语义）
- `app/src/components/ui/FormField.tsx` — `kind:'custom'` 是**没有媒体 kind** 时的唯一出路（`render` 注入）
- `app/src/features/auth/session.tsx` — 会话与 `useSession`（本页不需要，但要知道资料与登录态的关系）
- `docs/app/product/App页面清单与结构盘点.md` §3-M 的 `M-02` 行（关键组件与头像限额）

**Settled**

- 走 **`K01 Form`**（`P4` 骨架），⛔ 不手写表单。
- 端点用 **`PATCH`**（页面清单写的 `PUT`/`POST avatar` 是错的，已登记更正）。
- 头像字段是 `kind:'custom'` + `C20 MediaPicker`，且 **`neverDraft:true`**（本地 URI 重启后失效）。
- 服务端**没有长度上限** → `maxLength` 由**页面**注入（⛔ 不指望服务端拦）。
- 保存成功后**返回上一屏并立即可见新值**（目标屏聚焦时重取，见开发设计文档 §1.2-3）。

**Edges and seam**

- 碰 `app/src/features/me/**` + 新增 `app/src/app/me/edit.tsx`；组件层只**新增** `C20 MediaPicker`。
- Seam：**S-4 纯规则**（资料 → 初始值的映射、限额）+ **S-1 页面**（提交语义与离开确认）。

**Run**

- `cd app && npx jest src/__tests__/p2c-06 --ci`
- `cd app && npx tsc --noEmit`

**Unknowns**

- 头像上传是 multipart（`FormData`）→ 与 JSON 提交**不是同一条路**：本任务要先把"先改文本字段、再传头像"的次序说清楚，⛔ 不做两件事的伪原子。
- `username` 改完会影响登录标识（后端把 `username` 当登录名之一）→ 提示文案要能让用户理解后果。
