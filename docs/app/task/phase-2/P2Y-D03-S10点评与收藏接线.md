# P2Y-D03 · S10 点评与收藏接线

## 1. Where this task sits

冲突收尾第三项。所有者已裁 S10 写路径归乙。
依赖 S11 与缓存失效机制；保留既有匿名评论渲染。

## 2. What the developer needs to know

先读 shared/api/canteen、后端收藏路由、DishDetail 和 Session。
收藏状态是私有读取，不放进公开食堂缓存。
只使用既有 GET/POST/DELETE 收藏 API；登录失效走统一会话。
写失败保留旧值，写成功重新读取；并发与换菜品不能串状态。

## 3. The workflow

1. 加收藏切换、失败和点评入口回归，先提交测试。
2. 接独立收藏状态与写动作，防止双击重复提交。
3. S10 添加单个点评入口，导航到现有 S11。
4. 成功写后失效读资源，失败呈现可重试动作。
5. 回写页面清单及角色裁决，运行全量验证。
6. 写批次小结、验收审计并推送 dev-yps。

## 4. The test cases

| 输入 | 期望 | 接缝 |
|---|---|---|
| 点击点评 | 带产品id进入S11 | 页面 |
| 收藏/取消成功 | 真接口、重读后显示服务端状态 | 页面 |
| 写失败或切账号 | 保留正确所属状态，不显示假成功 | 请求竞争 |
| 连点 | 仅一笔写请求 | 页面 |
