# P2Y-B04 · 食堂检索

## 1. Where this task sits

- Wave B 四张可用页面；推进 R-Y5 食堂搜索。
- Starts after：接口核对；Waits on it：食堂首页搜索入口。
- 页内提交关键词和分页；不创建丙域文章详情路由。

## 2. What the developer needs to know

**Read first**
- `routes/canteen.js` — 搜索q上限和hasMore结构是什么？
- `shared/api/canteen.js` — 搜索API如何复用？
- `app/src/components/ui/SearchField.tsx` — 键盘提交如何触发？
- `app/src/components/ui/ListScreen.tsx` — 业务空态与分页错误如何区分？

**Settled**：trim后1–50字符才请求；产品跳S10；文章详情未交付时只读展示，不跳404。
**Edges and seam**：SearchField+ListScreen渲染和关键词纯函数；食堂域内实现。
**Run**：`cd app; npm.cmd test -- --runInBand --silent p2y-b04 p1-17`；`npm.cmd run typecheck`。
**Unknowns**：切换关键词的旧请求必须废弃；各类分页使用服务端hasMore，不猜条数。

## 3. The workflow

1. 阅读第2部分并复述：无效关键词是业务空态而不是网络失败。
2. 写空/超长零请求和产品结果用例。
3. 实现查询规范化、提交与分页。
4. 加入请求竞争、去重和页脚重试。
5. 接食堂首页入口并运行回归，提交。
