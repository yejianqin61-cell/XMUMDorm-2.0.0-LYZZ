# P2B-01 · 未读真源与顶栏角标

**Phase B 未读真源一条线**，其目标是：未读数**一处为真、四处一致**；私信 4s 内互相可见、离开即停。
**本任务推进 JR-7 信箱四屏一致 + 角标单一真源**的一半：**真源**与**顶栏**。
**Starts after**：无。**Waits on it**：`P2B-03 M-11 会话列表`、`P2B-04 F-01 信箱页`（两者都读同一个 hook）。

## 1. 本任务需要知道什么

**Read first**

- `app/src/components/ui/TopBar.tsx` — 角标怎么显示、`unreadCount` 与 `onMailboxPress` 的语义（只看形状，不改）
- `app/src/components/ui/Screen.tsx` — `unreadCount` / `onMailboxPress` / `showMailbox` 三个 prop 怎么透传
- `shared/api/notifications.js` — `getUnreadSummary()` 的返回形状与 `getNotifications()` 的关系
- `routes/notifications.js:47-60,272-286` — `buildUnreadSummary` 的**实际字段**（`total/byType/byModule/byCategory`）
- `docs/app/task/phase-2/开发设计文档-甲.md` §3-JR-7 — 验收项与"通知派生"这个硬骨头

**Settled**

- 未读只有**一个**来源：`GET /api/notifications/unread-summary` 的 `data.total`；⛔ 客户端**不本地递减**。
- 已读之后要**重新拉汇总**，不是把数字减一。
- 顶栏动作只有一个（信箱）；⛔ 不新增第二个动作（宪法 4.2）。
- 四个一级 Tab 的角标必须**同源、同形**；⛔ 页面不许自己算未读。

**Edges and seam**

- 碰 `app/src/features/mailbox/**`（本任务新建）+ 四个 `(tabs)/*.tsx` 各一行；⛔ 不改 `TopBar`/`Screen`。
- Seam：**S-4 纯规则**（从汇总载荷取 total）+ **S-5 源码扫描**（四个 Tab 都接了同一个 hook）。

**Run**

- `cd app && npx jest src/__tests__/p2b-01 --ci`
- `cd app && npx jest src/__tests__/p0-05 src/__tests__/p0-07 --ci`（导航与发布入口唯一性的既有断言）
- `cd app && npx tsc --noEmit`

**Unknowns**

- 拉取失败时角标必须是"不显示"而不是"0 条"（0 是个具体主张，拿不到就别主张）。
- 未登录时**不发请求**；登出要清掉数字。

## 2. 工作流

1. 读上面五处，用一句话复述本任务。
2. 写 1 号用例（汇总载荷 → total；形状不对 → `null`）—— 先红。
3. 写纯函数与 `useUnread` hook，让它变绿。
4. 加 2–4 号用例（未登录不发请求、失败不显示 0、已读后 refresh 重新取）。
5. 四个 Tab 页各接一行，加 5 号用例（源码扫描：四个都接、且没有人写死 `unreadCount`）。
6. 跑三个命令，提交。
