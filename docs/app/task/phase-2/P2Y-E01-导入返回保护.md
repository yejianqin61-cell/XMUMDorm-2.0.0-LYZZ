## 3. The workflow

1. 读第2部分，复述：导入未保存时确认返回，成功时直接返回。
2. 写取消留页、确认移除、请求期间拦截、成功放行的红测试并提交。
3. 提取公共保护状态逻辑，由Form与T03共同消费。
4. 保持导入成功不可因草稿存储失败被误判成可重试提交。
5. 运行保护与导入回归、类型和lint检查。
6. 独立提交修复，关闭TD-72并回写验收证据。
