## 2. 它意味着什么

「我的」这一格现在是**完整可走**的：仪表盘 → 我的帖子 → 设置 → 关于与法律 → 两份法务文本，全部进入得去，⛔ 没有 404 入口（那个账本一直在盯）。
三处刻意的取舍：
① **法务正文内置**并把"内置"当作权威来源（`fetchRemote` 返回本地常量）→ 既满足"离线可读"，又不会挂一条"这不是最新的"误导用户；
② **Q5 按默认口径执行**：三份文本都是**可辨识的占位**（开头写明"待替换"），⛔ 不假装是最终法务文本，替换只改一个文件；
③ ⛔ **不用 WebView 渲染长文**（宪法 4.1.2）。
