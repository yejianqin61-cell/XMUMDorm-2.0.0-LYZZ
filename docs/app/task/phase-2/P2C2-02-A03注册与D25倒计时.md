- `app/src/components/ui/OtpInput.tsx` 与 `features/publish/usePublishForm.ts` — `P4` 骨架与六位码输入件的既有用法
- `docs/app/task/phase-2/开发设计文档-甲.md` §3-JR-8 — 本任务的四个硬骨头

**Settled**

  先例是 P1-13 给 `shared/api/request.js` 补 `err.body` 那次**独立修复提交**。
