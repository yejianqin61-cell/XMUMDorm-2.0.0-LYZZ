**Run**：`cd app; npm.cmd test -- --runInBand --silent p2y-c01 p1-17`；`npm.cmd run typecheck`。

## 3. The workflow

1. 阅读第2部分并复述：公开数据缓存有TTL，失效前响应不得回写。
2. 写新鲜/过期/离线缓存失败用例。
3. 实现版本化缓存落盘与请求合并。
4. 给四张既有页接键与陈旧横幅。
5. 验证点评失效重读与评论追加竞争。
6. 跑回归和类型检查并提交。

| Case | Input | Expected | Seam |
