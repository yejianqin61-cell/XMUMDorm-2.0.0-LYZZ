# P2Y-A01 · 修复课表缓存往返

## 1. Where this task sits

- Wave A 打通共享数据；推进 R-Y1 共用课表缓存。
- Starts after：main基线核对；Waits on it：请求合并与导入失效。
- 仅修复既有格式缺陷，公开函数签名兼容。

## 2. What the developer needs to know

**Read first**
- `app/src/features/tools/timetable.ts` — 写入与读取为何使用不同字段？
- `app/src/__tests__/p1-16-timetable.test.tsx` — 既有离线行为如何验收？
- `app/src/shared/storage.ts` — 如何安全落盘并处理坏值？

**Settled**：本地优先失败保留内容（计划 R-Y1）；不改公共 UI。
**Edges and seam**：`readCachedWeek` / `writeCachedWeek`，只改工具域。
**Run**：`cd app; npm.cmd test -- --runInBand p2y-a01 p1-16`；`npm.cmd run typecheck`。
**Unknowns**：旧缓存可能是接口形状或规范化形状；同时覆盖两种，不丢兼容。

## 3. The workflow

1. 阅读第2部分并复述：缓存课程名与时间必须原样恢复。
2. 写完整字段往返失败用例，记录失败并独立提交。
3. 以最小格式兼容修复使首例通过。
4. 依次加入旧缓存、坏值与空周用例。
5. 运行相关回归与类型检查，提交修复。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 完整往返 | CS101 / Algorithms / 08:00 / 10:00 / A1 | 字段逐项不变 | read/write |
| 旧接口格式 | snake_case课程 | 同一课程对象 | read |
| 旧规范化格式 | camelCase课程 | 同一课程对象 | read |
| 坏值 | `{nope:true}` | null | read |
| 空周 | week3、days空 | 七天空数组 | read/write |
