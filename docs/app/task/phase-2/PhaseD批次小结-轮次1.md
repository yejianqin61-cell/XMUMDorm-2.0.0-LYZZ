## 2. 它意味着什么

Phase D 的主题是"**收口**"，而收口的第一步不是写文档，是**堵住会被漏掉的路**。本轮堵了两条：
① `MessageKey` 类型只挡字面量，**动态拼的 key 一律靠 `as MessageKey` 绕过类型系统** —— 漏一个就在界面上显示 `me.level.4` 这种原始 key，且编译期运行期都不报错。现在三处动态 key 的**每个取值**都被钉住（zh 与 en 都要有）。
② CI 的四把尺子 + 类型检查 + App 单测**都看不到 `shared/**`** —— 而那是 Web 与 App 共用的代码（第 11 轮我刚改过 `shared/api/auth.js`）。也就是说：**改共享层的那个提交不会触发任何 CI**。现在它触发了。
