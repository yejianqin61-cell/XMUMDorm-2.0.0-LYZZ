# P2C2-01 · `A-01` 启动与会话水合

**Phase C2 鉴权收尾**，其目标是：冷启动能判断「已登录 / 未登录 / 会话过期」而**不闪屏**，且三条鉴权链路（登录已有、注册、找回密码）可用。
**本任务推进 JR-8** 的第一件：**水合**与**门**。
**Starts after**：无。**Waits on it**：`P2C2-02`/`P2C2-03`（它们要有地方落）。

## 1. 本任务需要知道什么

**Read first**

- `app/src/features/auth/session.tsx` — 四态状态机（`restoring/signedOut/signedIn/expired`）与水合 effect
- `app/src/app/_layout.tsx` — Provider 顺序与 Stack；门应该挂在哪一层
- `app/src/app/login.tsx` — 现在的登录页与它的入参
- `docs/app/design/App页面骨架与布局规范.md:270` — 启动页的硬要求（logo 必须在**安全区内**居中）
- `docs/app/product/App页面清单与结构盘点.md` §3-A 的 `A-01` 行

**Settled**

- 启动页**不是原型**（页面清单写「启动流程（非原型）」）→ 它是一段**状态**，不是一个新骨架。
- 门挂在**根布局**：⛔ 不挂在页面里（否则每个页面都要判一次，且切片用例是裸渲染页面的）。
- `restoring` 期间**不允许**跳登录页（那就是"闪一下登录页"的病根）。
- 品牌位只用 `Surface` + `LoadingState`（`A-01` 的关键组件就是这三个），⛔ 不新增组件。

**Edges and seam**

- 碰 `app/src/features/{auth,navigation}/**` 与 `app/src/app/_layout.tsx`。
- Seam：**S-4 纯规则**（`resolveGateAction(state)`）+ **S-1**（门的渲染）。⛔ 不新增接缝。

**Run**

- `cd app && npx jest src/__tests__/p2c2-01 --ci`
- `cd app && npx jest src/__tests__/p1-13 --ci`（会话既有契约不得回归）
- `cd app && npx tsc --noEmit`

**Unknowns**

- 哪些路由**必须**登录？内测期先按"四个一级 Tab 可匿名浏览、只有发布/我的需要登录"还是"全部要登录"？本任务按**最小假设**：只把"未登录"送去登录页的是**需要身份的路由清单**，清单为空时门只负责"不在 restoring 期间放行错误内容"。

## 2. 工作流

1. 读上面五处，用一句话复述本任务。
2. 写 1 号用例（`resolveGateAction`：`restoring` → 显示启动位，**⛔ 不跳登录**）—— 先红。
3. 写纯函数与启动位组件，让它绿。
4. 加 2–4 号用例（未登录 → 跳登录；已登录 → 放行；过期 → 跳登录并带原因）。
5. 把门接进根布局，加 5 号用例（源码扫描：门只在根布局挂一次）。
6. 跑三条命令，提交。
