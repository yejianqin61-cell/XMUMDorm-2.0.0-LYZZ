# P2Y-D04 · T01 今日摘要

## 1. Where this task sits

公共工具 Tab 已获授权接线。本任务补齐页面清单 T01 的当前／下一节课和本地放假日摘要；不新增 T07 总览页。

## 2. What the developer needs to know

读取工具仪表盘、shared/config/semesters.js、Web 的 holidays.js 和宪法 §9.6。
日历仍是一份事实源：将原有纯日历模块迁入 shared/config，Web 原路径重导出，数据与函数行为保持一致。
App 按吉隆坡日期选择放假日，不导入 Web UI。当前课程区间为开始含、结束不含；无当前课程时仍展示当天课程。

## 3. The workflow

1. 补当前课程边界、时区和放假日跨日回归用例，提交红测试。
2. 迁移纯日历配置并保留 Web 导出接口。
3. 用分钟时钟刷新当前／下一节课程，跨日重读今日待办。
4. 同层展示本地放假日摘要，补双语文案。
5. 运行 App 回归和根测试，提交后将新增事实回写验收记录。

## 4. The test cases

| 输入 | 期望 | 接缝 |
|---|---|---|
| 08:00、09:59、10:00 | 当前课程含开始、不含结束 | 纯规则 |
| UTC 00:30 | 按吉隆坡 08:30 选当前课程 | 时区 |
| 假期最后一天及次日 | 当日仍可见，次日选下一项 | 纯规则 |
| 假期摘要与今日课表 | 四块同屏，学校入口保留 | 页面 |
