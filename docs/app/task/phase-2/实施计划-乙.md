## 2. The approach, requirement by requirement

### R-Y1 共用课表缓存

- **Approach**：先用课程名/时间往返用例修复旧格式缺陷，再在既有 hook 中合并同周请求，导入成功后失效所有周。
- **Touches**：工具域课表与导入。
- **Test seam**：既有 `readCachedWeek` / `writeCachedWeek` / `useTimetableWeek` 与导入页渲染。
- **Acceptance**：课程字段逐项相等；两个读者一次请求；导入后的旧响应不得写回；翻周不显示前周内容。
- **Hard part**：导入与正在进行的请求竞争；私有缓存不能跨账号或学期复用。

### R-Y2 工具首页三块

- **Approach**：乙域提供可直接访问的仪表盘和可复用内容；公共 Tab 接线留到最后。
- **Touches**：工具域、待办摘要。
- **Test seam**：页面渲染与既有课表 hook。
- **Acceptance**：三块真数据；每块失败可独立重试；原有课程表/导入/校方系统入口保留。
- **Hard part**：`(tabs)/tools.tsx` 属甲；本计划不擅自扩大写作用域。

### R-Y3 待办增删改勾选

- **Approach**：复用列表原语与 K01 表单，调用现有六个 API；日期时间先提供受校验的输入，平台选择器准入单独处理。
- **Touches**：待办域与工具路由。
- **Test seam**：待办页面交互；日期时间/载荷纯函数。
- **Acceptance**：创建、编辑、勾选、删除均发真实 API；删除二次确认；分页不漏项；无效日期不提交。
- **Hard part**：原生选择器尚无公共组件与依赖准入，不把输入框宣称为已交付的平台选择器。

### R-Y4 食堂发点评

- **Approach**：独立 S11 路由消费 K01 Form 与 RatingScale；成功发出失效信号，S10 读外壳重取。
- **Touches**：食堂域表单与读资源。
- **Test seam**：表单校验和页面提交渲染。
- **Acceptance**：五档载荷与后端枚举一致；300/301边界；只成功时失效；匿名投影保留。
- **Hard part**：图片依赖未准入；S11 不在全局 PublishId 注册表，不能复制发布宿主。

### R-Y5 食堂搜索

- **Approach**：在页内明确提交关键词；不合法关键词不发请求；按接口返回的 products/articles 分页展示。
- **Touches**：食堂检索域与路由。
- **Test seam**：搜索页渲染与业务关键词判断。
- **Acceptance**：空/超长为可解释空态；有效结果有去向；翻页去重；请求竞争只留下最新关键词结果。
- **Hard part**：接口 HTTP200 `status:-1` 会被共享请求层抛出，必须在请求前镜像长度约束。

### R-Y6 食堂读缓存

- **Approach**：给既有 useCanteenResource 增加可选缓存配置，不改 normalize 返回形状；公开数据落盘，过期后台刷新。
- **Touches**：食堂读外壳与四张既有页。
- **Test seam**：既有 `useCanteenResource` 渲染接缝。
- **Acceptance**：区域10分钟、榜单30秒；键含筛选；显式重试绕过新鲜缓存；旧失效请求不写回。
- **Hard part**：详情与列表分数均依赖评论，失效要覆盖整个食堂读域。

### R-Y7 错误与逐页验收

- **Approach**：实现过程中自带四态与对称词条；末批补齐逐屏13.1证据，再按固定差异审计。
- **Touches**：乙域、增量词条、乙验收文档。
- **Test seam**：页面交互测试、App verify、根测试。
- **Acceptance**：类型检查、相关回归、全量测试、四把尺子；真机/读屏/返回栈未测项有明确状态。
- **Hard part**：自动化通过不等于双平台真机通过；依赖或甲域缺口不得冒充完成。

## 3. Phases

### Wave A · 打通共享数据（3项）

**Goal**：课表远端→落盘→离线显示闭环，导入后读者共用更新；点评字段与失效契约明确。

1. 修复课表缓存字段往返丢失（P2Y-A01）。
2. 合并课表请求并接导入失效（P2Y-A02）。
3. 定义点评字段与食堂失效契约（P2Y-A03）。

**Proof**：课表完整字段往返、并发/导入竞争、五档/字数边界用例；每项提交；批次小结。
**Not here**：公共 Tab、图片准入、S10 收藏与评论写控件。

### Wave B · 四张可用页面（4项）

**Goal**：T06、T01、S11、S14 可以直接访问并调用现有接口，每页自带双语与四态。

1. 实现待办列表及表单（P2Y-B01）。
2. 实现工具仪表盘（P2Y-B02）。
3. 实现五档点评表单（P2Y-B03）。
4. 实现食堂检索（P2Y-B04）。

**Proof**：页面渲染/提交/失败/空态用例；类型检查；批次小结。
**Not here**：平台日期时间选择器、原生选图、公共 Tab 接线。

### Wave C · 缓存与验收收尾（3项）

**Goal**：离线仍可读、错误可修正，乙逐页交付范围与未测项可核查。

1. 接食堂读缓存与提交失效（P2Y-C01）。
2. 补导入400修正提示与边界回归（P2Y-C02）。
3. 完成逐屏13.1、批次小结与本轮审计（P2Y-C03）。

**Proof**：全量 verify、根测试、固定基线审计；证据列出命令与结果。
**Not here**：广告/榜单铺页、生产部署、EAS发布、未获裁决的冲突项。

最后处理三组冲突：公共 T01 入口；S10 写路径归属；图片及日期时间平台组件准入。先交可审查的实现与差异，再请求确有必要的裁决。
