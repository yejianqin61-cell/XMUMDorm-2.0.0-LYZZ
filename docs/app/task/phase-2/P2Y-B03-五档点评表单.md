# P2Y-B03 · 五档点评表单

## 1. Where this task sits

- Wave B 四张可用页面；推进 R-Y4 食堂发点评。
- Starts after：字段/失效契约；Waits on it：食堂缓存刷新与S10入口裁决。
- 自有S11路由；原生选图留待准入，不把禁用控件报为完成。

## 2. What the developer needs to know

**Read first**
- `app/src/features/square/review.ts` — 既定字段和五档载荷是什么？
- `app/src/components/ui/Form.tsx` — 提交与离开确认如何共用？
- `app/src/components/ui/MediaPicker.tsx` — 可注入选图与限额如何接？
- `shared/api/canteen.js` — FormData载荷如何传给共享API？

**Settled**：正文必填≤300；图片≤3且neverDraft；成功后invalidate再返回详情；服务端鉴权为权威。
**Edges and seam**：K01表单页面提交；不注册全局PublishId、不改公共组件。
**Run**：`cd app; npm.cmd test -- --runInBand --silent p2y-b03 p2y-a03`；`npm.cmd run typecheck`。
**Unknowns**：原生选图未准入；提交失败必须保留正文，不能再次覆盖草稿。

## 3. The workflow

1. 阅读第2部分并复述：五档与正文提交走K01唯一状态机。
2. 写缺评级不提交及合法提交用例。
3. 接RatingScale、正文和图片字段到Form。
4. 接鉴权错误、失败保留输入、成功失效与返回。
5. 验证双语与边界，运行类型检查并提交。

## 4. The test cases

| Case | Input | Expected | Seam |
|---|---|---|---|
| 缺评级 | 只有正文 | 字段错误、不调用API | 表单 |
| 合法提交 | hot+Good | 夯爆了+Good、成功去详情 | 表单 |
| 重复点击 | 提交未完成 | 一次请求 | 表单 |
| 失败 | 离线拒绝 | 正文保留、三要素提示 | 表单 |
| 深链错误 | id非正整数 | 业务空态，零写请求 | 页面 |
