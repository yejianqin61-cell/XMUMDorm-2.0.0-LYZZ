## 2. 实现要点

### 2-1 ⚠️ README §7-12：`P11` 说的"节次"，接口**没有**
§2.7 把 `P11` 描述为"星期 × **节次**"，但 `GET /api/schedule/week` 只给
`start_time`/`end_time`（`routes/schedule.js:160`）—— **没有节次编号，也没有节次表**。
→ 行键用**开始时间**（`buildTimetableRows`）。
⛔ 不猜"第几节"：那等于凭记忆造一张节次表（宪法 15.2-1 明令禁止）。
将来后端若给出节次，只换行键即可，**网格与页面的契约不变**。

### 2-2 周切换：`C14` 上限 5 项，而学期有 ~18 周
页面清单指定用 `C14 SegmentedControl`，而它**最多 5 项**（§2.2 硬约束），
一学期 18–20 周 → 只能给**窗口 + 平移**：
- `weekWindow(center, totalWeeks, 5)`：以选中周为中心的 5 周窗口，夹在 `1..totalWeeks` 内；
- 左右两个 `IconButton` 各平移**一整屏**（5 周）。
⛔ 没有把 18 项塞给 `C14`（它会在 dev 下报警告，那正是它的用途）。

### 2-3 今天高亮：**只有显示的就是当前教学周时**才高亮
`shouldHighlightToday(shownWeek, currentWeek)`。否则用户翻到第 3 周时，今天那一列会被点亮
——那是**误导**。服务端说"未开学/已结束"（`currentWeek = null`）时一律不高亮。

⚠️ "今天"用 **吉隆坡时区**（`kualaLumpurCalendarParts`）而不是设备本地时区：
学校在马来西亚，学生漫游或跨时区时按设备时区算会**高亮错行**。
用例专门断言"17:00Z 在 KL 已是周一"这种跨日边界。

### 2-4 本地优先（宪法 10.6）：先给缓存 → 再打远端 → **失败不清空**
`useTimetableWeek` 的三步：
1. 读缓存 → **立刻**有内容可看（`source='cache'`，页面挂 `OfflineBanner(variant=stale)`）；
2. 打远端 → 成功则替换并**写回缓存**（`source='remote'`）；
3. 失败 → **保留已有内容**、只把错误挂上（页面据此决定是否显示陈旧提示）。
用例断言：**远端失败但有缓存时，内容仍在**（这正是"离线优先"的全部意义）。

### 2-5 鉴权失败在 **fetch 包装层**处理（P1-13 接缝的正确用法）
⚠️ 这里有个容易写错的地方：接缝要的是**抛出来的原始错误**（带 `status`/`body`），
而 hook 存下来的是 `AppError`（**已经没有 `status` 了**）→ 拿 `AppError` 去分类只会得到 `other`，
**会话失效就不会清令牌**。所以包装层里 catch → `handleAuthFailure` → 抛 `AppError`；
`T02` 的 onAction 只负责重试。⛔ 页面里不出现 `status === 401` 这类判断。

### 2-6 课程卡点击：**不假跳一个不存在的路由**
页面清单只要求"课程卡可点"，**没有课程详情页**（也不在组件/原型清单里）。
所以点击给一条**回执**（课程 + 时间 + 地点），⛔ 不 `push` 一个没建的 `/tools/course-detail`。
用例专门断言跳转目标里**不出现** `course-detail`（防止后来者"顺手补一个假路由"）。

## 6. 风险与降级

| 风险 | 触发 | 处置 |
|---|---|---|
| 网格横向滚动在小屏上"看不全一周" | 5 天很挤 | 时间列宽 + 每天列宽都走令牌（`space_12`）；若真机反馈挤，改为"只显示有课的天"并在 §7 回写（⛔ 不写死数值） |
| 缓存无 TTL（可能显示很旧的课表） | 长期离线 | 已用 `OfflineBanner(stale)` **明示不是最新**；TTL 与"课表多久变"有关，属 `T-02` 的后续口径（登记） |
| 后端 500（缺表）时的文案 | 迁移未跑 | 服务端 message 很长且是技术性的 → 本页走 `T02` 的通用错误三要素，⛔ 不把服务端技术文案直接给用户 |
| `TodayCard` 缺失 | 用户想知道"下一节课" | 本页网格已能回答"周几几点有什么课"；`TodayCard` 与 `T-01` 一起裁（登记） |
| 周次与校历不一致 | 校历调整 | 周次全部由服务端 `currentWeek/totalWeeks` 驱动，**客户端不内置校历**（`shared/config/semesters.js` 只用于夹紧与"今天"） |
