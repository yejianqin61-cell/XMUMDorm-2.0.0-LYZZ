## 2. 实现要点

### 2-1 状态机是纯函数（§3.2.3 `【已定】`）
`formReducer` 的三条不变量都写成了断言：
- **`submitting` 期间不得再提交**（`submit:start` 返回**同一引用**）；
- **提交中改内容不打断提交**（`edit` 在 `submitting` 下无效）；
- `submit:success` **清掉字段错误**（否则成功页上还挂着红字）。

`hasUnsavedChanges` 也定死了边界：`dirty`/`validating`/`error` 为真；**`submitting` 为假**
（正在保存不算"未保存"）；`success` 为假。

### 2-2 ⚠️ 一处**文档与文档冲突**的处置（如实记录）
- **§3.2.1** 把 `FormField` 的解剖写成"标签 + 必填 + 控件 + 就近错误"；
- **§3.3.2** 又把同一套写进 `C04`/`C05` 的解剖里。

两者**只可能有一处渲染**，否则同一个标签会出现两遍。本包选择：
**标签 / 必填 / 就近错误由控件渲染**（§3.3.2），`K03` 负责**描述符 → 控件的映射**，
并补控件没有的两件事：**帮助文案**与**字段注册**（`K04` 才能"把焦点移过去"）。

为什么不做成"K03 画标签、控件画裸输入"：那要给 8 个控件各加一个 bare 模式，
换来的只是把同一份标签换个地方画 —— 属 §9.14-① 说的"同语义多层"。

### 2-3 草稿与凭据护栏（这轮最要紧的一处）
宪法 4.4.3 要求"进程被杀后输入不丢"，落盘层（P1-02）却有**凭据护栏**：
`draft:change-password` 这种 key 切分后出现 `password` 段 → `CredentialStorageError`。
本文件的处置：
1. `draftableValues()` **剔除** `password` 类字段（⛔ 绝不把凭据写进 AsyncStorage）；
2. 落盘前 `canPersistDraft()` 预检 → **不通过就干脆不落草稿**（⛔ 不崩、也不静默写）；
3. **`idle` 与 `success` 不写草稿** —— 这条是实测踩出来的：
   最初"每次值变化都写"，于是**刚打开什么都没改也会留下一份草稿**，
   下次进来会被当成"有未保存内容" → **用户没改过任何东西却被弹离开确认**。

### 2-4 提交语义（§3.2.4）写成类型，页面拿不到"弹窗"这个选项
`postSubmitPlan(semantic)` → `{ navigate, invalidateLists, announce }`，
而 `announce` 的类型是 `'toast' | 'none'` —— **⛔ 成功不得弹对话框**（宪法 10.4）
这条不是靠 review 记得，而是**类型里没有那个取值**。

### 2-5 其他按文档落地的细节
- **服务端字段错误按名回填**：`applyServerFieldErrors` 把映射不上的**收进 `unmapped`**（不丢，交 `K04` 置顶）；
- **不可见字段不参与校验**（否则"没填的条件字段"会永远挡住提交）；
- `isEmptyValue` 明确 **`0` 与 `false` 不算空**（否则"数量 0"会被判未填）；
- 校验函数返回**词条 key**，⛔ 不返回拼好的句子（语言切换后文案要跟着变）；
- ⛔ **提交中不整屏变灰**（§3.2.5-④）：只有主按钮 `loading`，字段保持可用。

## 3. ⚠️ 一条**流程事故**与由此新增的纪律

修测试时我用 PowerShell 的命令行传了**含中文**的替换字串，结果 `Get-Content -Raw` +
`WriteAllText` 把整个测试文件的 UTF-8 **按 cp1252 解码后又写成 UTF-8** —— 全文中文字面量变成乱码。
已用一次性脚本（cp1252 → 字节 → UTF-8）**完整还原**并核对，未丢内容。

因此给任务包补一条纪律（已写入 [README §3](README.md)）：
> **⛔ 不要用 shell 传非 ASCII 文本去改文件**（命令行的代码页会把中文写成乱码）；
> 改文件一律用编辑器工具（`write`/`edit`），它们不经过 shell。

## 6. 风险与降级

| 风险 | 触发 | 处置 |
|---|---|---|
| 草稿**每次输入都写** AsyncStorage | 长文输入（课评 3000 字） | 当前是"输入不丢优先"；若真机发现卡顿，改为**节流写**（时间量不是尺寸，不走令牌）；⛔ 不改成"只在失焦写"（进程被杀就丢） |
| `Form` 内部挂了 `Screen` | 页面想自己控制骨架 | 现阶段 `P4` 就是整页骨架，故自带 `Screen`；若将来要嵌进 Sheet（`O11`），加 `variant='sheet'` 让外层决定容器，⛔ 不复制一份表单 |
| 焦点移动依赖 `findNodeHandle` | 该 API 已被 RN 标记为将来移除 | 已隔离在 `focusAccessibilityElement` 一个函数里；届时换 ref 方案只改一处 |
| `asyncValidate` 尚未接进 `useForm` | 唯一性/权限类字段 | §3.2.2-④ 允许它只用于这两类；等第一个真实用例（组织身份 `P-04`）出现时接，⛔ 不预先造 API |
