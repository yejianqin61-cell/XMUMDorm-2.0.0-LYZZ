## 3. 实现要点

### 3-1 `Toast` 的**动作与状态必须分成两个 context**
P1-07 第一次跑这条用例直接把 Node 跑到 **OOM**：测试里写 `useEffect(…, [toast])`，
而 `show()` 一改 `current`，context value 身份就变 → effect 重跑 → 又 `show` → **无限循环**。

这不是"测试写错了"那么简单：**我的 API 让页面很容易掉进这个坑**。
所以拆成两个 context：
- `ToastStateContext`（`current`，**会变**）→ 只给展示层 `ToastHost`；
- `ToastActionsContext`（`show`/`dismiss`，**身份稳定**）→ 给页面的 `useToast()`。

页面现在可以安全地把它放进依赖数组。用例里也留了注释说明为什么依赖写 `toast.show`。

### 3-2 `ToastHost` **不读 insets**，由根布局取一次传进来
宪法 17.1-S2 的授权依据不是我的推断，而是 `p0-04` 用例标题自己写的
**"S2：Screen 与根布局各一处"** —— 根布局就是那个指定的第二处。
分工：`GlobalOverlays`（在 `SafeAreaProvider` 内）调一次 `useSafeAreaInsets()`，
把 `bottomInset` 当**普通 prop** 传给 `ToastHost`。
⛔ 展示层自己再调 hook 就变成第三个调用点，"唯一容器"名存实亡。

### 3-3 `T02` **结构上**不可能泄露技术细节
组件只接收 `AppError`（`kind` + `target` + 可公示的 `params`），拿不到 HTTP 状态码/堆栈/内部码。
所以"不泄露技术细节"不是靠自觉，而是**类型上没有那个通道**。用例另加一条源码断言。

### 3-4 `T03` 的"不配文字"是可测的
断言 `LoadingState.tsx` 里**没有 `<Text`**。⛔ 没有「加载中…」这类无信息量文案（10.5-5）。
另：本组件**不声明 reduced-motion 降级** —— 骨架/转圈表达的是"进行中"这一**状态**，
关掉会让人分不清"在加载"与"加载完但为空"；§7.4 列出的降级项是**页面进退**与**点赞缩放**。

### 3-5 `T05` 把"错误必须带 retry"写进类型
```ts
{ state: 'idle' | 'loading' | 'end' } | { state: 'retry'; onRetry: () => void; retryLabel: string }
```
`state:'retry'` 那一支**必须**给 `onRetry`，否则 `tsc` 不过。
另外 `loading` 与 `retry` **不允许同时出现** —— 分页状态机保证同一时刻只有一个在跑，
多给一个 prop 就等于允许非法状态。

### 3-6 `T06` 的令牌→属性映射抽成纯函数
测试渲染树里 `RCTRefreshControl` 的 props 是**空的**（原生组件不经 JS 树暴露），
所以"颜色是否来自令牌"没法靠渲染断言。抽成 `refreshControlProps(spec)` 后这条**可测**，
组件只剩"取主题 → 调用 → 渲染"三步。

### 3-7 `O08` 的三条硬约束
① **insets 从唯一容器取**（`useScreenInsets`，S7）；② **失败绝不丢内容** —— 组件**从不清空输入**，
清空是调用方在成功后的责任（§4 `failed` 行）；③ 计数器**复用 `C05` 的 `counterState`/`counterLabel`**，
⛔ 不另写一套三态与警告双通道。

### 3-8 ⛔ 本轮**不做**的
| 项 | 原因 |
|---|---|
| `Toast` 的**滑走关闭** | 需要 `gesture-handler` 的手势接线；本版是**点击关闭 + 自动消失**，已登记 |
| `O07 PickerSheet` | 仍缺（P1-05 已登记），`C07`/`C09` 的最终形态等它 |
| `O06 BottomSheet` / `O11 FullScreenModal` / `O12 FullScreenNotice` / `O13/O14` | 不在本任务范围（§2.5 的其余覆盖层按消费者出现再做） |

## 6. 风险与降级

| 风险 | 触发 | 处置 |
|---|---|---|
| `Toast` 不能滑走 | 真机手感评审 | 接 `gesture-handler` 的 pan 手势；⛔ 不自绘（与 `T06` 同一条原则）。已登记遗留 |
| `O03` 的透明遮罩用了 `bg-canvas` 当遮罩色 | 视觉评审认为不够"压暗" | 令牌源若加 `bg-scrim` 就用它；⛔ 不写 `rgba()` 裸值 |
| `O05` 的 modal `animationType="slide"` 不受 reduce-motion 控制 | 真机（系统开了"减弱动态效果"） | 按平台读数换 `animationType="fade"`；已列 `TC-P1-07-1M` |
| `ToastHost` 用绝对定位，多个 Toast 会重叠 | 连续快速操作 | 现在是**后一个替换前一个**（`current` 单值）。若需排队，加队列，但不改 context 契约 |
| T/O 层"零中文字面量"的强制 | 后续任务觉得麻烦 | 这是**刻意的**：文案必须走词条表，否则英文界面会出现中文 |
