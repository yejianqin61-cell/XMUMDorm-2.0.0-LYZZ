## 2. 本轮**一个独立 bug 修复**（`4dfb848`）

一次跑测试出现 **20 个失败**，症状极具误导性：失败的是**后面毫不相干的用例**，
根因却在**前面**。定位链（每步都实测复现）：
1. 把失败的组件单独渲染 → **全部正常**；
2. 逐个 describe 单独跑 → `3A` 独立就红，`6A`/`11A` 独立却绿 → 存在**跨用例污染**；
3. 二分到最小复现：**同一个 `it` 里 `render()` 两次**，会让**下一个用例**的渲染查不到任何节点；
   在两次渲染之间 `await cleanup()` **更糟**。

→ 新增 `__tests__/helpers/renderApp.tsx`：Provider 接线收一处 + **第二次调用直接抛错**
（把"几层之后才炸"变成"就在犯错那一行炸"）。

同一次排查还得出一条**交互规则**（实测）：
**`fireEvent.press` 会调用 handler，但不会把 `setState` 的重渲染冲出来**；
`userEvent.press` 可以。即"断言回调被调用"用 `fireEvent` 够，"断言界面变了"必须 `userEvent`。
⚠️ 这条**推翻了 P1-05 的一个结论**：当时把 `C07 Select` 展开断言失败归因为
"RNTL 不在 `combobox` 角色上模拟 press" —— **那个归因是错的**（真实原因是上面这条）。
`Select` 的受控 `open` 依然是改进（表单 DSL 需要），但理由已在 P1-05 v1.1 更正。

## 3. 实现要点

### 3-1 `D11 RatingScale`：**非线性**是它的存在理由
5 档权重 **10 / 7 / 4 / 1 / −1**（§3.1 已核对枚举表）。用 1–5 星表达会把它压成等距刻度，
而**榜单正是按这个权重算的** —— 所以"不能用 `D10` 代替"不是偏好，是口径问题。
用例里专门断言**相邻差值不是常数**，把"非线性"变成可测事实。
标签走词条（`canteen.rating.*`），权重与档位映射是纯函数。

### 3-2 `D02`：匿名投影**类型上拿不到身份**
```ts
type CommentAuthor = { kind: 'anonymous' } | { kind: 'named'; name; avatarUri?; levelLabel?; onPressAuthor? }
```
⛔ 不做成 `{ name?: string; anonymous?: boolean }` —— 那样"传了 name 且 anonymous=true"
就成了合法状态，而那正是要防的。匿名分支连**头像位**都不渲染（占位方块会暗示"这是某人"）。

### 3-3 `D24`：跳转的安全边界写在纯函数里
`resolveBannerTarget` 的分支：
- `https` → **只放行 `https://`**（`http://` / `javascript:` / `data:` 一律 → `none`）；
- `internal` → 只放行以 `/` 开头且**不是 `//`** 的站内路径；
- `shop`/`product`/`region` → 返回 `{entity, id}`，**路由表属页面**（⛔ 组件不认识路由）。
另：`shouldAutoRotate`（单张不转 / 减弱动态不转）；⛔ **不展示排期**（后端 `parseBannerBody`
写不进 `starts_at/ends_at`，不确定的信息不显示）。

### 3-4 `D18`：用已准入的库，但**视觉必须全归令牌**
`@ronradtke/react-native-markdown-display` 早已在准入登记里（MIT、0 原生文件 → 可 OTA）。
⚠️ 必须 **`mergeStyle={false}`**：否则库自带默认样式会与令牌混在一起，
出现"设计系统管不到的字体和颜色"（宪法 1.4 要防的正是这个）。
关掉之后每一处视觉都来自 `markdownStyles(theme)`，用例把它**逐值校验**：
颜色必须等于某个颜色令牌的值、数字必须落在间距/圆角/描边/字阶的取值集合内。
TOC 按 §2.6 由本组件 own（后端只存原文）：`extractToc` **跳过围栏代码块里的 `#`**、
去掉标题里的行内标记、重复标题自动加序号。

### 3-5 顺带发现并修掉的两处"语言串台"
- `RatingScale` / `StarRating` 的组合式无障碍标签原先在代码里拼中文
  （`${label}，权重 ${weight}`）→ 英文界面会读出中文。已抽出词条
  `a11y.ratingTier` / `a11y.starRating` / `a11y.starRatingBare`。
  ⚠️ **这条债在 P1-05 的控件里还在**（`'必填'`、`'清除'`、`移除${…}` 等默认标签），已登记 TD-46。
- `StarRating` 的 `View` 上没有 `accessible`：RN 的 `View` 默认不是无障碍元素，
  只给 `accessibilityRole` 是**不生效**的（读屏与 `getByRole` 都看不到）。

### 3-6 新依赖问题的登记（已写入依赖准入登记 §troubleshooting）
`@ronradtke/react-native-markdown-display` 的 `dist/` **带着未编译的 JSX**（Metro 会编、
Jest 不会）→ 必须在 `jest.config.js` 的 `transformIgnorePatterns` 里给它开例外。
⛔ 做法是**展开 preset 的正则、只追加一项**，而不是手写一份完整名单（那会随 preset 升级静默过期）。

## 6. 风险与降级

| 风险 | 触发 | 处置 |
|---|---|---|
| `D18` 的库样式键覆盖不全 | 出现某个未映射元素（如表内链接） | `mergeStyle={false}` 下"没给"= 没样式（不会偷偷用库默认值），表现为**缺样式而不是错样式**；补齐 `markdownStyles` 即可 |
| `D24` 的 `slideWidth` 依赖 `onLayout` | 首帧宽度为 0 | 首帧按 `flex:1` 渲染，量到宽度后转固定宽；⛔ 不用 `useWindowDimensions`（会忽略容器内边距与大屏 `maxContentWidth`，违反 17） |
| `RatingScale` 的档位标签在窄屏折行 | 真机（英文标签更长） | 已有 `flexWrap`；若仍挤，改为两行布局，但不改档位语义 |
| 组合式 a11y 标签仍是中文（`D01`/`D02`/`D03` 的 `labels` 由页面给） | 英文界面 | 这些**本来就是 props**（页面传词条）✅；残留的是 P1-05 控件的默认标签 → **TD-46** |
