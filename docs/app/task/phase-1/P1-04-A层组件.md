## 1. 目标

把 12 个原子交付到"**页面可以只拼组件、不碰任何数值与色值**"的程度。
判据不是"文件写完了"，而是：**后续页面写不出魔法数字** —— 尺寸只能从档位里选，色只能从语义令牌里取。

## 3. 实现要点

### 3-1 为什么 `A03 Stack` 值得单独存在
宪法 2.4 要求"间距只取令牌档位"。只要页面还在手拼 `flexDirection` + `gap`，"写个 12" 就随时可能发生。
`Stack` 的 `gap` **类型是 `SpaceKey`**（令牌键的联合），把"能不能写数字"从**纪律问题**变成**编译问题**。

### 3-2 `A06 Icon` 的 a11y 二选一是**结构保证**，不是提醒
`label` 传与不传走两条分支：传 → `accessible` + `accessibilityRole="image"` + `accessibilityLabel`；
不传 → `accessible={false}` + `accessibilityElementsHidden` + `importantForAccessibility="no-hide-descendants"`。
⛔ 不用 `aria-hidden`：Lucide 的 `hasA11yProp` 把任何 `aria-*` 判为"有语义"，**反而会把它暴露给读屏**。

> **实现期发现（很值得记）**：P1-04 的用例第一次跑时，`getByTestId(hiddenIcon)` **查不到**节点 ——
> 因为 RNTL 默认**不返回被隐藏的节点**。这本身就是"隐藏真的生效"的旁证。
> 于是把它写成两条用例：一条断言**隐藏方式**（`includeHiddenElements: true` 才看得到），
> 一条断言**默认查询确实查不到它**（防止"设了 prop 但没起作用"）。

### 3-3 `A08 Badge`：色调与承载文字是**成对**的
`action-primary` 载白字 7.41:1（`text-on-fill` 的 `minReason` 明确只允许它）；
`action-accent`（美团黄）**只承载深墨**（`text-on-accent`）——白字 on 它是 1.61:1，属红线；
`state-*` 填充暗色下很亮 → 用 `text-on-state`（深墨）。这三条映射不是审美选择，是**实测对比度的直接后果**。

### 3-4 `A12 Pressable` 的降级是可测的
`resolveFeedback(feedback, reduceMotion)` 抽成**纯函数**导出。
理由：否则只能 mock `AccessibilityInfo` + 等 effect，测试会不稳。现在它是四条纯断言。

### 3-5 ⛔ 明确**不做**的部分（不建无引用 API，宪法 9.1）
| 项 | 为什么不做 |
|---|---|
| `A10 Skeleton` 的 `grid` 变体 | 内测里没有它的消费者（宫格在 `S-01`，非内测） |
| `A11 Progress` 的 `segmented` 变体 | 消费页 `S-12` 非内测 |
| `A09 Chip` 的 `filter` 变体 | 与 `selectable` **视觉完全相同**，差别只在语义位置（导航 Tab ≠ 筛选 Chips，4.8.1-R4）——那由布局保证，⛔ 不为同名不同义铺第二份 API |
| `A08 Badge` 的 `level`/`draft` 变体 | 消费页 `M-01/M-03/M-09` 属后续任务 |
| `Surface` 的 `accentSoft/successSoft/warningSoft/dangerSoft` | 令牌**已存在**（`bg-*-soft`），但**没有消费者**；等第一个消费者出现再加一个映射即可 |

## 7. 风险与降级

| 风险 | 触发 | 处置 |
|---|---|---|
| `Avatar` 的尺寸借用间距令牌，语义不准 | 设计日后定了 avatar 专用档位 | 令牌源加一组，只改 `Avatar.tsx` 的映射，**调用点形状不变** |
| `Skeleton` 用 `bg-sunken` 当骨架色（**骨架专色令牌源未定义**） | 视觉评审认为骨架太"实" | 令牌源加骨架专色后只改一个文件。缺口已在文档登记 |
| `Pressable` 的 `hitSlop` 默认 `space_2` | 真机上相邻可点元素误触 | 调默认值或用 `hitSlop` prop 覆盖；**不做"自动按相邻元素收缩"**（那是隐式魔法） |
| SVG 环形进度在低端机上有绘制开销 | 真机掉帧 | `ProgressRing` 只在 `M-01/M-17` 用；若成问题改用 `bar` |
| 新增 `icon-size` 组破坏生成器幂等 | 忘记加进 `groupOrder` | 已加；TC 与幂等检查（连跑两次字节一致）都在 |
