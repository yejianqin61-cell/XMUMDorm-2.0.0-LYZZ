## 3. 实现要点

### 3-1 App 自己建 client，但**契约必须共享**
`shared/query/queryClient.js` 导出的是 **Web 的** client（按浏览器语义调的默认值）。App **不复用那个实例**，而是自建，理由：
- 共享的是**契约**（query key 一律来自 `shared/query/queryKeys.js` 的 `QK`）；
- client 配置是**宿主事实** —— 与 `shared/api/platform.js` 的分工完全一致（宿主给事实，shared 给契约）。

⛔ 因此写了一条结构测：`app/src` 内**不得**出现 `export const QK`（不许本地重写一份 key 工厂）。

### 3-2 默认值与其理由（每一条都能被问"为什么"）
| 项 | 值 | 理由 |
|---|---|---|
| `staleTime` | 60s | 与 Web 的 `shared/query/queryClient.js` 对齐 |
| `gcTime` | 15min | 进详情再返回不重拉 |
| `retry` | 1 | 校园网抖动重试一次；⛔ 不叠到用户可感知的等待 |
| `refetchOnWindowFocus` | **false** | RN **没有 window focus 语义**，开着等于悬空 |
| `refetchOnReconnect` | true | 断网恢复自愈（10.6 的另一半） |

> 逐接口的 TTL 精度（banners 5min / regions 10min / rankings 30s）在**各自调用点**用 `staleTime` 覆盖，⛔ 不改全局。

### 3-3 ⛔ 凭据护栏（宪法 4.1.2-2 的机器化）
`storage.ts` 的 `assertNotCredential()` 在**写入前**拦下凭据类 key，匹配规则按**分隔符切分的整段**：
- 拦：`token` · `jwt` · `auth:token` · `refresh_token` · `user:password` · `api.credential`
- 不误伤：`draft:publish` · `cache:tokenizer:size` · `cache:schedule:week`

依据：我们自己的 JWT 走 `expo-secure-store`；把凭据写进 AsyncStorage 明文是宪法级禁止项。

### 3-4 脏数据不得抛
`getItem` 的 `JSON.parse` 包在 `try/catch` 里，坏值返回 `fallback`（默认 `null`）。
理由：这些读发生在**渲染路径**上，抛异常就是白屏（与 P1-01 的 `unwrapArray` 同一条纪律）。

### 3-5 连通性必须接线（否则"离线优先"是空话）
TanStack 默认靠 `navigator.onLine` 判断在线 —— **RN 里它不存在**，于是永远认为在线。
`configureConnectivity()` 把 NetInfo 的状态映射成 `onlineManager.setOnline(...)`，判据是
`isConnected === true && isInternetReachable !== false`（后者可能是 `null`，语义是"未知"，按在线处理）。
