## 2. 为什么本 task 停止

正式法律文本是外部批准输入。工程自行改写会产生法律和发布风险，也会破坏“正文来自批准版本”的验收条件。

因此本轮：

- 不删除占位提示。
- 不伪造版本日期或批准状态。
- 不修改 `legal.ts` 的正文内容。
- 保留 P-1 / TD-61 为上架前开放项。

需要所有者提供：

1. 中文隐私政策正文及版本日期。
2. 英文隐私政策正文及对应版本日期。

4. 英文服务条款正文及对应版本日期。
5. 明确的批准版本标识。
