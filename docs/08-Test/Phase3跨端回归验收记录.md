## 人工验收清单

以下项目由发布前验收人员在实际设备和生产环境执行：

- 管理员完成广告创建、草稿预览、投放位配置、上线、复用、下线、过期、归档和点击统计查看。
- 普通用户无法从树洞、食堂、广场普通流、搜索、热搜、推荐或个人帖子列表发现广告帖。
- 有效广告轮播进入广告详情；无效广告显示不可用状态，不落入普通帖子详情。
- App 内站内 CTA、HTTPS 外链、Android 返回键和 Web 外链行为符合规格。
- App 四栏 Tab 在中文/英文、小屏、安全区、手势导航、三键导航、字体放大和减少动效设置下稳定。
- 树洞中英文页面不显示个性化推荐暗示，且排序、分页和筛选行为不变。

## 已知边界

- 第一版不包含计费、曝光归因、转化归因、竞价和推荐算法。
- 微信、WhatsApp、电话、短信及其他特殊协议暂不支持。
- 生产数据库必须先执行广告相关迁移后再启用广告管理功能。
