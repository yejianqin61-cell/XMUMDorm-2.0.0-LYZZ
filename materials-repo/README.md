# XMUM 学习资料库

XMUM（厦门大学马来西亚分校）学生学习资料的公开仓库，由
[XMUMDorm（厦马小筑）](https://github.com/yejianqin61-cell/XMUMDorm-2.0.0-LYZZ)
站点的「学习资料」模块驱动。

**浏览与下载请走站点**，不要直接浏览本仓库 —— 站点的课程页会把同一门课的
笔记 / 课件 / 试题 / 答案聚合在一起，并提供在线预览。

---

## 这个仓库是什么

- **存储**：所有资料文件本身（Markdown / PDF / 图片 / 压缩包等）
- **索引**：`index.json` —— 站点前端的唯一入口，含每份资料的课程、类型、课时、
  考试节点等元数据
- **校验**：`.github/workflows/validate.yml` 在每次 PR 上做强制校验

## 这个仓库不是什么

- ❌ 不是代码仓库（站点代码在另一个仓库）
- ❌ 不存放任何用户身份信息（上传者昵称之外，没有用户数据）
- ❌ 不接受绕过站点的上传（普通用户无需 GitHub 账号，通过站点上传即可）

---

## 目录结构

```
c<courseId>/<type>/<文件>
```

- `courseId`：课程 id（稳定、永不重命名）；课程名与 id 的映射见 `index.json` 的 `courses[]`
- `type`：五类之一 —— `notes`（笔记）/ `lecture`（课件讲义）/ `exam`（试题）/
  `answer`（答案）/ `other`（其他）

完整规范（命名、体积、允许类型、安全约定）见 **[CONTRIBUTING.md](./CONTRIBUTING.md)**。

## 下架与举报

如果你是**著作权人**，或发现仓库中存在侵犯你权利、泄露隐私、或你不希望被公开的内容，
请通过以下任一方式联系我们，我们会在核实后**尽快下架**：

- 在 GitHub 上开一个 Issue 说明（可标注 `takedown`）
- 通过 [XMUMDorm 站点](https://github.com/yejianqin61-cell/XMUMDorm-2.0.0-LYZZ) 的反馈渠道联系管理员

> ⚠️ **关于下架的时效**：本仓库内容通过公共 CDN（jsDelivr）分发，而 jsDelivr 会**长期缓存**
> 已分发的文件。即使我们从仓库中删除了文件，**CDN 上的副本仍可能在短时间内（甚至更久）
> 继续可访问**。我们会尽力清理（包括向 CDN 提交 purge 请求），但**无法保证即时生效**。
> 这一点请在下架申请时知悉。
