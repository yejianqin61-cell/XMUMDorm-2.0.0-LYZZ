# 业务理解

- 软件名称：厦马小筑
- 产品定位：面向厦门大学马来西亚分校学生的校园生活与社区服务平台，提供移动端和网页端入口。
- 面向领域 / 行业：教育信息化与校园生活服务
- 核心价值：将校内讨论、校园通知、食堂信息、社团活动、二手交易、跑腿和个人日程集中在同一校园账号下，减少学生在多个群组和渠道之间查找信息的成本。
- 证据文件：`业务理解证据.md`

## 目标用户

- 厦门大学马来西亚分校在校学生
- 校内社团、学院和学校组织的内容负责人
- 平台内容与用户管理员

## 主要业务功能

- 校园账号与个人资料
- 匿名社区与内容互动
- 校园广场与组织通知
- 食堂信息共建与评价
- 社团活动与成员协作
- 二手交易与跑腿服务
- 课程日程、待办与日记
- 站内通知、举报与后台治理

## 功能说明

- 校园账号与个人资料：学生可注册、登录并维护昵称、头像和语言偏好；不同身份在同一账号体系下获得对应的发布或管理入口。
- 匿名社区与内容互动：用户可浏览树洞信息流，按话题查看内容，发布匿名帖子、图片和评论，并对帖子进行点赞、收藏、举报或删除自己的内容。
- 校园广场与组织通知：广场汇集校园今日、热搜、社团、二手和跑腿入口；学校组织、学院和社团负责人可在权限范围内发布通知或活动内容。
- 食堂信息共建与评价：用户按食堂分区浏览商铺、菜品和排行，可新增商铺、菜品及分类信息并提交菜品评价；删除商铺、菜品和分类由管理员处理。
- 社团活动与成员协作：学生可浏览社团、加入社团、阅读社团日常帖子和活动通知，并报名参与活动；社团负责人可维护社团内容和成员事项。
- 二手交易与跑腿服务：用户可发布和筛选闲置商品、维护出售状态并联系交易对象，也可发布、承接和查看跑腿任务状态。
- 课程日程、待办与日记：用户可以维护课程表、个人待办和日记，在个人空间查看自己的记录和内容；待办完成状态可即时更新。
- 站内通知、举报与后台治理：系统为互动、活动和组织事务生成站内通知；用户可举报不当内容，管理员可处理举报、敏感词、用户状态、内容和审计记录。

## 典型操作流程

1. 学生注册或登录校园账号，并按需要设置昵称、头像和语言。
2. 学生从底部导航进入树洞、食堂、广场、社团或个人空间，浏览与自己相关的内容。
3. 学生在对应模块完成发帖、评价、报名、交易发布、任务发布或个人记录维护。
4. 系统将评论、活动报名、组织通知等结果写入站内信箱，用户可查看和处理未读通知。
5. 发现违规内容时，用户提交举报；管理员在后台审核内容和用户状态并记录处理结果。

## 操作手册页面/流程模块

1. 账号登录与个人资料：从启动页或个人空间的账户入口进入登录、注册和资料编辑页面。
   - 使用场景：首次使用时完成注册或登录；需要调整头像、昵称或语言时进入个人资料页。
   - 操作要点：填写账号信息并提交登录或注册；进入个人资料页修改允许编辑的资料；保存后返回个人空间查看更新后的显示信息
2. 树洞信息流与匿名发布：从底部导航进入树洞，点击发布入口创建新帖子，点击信息流条目查看详情。
   - 使用场景：学生想查看校园讨论、搜索话题或发表匿名想法时使用。
   - 操作要点：浏览信息流或按话题筛选内容；输入标题或正文并按需要添加图片；发布后在详情页查看评论和互动；对自己的内容进行编辑或删除，对不当内容进行举报
3. 广场、热搜与校园通知：从底部导航进入广场；校园今日页内通过学校通知和学院通知标签切换内容。
   - 使用场景：学生想快速获取学校或学院通知、参与热搜讨论，或进入社团、二手和跑腿服务时使用。
   - 操作要点：浏览轮播和校园通知；切换学校或学院通知查看对应信息流；进入热搜详情参与讨论；有组织权限的用户选择所属组织后发布通知
4. 食堂分区、商铺和菜品：从底部导航进入食堂首页，选择食堂分区后进入商铺页，点击商铺或菜品查看详情。
   - 使用场景：学生在用餐前查询商铺、菜品和排行，或发现缺失信息时补充商铺、菜品和分类。
   - 操作要点：选择食堂分区浏览商铺；进入商铺查看菜品和分类；按需要新增商铺、菜品或评价；管理员在管理界面处理删除操作
5. 社团与活动报名：从广场或底部导航进入社团首页，选择社团和活动条目进入详情。
   - 使用场景：学生寻找社团或决定参加活动时使用；社团负责人维护社团日常内容和活动安排。
   - 操作要点：浏览或搜索社团；进入社团查看动态和活动；符合条件时填写活动报名信息；负责人发布活动或日常帖子并查看报名情况
6. 二手交易与跑腿任务：从广场入口或底部导航进入二手市场和跑腿模块，点击发布按钮创建商品或任务。
   - 使用场景：学生出售或购买闲置物品、发布临时跑腿需求或承接他人任务时使用。
   - 操作要点：选择分类或状态筛选内容；进入详情查看商品或任务信息；发布自己的商品或跑腿需求；根据完成情况维护出售或承接状态
7. 课程表、待办与日记：从个人空间进入课程表、待办或日记页面。
   - 使用场景：学生需要查看一周课程、安排待办或记录校园生活时使用。
   - 操作要点：查看或维护课程安排；新增待办并设置截止信息；勾选完成的待办；选择日期创建或修改日记
8. 站内信箱、举报与后台管理：从顶部通知入口或个人空间进入信箱；在内容详情中打开举报入口；管理员从个人空间进入后台。
   - 使用场景：学生收到评论、活动或组织事务提醒时查看信箱；发现不当内容时举报；管理员审核内容和用户状态时使用后台。
   - 操作要点：在信箱查看通知并进入关联内容；选择原因提交举报；管理员查看待处理举报并进行内容或用户处置；管理员查看系统配置和审计记录

## 申请表建议口径

- 开发目的：为厦门大学马来西亚分校学生提供统一的校园信息交流、生活服务和个人事务管理入口。
- 软件的主要功能：软件提供校园账号注册登录和个人资料维护，并以树洞、广场和社团模块承载校内内容浏览、匿名发帖、评论互动、组织通知和活动报名。食堂模块支持按分区查询商铺和菜品、浏览排行、维护菜品信息及发表评价；二手市场和跑腿模块支持发布、筛选、状态维护和事务跟进。课程表、待办和日记帮助用户记录个人日程。站内信箱集中展示互动和事务提醒，举报及管理员后台用于处理不当内容、敏感词、用户状态和审计记录。软件支持中文和英文显示，可通过网页端与 Android 移动端访问。
- 技术特点：采用 React 前端、Node.js 服务端和 MySQL 数据库组织校园业务数据；移动端使用 Capacitor 封装 Android 客户端，采用令牌认证、对象存储图片上传、站内通知与基于角色的管理权限控制。
- 软件的技术特点选项：APP/教育软件
- 软件分类：应用软件
